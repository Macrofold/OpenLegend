# Open Legend

A shared simulation of people, memory, survival, and worlds whose mechanics can grow through play.

**Create a world by playing it. Share what you discover.**

The project is currently a research and design archive, with an interactive art-reference board. The game, hosted worlds, marketplace, memberships, and creator fund are not implemented or available for purchase.
