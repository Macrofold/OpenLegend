## R06 / P1 — Which host/framework supports actual sector ownership and reconnect semantics?

Investigation: One-sector always-on service trial, deploy drain, reconnect, replica routing, database outage, restore

Evidence needed: No dual authority/duplication; measured cost and recovery; documented routing

Current qualification belongs to the linked delivery owners, not the former archive's “not started” snapshot. This question grants no new implementation or paid-experiment authority.

PD11/PD12 retain the many-world fleet and shared-world expansion route. The foundation research distinguishes provider orchestration from simulation ownership; it does not select a replacement provider or make independent-world throughput evidence for one crowded world.

## R12 / P1 — What does a sector actually sustain?

Investigation: Load/soak tests with active clients, NPCs, bursts, fire, inventory changes, reconnect and provider latency

Evidence needed: Report safe occupancy under workload, CPU, memory, serialization, bandwidth, queues and costs

Current qualification belongs to the linked delivery owners, not the former archive's “not started” snapshot. This question grants no new implementation or paid-experiment authority.

The current research ambition is 1,000 concurrent humans per independent persistent world, potentially 5,000, plus NPC activity. It is not a selected local cap, a measured operating envelope or a replacement for smaller proof/release gates. Qualify dispersed active areas, concentrated interaction/recipient load, old history, cold activation and failure bursts separately. Physical exclusion can bound some local work but does not prove small coupled components or bounded delivery. Use the [qualification chapter](../../../research/mmorpg-engine-foundations/05-qualification-and-capacity.md) and the needs-design briefs' existing PF/PS/NSC owners; do not create another benchmark programme.

## R13 / P1 — Can partial failures repair without rewriting history?

Investigation: Crash during trade/commit/process update/transfer; quarantine a live mechanic; restore pinned versions

Evidence needed: Outcome replay and ownership correct; public repair events understandable

Current qualification belongs to the linked delivery owners, not the former archive's “not started” snapshot. This question grants no new implementation or paid-experiment authority.

The initial native distribution design retains whole-world recovery at a complete durable cut. Partially resident regions, pending decisions and mature evidence must preserve that contract; independently committing regional storage remains a separate design, not an incidental consequence of adding compute cells.

## R15 / P1 — What are the minimum safeguards for a shared public wilderness world?

Investigation: Threat-model actual text/action/media paths; test injection, griefing, resource denial, private-state extraction and unauthorized creator speed changes

Evidence needed: Bounded effects/cost; usable reporting/blocking; creator powers isolated

Current qualification belongs to the linked delivery owners, not the former archive's “not started” snapshot. This question grants no new implementation or paid-experiment authority.

Include cost-amplifying inputs, physical blocking, reconnect/activation bursts and noisy-world contention when the corresponding feature is offered. Bounded output lists do not prove bounded preparation, and overload does not authorize dropping accepted effects or exposing shared private context.
