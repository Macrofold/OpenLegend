# Character bodies, clothing and animation

Research into convincing, continuously adjustable game characters from concept art, including anatomical foundations, identity, controls, garments, animation and browser delivery.

- [Strategy research](archive/2026/2026-11-11-strategy.md): complete candidate comparison, anatomical knowledge, transfer methods, AI-assisted workflows, costs, licensing, proposed validation and sources.
- [Amended research brief](archive/2026/2026-11-11-brief.md): the requested scope and intended coverage, including all five amendments concerning staged validation, native ecosystems, transfer, existing controls and clothing.

For the current Peacock anatomy problem, the [concrete workflows](archive/2026/2026-11-11-strategy.md#4-the-recommended-end-to-end-workflow) begin with MHP10’s selected fuller-donor repair when resumed. The proposed [2 → 4 → 12 support-shape plan](archive/2026/2026-11-11-strategy.md#a-concrete-support-shape-plan) separates useful source shapes from the 30 evaluation recipes; it is not a quota of generated bodies. Built-in body controls, existing morph/scan anatomy and focused sculpting are alternative sources for missing shapes. For a separately authorized foundation comparison, CC5.2 merits the first complete body-and-outfit trial when access and rights permit. Existing pauses, selections and acceptance remain controlling; these workflows are proposals, not executed quality evidence.
