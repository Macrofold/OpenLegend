# Character bodies, clothing and animation

Research into convincing, continuously adjustable game characters from concept art, including anatomical foundations, identity, controls, garments, animation and browser delivery.

- [Strategy research](archive/2026/2026-11-11-strategy.md): complete candidate comparison, anatomical knowledge, transfer methods, AI-assisted workflows, costs, licensing, proposed validation and sources.
- [Amended research brief](archive/2026/2026-11-11-brief.md): the requested scope and intended coverage, including all five amendments concerning staged validation, native ecosystems, transfer, existing controls and clothing.

The research recommends evaluating an established anatomical system on its native topology and rig with artist supervision, beginning with a small MetaHuman experiment while retaining Character Creator and other credible alternatives. The report is a researched recommendation; it does not select a production foundation, execute an experiment or authorize generation, purchases or paused production.
