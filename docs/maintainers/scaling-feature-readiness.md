# Massive-scale research: feature and release readiness children

[Scaling index](../scaling/README.md) · [Sequence](../scaling/sequence-and-gates.md) · [Deferred large-scale work](scaling-long-term/README.md)

**Planned, not verified.** These SF children decompose cross-subsystem evidence and integration requirements from the research. They do not reimplement SC tasks or the PF/CR/SW/EPR/INV/EWF/SL/D feature owners. Each body lives here once; its parent retains implementation and release status. Existing parent criteria now consume these concrete cases rather than duplicating their checkboxes. Every item includes its **Massive-scale research** provenance.

G0/G1/G2 are the current foundation/growth/public-release gates. A P3/P4/P5 consumer is feature-gated even if it arrives before general distributed scale. G3/G4 implementation stays in the separate deferred backlog. No tests, spending, deployments, retention decisions or new mechanics are authorized merely by tracking the work.

## Performance and behavioral evidence

<a id="sf01"></a>
- [ ] **SF01 — Reproducible workload manifest.** G0; parent PF00. Extend the existing profiler's result with commit/build/CPU/DB/device, seed, world age, density, active bodies/processes, events/actual witnesses, eligible recall size, speed and duration. **Exit:** cold versus warm and real versus simulated rates are explicit; the same manifest can reproduce a small semantic case and a bounded load case. **Massive-scale research:** [capacity](../../archive/02-research/massive-scale/capacity-model.md), [benchmark §§1–3](../../archive/02-research/massive-scale/benchmark-plan.md). This refines PF00, not a new benchmark platform.

<a id="sf02"></a>
- [ ] **SF02 — Complete latency and offered-load attribution.** G0/G1; parent PF00/PF05; depends on SF01. Correlate input, gateway/admission, writer, native, commit, projection, network, browser application and first frame; separately trace AI preparation/recall/provider/accepted output. Use scheduled arrivals as well as closed-loop clients and record generator saturation. **Exit:** p50/p95/p99/max/timeouts and offered/admitted/completed/rejected counts include hidden waiting; a rejected action or local prediction is not counted as confirmed movement. **Massive-scale research:** [benchmark §§2–4](../../archive/02-research/massive-scale/benchmark-plan.md), [browser networking](../../archive/02-research/massive-scale/domains/browser-networking.md).

<a id="sf03"></a>
- [ ] **SF03 — Sparse, dense and aged-state regression matrix.** G1, extended at G2; parent PF11/EPR09; depends on SF01. Vary distant entities, local neighbors, old history, active status rules, item holdings, definition count and time multiplier independently, then combine realistic peaks. Use SC/PF/SW counters to detect the first nonlinear cost. **Exit:** report true witness/output cost separately from unnecessary global scans, cold setup and steady state; stable algorithmic regression checks and noisy reference-host qualification retain different roles. **Massive-scale research:** [benchmark matrix](../../archive/02-research/massive-scale/benchmark-plan.md), [current pressure points](../../archive/02-research/massive-scale/repository-hot-paths.md).

<a id="sf04"></a>
- [ ] **SF04 — Small deterministic failure/semantic corpus.** G0 seam, G1/G2 evidence; parent PF11/EPR09/SL and existing deferred regression owners. Reuse adapters for clock, RNG, persistence and recorded provider outcomes; exercise last-resource races, event-time privacy, lost acknowledgment, stale result, correction and restore. **Exit:** both safety and resumption/liveness are checked against explicit expected outcomes; no paid call or full general simulator is required. Keep real DB/browser tests because fixtures cannot prove those integrations. **Massive-scale research:** [benchmark §6](../../archive/02-research/massive-scale/benchmark-plan.md), [architectural option 10](../../archive/02-research/massive-scale/architectural-options.md).

<a id="sf05"></a>
- [ ] **SF05 — Recall quality and character continuity corpus.** G1 and before a retrieval/model change; parent CR12/D2/D62; depends on SC11 and consumed retrieval path. Label direct observation, hearsay, false belief, same-named subjects, corrected names, unresolved promises, expired/forgotten evidence and long absence. **Exit:** exact eligible retrieval and mandatory references are measured with temporal/update accuracy and downstream behavior; unauthorized results are failures, not a quality tradeoff. Preserve complete required About-me/conversation/obligations rather than truncating to pass. **Massive-scale research:** [memory retrieval](../../archive/02-research/massive-scale/domains/memory-retrieval.md), [benchmark §5](../../archive/02-research/massive-scale/benchmark-plan.md).

<a id="sf06"></a>
- [ ] **SF06 — Browser/device execution qualification.** G1/G2; parent PF05/SW14 and D09; depends on SF02 and SC02 as applicable. Profile initial playable scene, CPU/GPU frame tails, decode/state-application work, allocation/heap, draw/animation counts, input response and background-tab behavior on selected devices. **Exit:** device/network envelope is recorded, warm FPS cannot hide cold-loading stalls, and local render simplification changes no authority or sensing. Protocol loss/reconnect evidence reuses SC02.4 rather than a second task. **Massive-scale research:** [browser networking](../../archive/02-research/massive-scale/domains/browser-networking.md), [media/assets](../../archive/02-research/massive-scale/domains/media-assets.md).

## Hosted-release gates

<a id="sf07"></a>
- [ ] **SF07 — Select release objectives and unresolved policies.** G2 before public persistence; parent D5, D03/D09/D48/D58–D62 and current governance. Specify admitted workload/device/region, durable acknowledgment/loss window, recovery point/time, retrieval deadline/quality, retention windows and human-private operations. **Exit:** decisions are recorded in existing owners; no numeric crowd/SLA, deletion policy or global rewind right is inferred from research. Native response and generated dialogue have separate objectives. **Massive-scale research:** [operational readiness](../../archive/02-research/massive-scale/soon/operational-readiness.md), [decision questions](../../archive/02-research/massive-scale/decision-questions.md).

<a id="sf08"></a>
- [ ] **SF08 — Measured unit economics and spend containment.** G1 measurements, G2 pricing/release; parent D5/billing; depends on SC10 and SF01. Account for CPU/RAM reserve, storage/index/WAL/backups, egress, inference/embeddings/attention/voice/assets, failed/stale attempts and operations. **Exit:** report per-player/world-hour distributions and heavy-creator/crowd/wake cases using actual contracted prices; quotas/reservations reconcile and runaway spend has a tested containment path. Average token price is not a subscription margin model. **Massive-scale research:** [capacity arithmetic](../../archive/02-research/massive-scale/capacity-model.md), [operations/cost](../../archive/02-research/massive-scale/domains/operations-cost.md).

<a id="sf09"></a>
- [ ] **SF09 — Security and cost-amplification review.** G0 boundaries, G2 before strangers share a world; parent D5/EWF/identity; depends on SC01/SC03/SC13. Trace hostile commands, replay, privileged tools, injected speech/books/memories, oversized assets, expensive queries and recursive triggers. **Exit:** deterministic authority/permission controls contain model/client proposals; limits cover expanded work, not only requests; private telemetry and operator access are scoped and auditable. Exact legal/minor/recording obligations require their own reviewed policies. **Massive-scale research:** [extensibility/security](../../archive/02-research/massive-scale/domains/extensibility-security.md), [risk register](../../archive/02-research/massive-scale/risk-register.md).

<a id="sf10"></a>
- [ ] **SF10 — Compatible deployment and rollback rehearsal.** G2; parent D5/SL/INV-5; depends on stable schema/protocol/source identities. Exercise mixed client, engine, job, module, save and prompt versions; drain or fence the owner and classify pending results. **Exit:** stale bundles/proposals cannot bypass current rules, rollback respects irreversible migrations/paid effects, and user-visible reconnect/update is explicit. This is initial deployment evidence; distributed directory/fleet implementation remains LT-O02. **Massive-scale research:** [operations/cost](../../archive/02-research/massive-scale/domains/operations-cost.md), [data migration](../../archive/02-research/massive-scale/soon/data-migration.md).

<a id="sf11"></a>
- [ ] **SF11 — Restore, dependency-outage and incident drills.** G2; parent D5; uses SF04/SC03/SC05/SC16. Rehearse empty-target restore, owner death near commit, slow DB, provider outage, corrupted/missing artifacts, erasure restoration and reconnect bursts. Write detection/containment/recovery/verification/user-communication procedures. **Exit:** useful play resumes under selected objectives with correct inventory, evidence, obligations and external accounting; runbook ownership is assigned at release, not invented here. **Massive-scale research:** [readiness drills](../../archive/02-research/massive-scale/soon/operational-readiness.md), [operations/cost](../../archive/02-research/massive-scale/domains/operations-cost.md).

<a id="sf12"></a>
- [ ] **SF12 — Complete first-shared-world qualification.** G2/P2 external access; parent D5/PF11, not dependent on P6. Run two independent humans plus representative agents through movement, conflicting actions, differing knowledge, conversations, disconnect and restart; then the admitted load with maintenance. **Exit:** SF07 objectives, privacy, queues, recovery, browser and cost gates pass with headroom; scope is stated rather than advertised as million-player capacity. No collection of isolated microbenchmarks substitutes for this end-to-end slice. **Massive-scale research:** [production world](../../archive/02-research/massive-scale/soon/production-world.md), [benchmark gates](../../archive/02-research/massive-scale/benchmark-plan.md).

## Feature-specific integration — do not wait for general massive scale

<a id="sf13"></a>
- [ ] **SF13 — Construction/environment dependency scenario.** G0 interface, G1/P3 before a new supported family; parent EWF08/INV-5/SW and the specific world mechanic. Reuse SC13/SC14 to trace a roof/wall edit through support, navigation, sight, hearing, rain/moisture, fire and observation. **Exit:** only actually supported relations execute, unknown physical prerequisites use declared behavior, old/new neighborhoods invalidate correctly and resource/definition continuity survives save/upgrade. This adds an integration fixture, not all listed solvers as implementation requirements. **Massive-scale research:** [environment systems](../../archive/02-research/massive-scale/domains/environment-systems.md), [simulation/time](../../archive/02-research/massive-scale/domains/simulation-time.md).

<a id="sf14"></a>
- [ ] **SF14 — Conserved local economy and rewind policy.** G1/P2 barter; extend for P4 currency, before any export. Parent D1/D2/AG and economy policy. Define unique/lot ownership, atomic trade/reservation, exact units and source/sink accounting using existing semantic owners. **Exit:** concurrent last-item claims, interruption, stale listings and save restoration preserve conservation; accelerated-time arbitrage and goods leaving a rewindable timeline have an explicit policy before transfer is enabled. Regional exchange additionally requires LT-R06. **Massive-scale research:** [economy/social](../../archive/02-research/massive-scale/domains/economy-social.md), [persistence](../../archive/02-research/massive-scale/domains/persistence-consistency.md).

<a id="sf15"></a>
- [ ] **SF15 — Sparse social records and high-fanout channels.** G1/P2 conversations; extend at P4 groups/mail. Parent NC/D2/EPR. Keep relationship, recognition, membership, current hearing and historical audience distinct; use sparse directional records and bounded channel delivery without redefining physical speech. **Exit:** joining late grants no previous private turns, mass announcements cannot block native actions, and high-degree participants are tested without a dense all-pairs relationship table. Remote spectator modes remain LT-S08, not an overflow shortcut. **Massive-scale research:** [economy/social](../../archive/02-research/massive-scale/domains/economy-social.md), [perception/interest](../../archive/02-research/massive-scale/domains/perception-interest.md).

<a id="sf16"></a>
- [ ] **SF16 — Generated-asset ingestion and delivery envelope.** Before runtime asset publication at its P3/P5 consumer; parent runtime-art/SW and D5. Separate generation/validation/transcoding/publication, pin immutable asset identities, use immediate native fallback and scoped CDN/storage access. **Exit:** hostile decoded sizes/mesh complexity are rejected before resource exhaustion; stale assets cannot alter bodies, revive entities or cross restore timelines; first-playable and peak GPU/network/memory costs meet the device envelope. **Massive-scale research:** [media/assets](../../archive/02-research/massive-scale/domains/media-assets.md), [browser networking](../../archive/02-research/massive-scale/domains/browser-networking.md).

<a id="sf17"></a>
- [ ] **SF17 — Voice/streamed-speech audience and lifecycle.** P5 before the first voice promise, not after P6. Parent NC/EPR/SW, D10/D5. Keep media separate from game authority; enforce actual recipient detail on transport, bind fragments to utterance/speaker/timeline and align captions/transcripts. **Exit:** modified-client subscription, door/range changes, interruption, reconnect, delayed synthesis and restore cannot leak intelligible speech or private URLs. Synthesize/transcribe shared authorized source work once where appropriate, not once per listener; muting a client is not confidentiality. **Massive-scale research:** [media/assets](../../archive/02-research/massive-scale/domains/media-assets.md), [perception/interest](../../archive/02-research/massive-scale/domains/perception-interest.md).

<a id="sf18"></a>
- [ ] **SF18 — Media capacity, consent and outage qualification.** P5; depends on SF17, D09/D10 and reviewed recording/retention policy. Measure concurrent speakers/listeners, codec bitrate, relay/TURN traffic, decode CPU, first-audio latency and paid speech services. **Exit:** selected browsers and audience controls pass under fanout and outage; text remains complete, unsafe retention is not assumed and pricing includes media egress. Large media-provider/deployment choices require this evidence, not a room-size marketing number. **Massive-scale research:** [media/assets](../../archive/02-research/massive-scale/domains/media-assets.md), [operations/cost](../../archive/02-research/massive-scale/domains/operations-cost.md).

## Existing advanced-feature gates, not new duplicate tasks

INV's G2/D20 and EWF10 continue to own isolated executable extensions; their required fuel/time/memory/query/output/descendant limits, restricted host capabilities and failure/restore evidence are described in [mechanic growth](../scaling/mechanic-growth.md) and the [security research](../../archive/02-research/massive-scale/domains/extensibility-security.md). They are conditional P7/G4 work, not permission to add a script runtime now. Pack rights/compatibility/export continue under INV/D4/D36, including source privacy, immutable pins and no automatic knowledge grants. Their work is explicitly mapped in [research coverage](../scaling/research-coverage.md).

SF13–SF18 are only required for the actual supported/released feature. They do not require implementing all speculative environmental, economy, voice or asset domains. Record deliberate unsupported capability rather than silently substituting a simpler mechanic. Promote genuinely long-term changes through the deferred backlog and preserve the original parent/child IDs.
