# Elapsed-time simulation delivery

## PF13 — Elapsed-time simulation

[Simulation time](../simulation-time.md) owns the engine contract; [base-world time](../worlds/base/time.md) owns current fidelity limits. This focused PF13 tracker replaces the previously unresolved link to a PF13 section in the general performance tracker. PF12 remains the broader scaling program; SW and EPR retain geometry, motion and sensory ownership. The [boundary catalogue](simulation-boundaries.md) records future opportunities, not a second task list.

### Delivered implementation

- [x] **PF13.1** Separate game-clock conversion from integration and rendering frequency. Accept finite elapsed game time and return a bounded completed prefix; `maxIntervals` limits computation, not simulated seconds. Keep the existing host wake and real-time routine durability policy.
- [x] **PF13.2** Resolve due start-state transitions, capture all conditional rates from that state, integrate existing work, then apply endpoint outcomes and observations. Newly started work receives no earlier duration. Preserve action IDs, exact support and zero-time stage handling without an unbounded fixed-point solver.
- [x] **PF13.3** Bound intervals at finite-family work completion, depletion, health damage, status comparisons/reactivation/daily windows, fuel expiry, commitments and conversation inactivity. Keep unsupported separately clamped/coupled flows on an explicit conservative fallback. Zero-rate operations do not erase opposing-rate detection.
- [x] **PF13.4** Preserve continuous swept movement, route/support seams, flight/perch/fall boundaries and native random timer remainder. Localize displacement-based sampled-perception fidelity in the bundled time policy. Dead, incapacitated and perception-blocked observers do not impose smaller sensory displacement limits.
- [x] **PF13.5** Subtract actual progressed time from host debt, retain navigation and cancellation fences, yield between bounded accepted intervals, and keep command durability unchanged. No source memory or consolidation pressure gates time; genuine storage failure still does. No new save format, replacement world or persistent scheduling authority was introduced.
- [x] **PF13.6** Retain independent browser/device frame updates and existing support-aware interpolation. No 20 FPS cap follows from sparse simulation or a future 20 Hz pose publication policy. Camera motion does not create model work or mechanical movement.
- [x] **PF13.7** Maintain the natural-boundary catalogue and RP03 review triggers, with exact versus approximate/candidate status, invalidation and existing subsystem ownership. Preserve old measured evidence as historical; remove mandatory-one-second assumptions from current contracts.
- [x] **PF13.8** Inspect the sound/speech branch and provide [integration guidance](speech-time-integration.md). Reuse the existing conservative status/static-object helpers; do not reintroduce binary hearing in place of that branch's graded listener-specific evidence. No merge of the sound branch is implied by this item.

### Runtime acceptance and remaining work

Record actual game-time progression and interval counts rather than treating attempted calls as ticks. See [evidence](../verification/simulation-cadence.md); short local observations do not qualify all dense workloads.
- [ ] **PF13.10** Qualify the combined sound/cadence application after branch integration: event-time emission before/after movement, sleep and geometry boundaries; stable heard fragments and real-time caption lifetime. Preserve the sound branch's latest revocation-safe asynchronous work and encounter-cache invalidation.
- [ ] **PF13.11** Replace the global conservative displacement/fallback constraint with region-local or dependency-valid bounds only after profiling shows benefit and intermediate evidence is defined. A tiny-radius sense or one fast flyer must not silently lose meaningful observations. Exact fleeting LOS/contact crossings remain unimplemented.
- [ ] **PF13.12** Define and qualify net-flow saturation/coupling for currently unsupported serial clamps before removing their one-second fallback. General nonlinear laws and mutually activating status cascades need explicit owned semantics, not an assumed sum of rates.
- [ ] **PF13.13** Extend sustained full-stack 1x/3x/8x qualification to dense stacked surfaces, many independently moving observers/flyers, mature history, repeated restore, slow navigation and PostgreSQL. Measure actual progress, debt including busy callback time, queue age, command tails and retained resources. Region scheduling and analytical dormant worlds are not prerequisites to the current slice.
- [ ] **PF13.14** Improve long snapshot-gap presentation using authorized recent-past motion, preserving floors/corners and immediate revocation. Rendering remains at device cadence; interpolation is not independent proof of collision or a 60 FPS performance claim. Coordinate with SW18 rather than creating another renderer.
