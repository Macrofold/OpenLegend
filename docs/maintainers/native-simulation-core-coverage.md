This finite inventory was refreshed at the pinned source using static import/re-export/dynamic-import specifiers (including type-only imports, domain subpaths and relative imports), package export resolution, then reverse transitive file dependencies across non-test `apps`, `packages` and `scripts`. Internal owner/caller duties are mapped above; no barrel-wide deletion is implied.
