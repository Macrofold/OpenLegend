Ordinary routes retain their smaller limits; the inner candidate schema remains unchanged. - [x] **WW09 — Near-exhaustion worker allocation (INV-13/21.3).** Quote native run funding after additional worker needs using the existing scoped attempt ledger and retained worker identity. Manual native-adapter and ledger observations cover new, reused and lost-marker cases. Image integration, provider enforcement and broader payer qualification remain open rather than implied by this run/worker slice.

Checked items mean the named implementation exists with the bounded recorded manual observations. They do not close [WAC01–WAC02, IRF01–IRF09 and UWA01–UWA10](TODO.md#world-agent-session-continuation--deferred-regression-coverage), live Macrofold qualification, or broader composition acceptance.
