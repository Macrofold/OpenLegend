## Current scope

**Design complete; implementation not started.** Rust is the selected proof candidate. Full supported-game adoption depends on a complete pipeline comparison; distributed and adaptive execution have later independent gates. No runtime, dependency, benchmark or resource change accompanies the design. Existing BK/PF/RU/SR implementation and evidence remain intact.

This tracker owns native-core conversion and its experiments. [PF10/PF11](performance.md#pf10--workers-and-movement-prediction) retains worker/operating and population qualification; [D6/PD12](production-deployment.md#conditional-launch-and-expansion) retains production distributed delivery. Do not duplicate their task bodies or claim their completion from a proof. [BK29](production-data.md#bk29--pressure-and-preparation-work-removal-proposed) remains the owner of current-runtime semantic/retention improvements; take its accepted source as common behavior when comparing.

## Delivery stages

- [x] **NSC00 — Architecture and staged decision design.** Specify compact resident authority, full smaller pipeline, host/native boundaries, exact personal evidence and restore, work pooling, cells, machine handoff, adaptive placement, isolation experiments and removal targets. Source inspection, primary research and affected documentation review establish design completion only. The [design pair](../projects/native-simulation-core-feature-spec.md) and E1–E7 are the deliverables.

- [ ] **NSC01 — Comparison contract and minimal native host.** After implementation authorization, pin the latest integrated source and selected family/input inventory; reconcile BK29 and all relevant existing acceptance. Build the two-crate workspace, exact toolchain/lockfile, generated boundary types, bounded native lifecycle and current-format installation. Prepare a narrow equivalent compact-state TS control for the replaced hot path, not a second full engine. **Exit:** explicit supported/refused installation, one authority per proof world, no raw world crossing, no per-field FFI or hidden live TS fallback. Correctness/setup only does not establish performance.

- [ ] **NSC02 — Complete one-worker gameplay proof.** Depends on NSC01. Port the entire declared movement/action/rate → sensing/local identity → attention/history → player/NPC capture → actual PostgreSQL save/cold-restore pipeline. Include real native animal reaction/continuation, speech, independent stale detail, unknown identity, correction/forgetting and pending-result fences. Preserve current numerical policies and the same semantic work in both arms. **Exit:** all declared [proof journeys](../projects/native-simulation-core-tech-design.md#91-freeze-the-comparison-contract) pass through real consumers; no empty save/recording stubs; failed writes and newer pending suffixes behave correctly. Run E1/E3 only after the implemented stage is complete.

- [ ] **NSC03 — Bounded parallel proof and adoption decision.** Depends on complete NSC02. Add one shared native compute pool, declared read/write scopes, independent jobs and deterministic effects/RNG. Compare identical one/multiple-worker execution with bridge, Node consumers, database, allocation and waiting included. Exercise tiny, crowded and independent workloads. **Exit:** E1–E3 evidence identifies what representation/language/parallelism actually improves under preselected existing criteria. Record **adopt**, **reject** or **inconclusive**. Reject/inconclusive stops broad migration; remove unsuccessful experiments and report the remaining bottleneck. A fast isolated kernel cannot pass this gate.

- [ ] **NSC04 — Complete supported-game conversion.** Conditional on NSC03 adoption. Inventory every runtime domain import and classify it as mutation, scoped read, authored data, formatting, transport or dead. Port the installed world-family closure and convert action/menu/inspection, body/status/inventory/assembly, authoring, grant, native response, cognition, memory and current-format storage callers together. Retire replaced Immer/draft/certification/diff and dual-authority paths. **Exit:** real standard opening and ordinary browser/NPC/save/restore journeys pass; the coverage manifest has no supported caller using a hidden TS world. Future unimplemented feature families retain their own trackers. Preserve useful starting content; no legacy reader or permanent backend switch.

- [ ] **NSC05 — Same-machine cells and interaction ownership.** Depends on NSC04 for full-game adoption; a scoped E4 can run earlier on the proof without claiming full delivery. Separate geometry membership from cell ownership and core scheduling. Implement conservative read overlap, exact conflict ownership and border-stable routing; no network stack is required. **Exit:** equal interior/edge/corner outcomes, large bodies/attachments, converging/dispersing groups, real heard/received history and scoped privacy; no duplicated simulation per player, full-cell copy per tick or unconditional global scan. Include E4's added metadata/copy costs.

- [ ] **NSC06 — Controlled distributed execution and custody.** Conditional on measured single-host capacity needs and NSC05. Coordinate with D6/PD12; retain one existing writer, same-operator/same-build world and exact affected-scope timing. Implement declared influence scopes, bounded prepared exchanges and prepare/stage/quiesce/fence/activate handoff. Keep unsupported/global scopes colocated. **Exit:** E5 establishes useful capacity after network/synchronization costs; commands and interactions occur once through failure before/after fencing, restart, stale replies and cross-boundary action/receipt/save paths. No global per-action RPC barrier, speculative rollback, full past-memory transfer or independently sharded storage. No production approval follows from a two-machine experiment.

- [ ] **NSC07 — Adaptive grouping and hysteresis.** Depends on NSC06; prototype placement decisions against captured counters without executing migration first. Add bounded actual-work/communication counters, neighboring-cell candidates, destination capacity checks and amortized transfer decisions. Reuse existing boundary data and immutable resources; retain no full former-owner replica. **Exit:** isolated E6 beats fixed assignments on complete stationary/moving/cycling/dispersal workloads without churn, enlarged overlap debt, gameplay barriers or starvation. If adaptive work costs more, remove it and retain static assignments. Exact operating values remain measured tuning, not world rules.

- [ ] **NSC08 — Adoption cleanup and existing qualification integration.** At each adopted boundary, update current contracts, manifests, limits, removal evidence and the scope of completed tasks. Remove rejected experiments and replace unsupported performance claims with source/workload-specific results. Coordinate dispersed-player, crowded-scene, boundary, mature-memory and failure acceptance through PF/PS/PD rather than a new suite. **Exit:** applicable stage obligations pass or are explicitly failed; no unfinished agreed conversion is relabeled a future improvement. Final production capacity and enjoyment remain their actual evidence owners.
