## Using and maintaining this index

Follow the dependency order inside each owning plan; table order is navigation, not a global implementation sequence. Cognition references the production persistence track, and conjuring references invention families and the art pipeline. Resolve those dependencies for the slice being built rather than treating every linked specification as a prerequisite to finish in full.

Keep task IDs and completion evidence in their owning documents. Put new maintenance follow-ups in Maintainer TODO and feature implementation work in its focused tracker. When adding, renaming or consolidating a work plan, update this index and affected links; preserve unique requirements, outstanding tasks and historical findings under the repository documentation rules.
