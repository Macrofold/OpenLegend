**Current progress.** The [Unreal project](../../apps/unreal/README.md) has a packaged Mac build of the existing-game port. The native client connects sign-in, steering with three cameras, conversation and reply recovery, actions and crafting, inventory, character status, trade, Events, Journal, the map, private notes and nicknames, and timed combat to their Rust owners. It includes previously selected public art for worlds with the matching artwork permission. See the [code and caller checks](#existing-game-port--november-25-2026).

**Rust evidence.** Local and hosted desktop sign-in passed approval, exact loopback binding, proof mismatch, concurrent redemption and independent sessions. The real update stream passed steering, direction changes, stale sequence refusal, stop, pause and observer omission. A two-client control transfer withdrew the first scope, reopened an observer view and recovered the original command receipt. Controlled HTTPS replies exercised unrelated movement, evidence withdrawal and explicit cancellation. The original outcomes and permitted caption text were checked through cold PostgreSQL reopening. Disconnecting during PostgreSQL commit for local sign-in, desktop code exchange and sign-out reproduced a stopped writer in each case. The repaired build completed each admitted operation and accepted the next write. It refused code replay and revoked only the selected session.

**Client checks.** Disposable source checks cover the steering replay bound, exact support IDs, matching support candidates, skipping unchanged body transforms and locating Mac and Windows build products. The client reacquires state after a stale-scope refusal and keeps the original receipt. Unresolved receipts reserve the slice’s single pending slot. UE04 owns the full recovery controls. The retained browser build, TypeScript and network boundary checks passed.

**Current batch.** Follow the [existing-game migration scope](../projects/unreal-engine-5-migration-feature-spec.md#existing-game-migration-scope). Complete the retained browser gameplay callers in Unreal, bring across the existing usable art, and provide the native launch path. Building and construction, invention, cooperation and creator work stay with their existing owners. Use focused code, build and real-server checks. A hand-tested playthrough, public release or new art approval is a separate milestone.

**Gameplay interruptions.** The local [interruption checks](#gameplay-interruptions--november-25-2026) cover UE02 connection and control, UE03 movement and UE04 drafts and original results. The native player uses the world’s offered actions and its speech composer.

### Control after an expired walk

- **Cause.** With 50 ms added each way, seeded ±10 ms jitter and the first renewal reply dropped, the old Mac package `a1b5a7de6` sent Stop at about 250 ms from the first input reaching the relay. Rust had accepted the next renewal and the relay sent its reply at 312 ms. The stop reply was sent at 353 ms and the client closed its healthy event stream at 359 ms. Rust treats the last controlling stream closing as departure, so the next view opened as an observer.
- **Same fault on the repaired Mac package.** Build `516892c8d` stopped the affected gesture once. A fresh W press moved another 1.04 m with a higher sequence on the same input token. Control and the original stream stayed live without a full state read or a new control request. The signed arm64 Development executable has SHA-256 `3ec702a240733295a58f87de53522bc3c2d900c776106b61e2e1c6dd928b7e93`. The run used the same 0.2× disposable Base opening and Rust release as above.
- **TCP loss and genuine disconnect.** An isolated Linux TCP relay added 50 ms and seeded ±10 ms jitter each way with 1% configured packet loss. It recorded nine actual drops toward Rust and three toward the Mac across four keyboard walks. Rust expired the first movement token, and a fresh press worked with the replacement on the same stream and control generation. Deliberately cutting that stream cleared the scene and brought the client back as an observer. W sent no movement request, and PostgreSQL matched the final position.
- **Focused checks.** The exact steering code passed 36 scenarios, including a lost Stop reply, a late reply after a new press, retaining the prediction bound and independent timed-attack renewal. TypeScript and the network boundary check passed. These were functional checks on local development transport. The UE03 release timing and platform gates remain in [Qualification under delay and loss](../projects/unreal-engine-5-migration-movement.md#qualification-under-delay-and-loss).
