## Selected outcome

A top-center danger notification offers **Defend** and **Retaliate**. Either deliberately hides obstructing task panels, preserves useful drafts and enters the existing combat view. Defend starts the ordinary finite shield/body defense; Retaliate requests one ordinary attack with the currently equipped supported source against the actual permitted attacker. Neither skips native preparation, recovery or exact lethal review.

An opening attack gains physical preparation time without slowing the shared world. One recipient-life encounter shares its allowance across attackers; real native timing, modifier sampling, rearming and released-projectile boundaries are defined in the world/technical owners. An anonymous player-assistance cue is not character knowledge or a hidden-source targeting grant.

Named equipment sets use exact carried objects and one short atomic transition. A deliberate manual set or explicit combat-mode choice may replace incompatible work; an automatic incoming-assault/own-offense mode notice may not. An emergency reaction takes priority with current gear. One not-yet-submitted set can follow its admitted reaction; an already canceled/refused admitted set is not automatically retried. Exiting combat never equips another set. A body brace and one craftable padded outfit supply the small missing native consumers needed for useful ordinary-life-to-protection play.

The complete loop includes returning to the last nonempty inventory/trade workspace without replaying a transaction, restarting a chore or changing gear. A menu grants no immunity or global pause. Peaceful escape and returning to a livelihood are successful outcomes, not incomplete fights.
