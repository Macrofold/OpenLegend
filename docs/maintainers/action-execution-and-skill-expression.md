## Intended player outcome and implementation boundary

A person can run with WASD, deliberately switch to attack mode, and receive predictable automatic entry after their own admitted offense or a personally experienced assault. An ordinary attack remains useful. An installed timed technique adds optional hold/release control. Every accepted release picks the body or point currently under the aim cursor, even if the cursor stayed still. A visible eligible target uses its current body center and observed-motion lead; ground/scenery uses exact XYZ. The projectile travels along the actual selected ray; good timing changes only supported native consequences and cannot force an impact. A qualified local duck changes the defender's real body, so it can clear one arrow and still be struck by another. Reach, recovery, shielding, body susceptibility and actual contact remain causal native outcomes.

The selected implementation retains native steering, exact selected shot rays, held-ready melee, ranged-weapon recovery, the obtainable hammer and bounded actual local posture. Ordinary manufacture, retained tools, named output ports, open baskets and finite work batches remain useful foundations. Pouch fitting and its quality facet are removed rather than replaced. Integrate with [CTR01 physical contact](combat-and-threat-responses.md#ctr01--world-permission-and-actual-contact), observed-motion aiming, native animal responses and [CF defense](parallel-batch-06-rivals-and-contested-ground.md); their independent acceptance is not completed by ASE.
