# Action execution and skilled input — ASE01–ASE12

**Status: Design complete; implementation and independent player qualification not started (October 19, 2026).** This focused tracker owns the finite deliverable for [ND38 — Player skill during action execution](needs-design.md#nd38--player-skill-during-action-execution). The [feature specification](../projects/action-execution-and-skill-expression-feature-spec.md) owns gameplay; the [technical design](../projects/action-execution-and-skill-expression-tech-design.md) owns reusable mechanisms, server input authority and client controls; the [world profile](../worlds/base/skilled-action-execution.md) owns chosen fictional laws and tuning; [ASE limits](../limits/action-execution-and-skill-expression.md) owns the bounds/tuning inventory. A researched suggestion and a designed interface are not executable behavior.

## Intended player outcome and implementation boundary

A person can run with WASD, deliberately switch to attack mode, and receive predictable automatic entry after their own admitted offense or a personally experienced assault. An ordinary attack remains useful. An installed timed technique adds optional hold/release control while the player follows a moving animal with the cursor. The projectile travels along the actual selected ray; good timing changes only supported native consequences and cannot force an impact. A qualified local duck changes the defender's real body, so it can clear one arrow and still be struck by another. Reach, recovery, shielding, armor and actual contact remain causal native outcomes.

The same optional-input mechanism supports **carefully fitting an existing manufactured woven container** through a distinct placement challenge. Real material work produces one capacity-bearing individual item that remains useful through carrying, nesting, gifting and trading. Neither path makes human reflex mandatory for competent basic play or makes NPCs pretend to use a mouse.

Current aim and walking are incompatible; selected shots still use direction deviation; manual held-ready melee, launcher recovery, the authored obtainable hammer and actual local duck remain unimplemented. Items lack the selected per-instance fit. Every change below must land through its existing owner. Implementation depends on the selected, partially pending [CTR](combat-and-threat-responses.md) collateral/observed-threat work and [CF](parallel-batch-06-rivals-and-contested-ground.md) defensive work; their existing acceptance gates remain open.
