## Deliberate scope decisions

- Server mode changes require restart. A remote/live toggle and worker broadcast mechanism are outside this project.
- Native per-operation counters and heavy CPU/allocation/tracing remain separately explicit. The main server switch does not automatically activate all instruments.
- Operational error records, Intelligence inspection, saved gameplay history and spending/accounting remain independent. Their existing improvement work stays with its current owners.
- Off-mode automated browser comparisons initially use the existing fixed-input workload. Survival input currently depends on opt-in scene inspection; adding an independent read-only testing hook is deferred until a concrete matched survival comparison requires it. Do not describe the limited comparison as full survival-soak qualification.
- A matched finite service comparison measures collection overhead of about 2.9% additional CPU for its first tick and 7.1% for seven warm ticks, with identical resulting worlds. This is not full-game or smooth 3× evidence. Both authorized additional 60-second observations are performed and analyzed. Actual successful gameplay differs materially, so PC06’s matched-activity requirement remains open. The two-run allowance is exhausted; no further full-game observation is authorized. See the report for 2.99893×/2.98129× progress, the off browser’s 476.6 ms stall, retained earlier gameplay compromises and unattributed console HTTP errors.

The selected [renderer comparison](../projects/renderer-comparison-feature-spec.md) is an unimplemented consumer of this contract. [RCP10](renderer-comparison.md#rcp10--extend-profiling-and-comparison-reports) owns backend collectors and equivalent report semantics; RCP11 owns its declared comparison scope. Preserve default-off preparation, capture/query ownership and immutable stopped reports. A renderer selector does not enable profiling, and callback cadence is distinct from actual draw submissions and physical screen presentation. This design supplies no further PC06 run allowance or closure of its matched-activity evidence gap.
