## What a name or ID identifies

| Canonical term                  | Meaning in OpenLegend                                                                                                                                                                                                       | Source                                                                                                                |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Stable ID                       | The stored key for one entity or record within its owner’s scope. Say what it identifies, such as an **entity ID** or **event ID**. Two people can have the same name. Renaming one leaves its ID and relationships intact. | [Identity contract](../identity-and-references.md#contract)                                                           |
| Composite key                   | The fields that together identify one record. For personal evidence, a shared source ID can occur in more than one observer’s records or in several record kinds. A lookup needs the complete key for that record.          | [Identity contract](../identity-and-references.md#contract)                                                           |
| Definition ID                   | The key for an authored definition, such as a kind of tool. An **item instance ID** identifies a particular item in the world. Two knives made using the same definition can have different owners and locations.           | [Definitions and physical entities](../identity-and-references.md#contract)                                           |
| Definition pin                  | The definition ID, version and digest taken together. A **digest** is a value computed from content for comparison. Matching a definition by ID alone can select different content.                                         | [Definition pin validation and comparison](../../packages/domain/src/definition-pins.ts)                              |
| Canonical name (entity or item) | The name stored by the naming rules. Common names omit a grammatical article, such as “hare”. A meaningful article inside a proper name stays, as in “The Nameless”. This use of “canonical” describes stored spelling.     | [Entity names and articles](../entity-names.md#one-grammar-owner)                                                     |
| Permitted label                 | The wording a particular observer may receive for a subject. The same person might appear as “a person” to one observer and “Ada” to another. The label can change when the observer learns something.                      | [Display grammar](../entity-names.md#one-grammar-owner), [actor context](../identity-and-references.md#actor-context) |
| Name form                       | The grammatical category used to display a permitted name, such as a proper name, a singular count noun, a plural or a mass noun. It determines how the display site can add an article.                                    | [Entity names and articles](../entity-names.md#one-grammar-owner)                                                     |

## What a reference lets its recipient do

| Canonical term                | Meaning in OpenLegend                                                                                                                                                                                                                   | Source                                                                                                       |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Observer-local contact        | Something one observer detected, such as a voice from behind a door. The contact alone establishes neither who produced it nor that a person was there.                                                                                 | [Observer-specific references](../identity-and-references.md#selected-observer-specific-evidence-target)     |
| Remembered individual         | An individual known to a particular observer through retained evidence, such as someone with a familiar voice. The observer may remember a face or voice without learning a name or knowing where the individual is now.                | [Observer-specific references](../identity-and-references.md#selected-observer-specific-evidence-target)     |
| Current-body reference        | A reference to a particular physical life for a current interaction. In the player interface the opaque body reference changes when the body is replaced or the server restarts. The server still checks whether the action is allowed. | [Control and projection](../identity-and-references.md#control-and-projection)                               |
| Known-place reference         | A token for a remembered destination that a character is allowed to select. For example, a character can offer to guide someone to a remembered place without seeing it now.                                                            | [Destination references](../identity-and-references.md#contract)                                             |
| Decision-scoped handle        | An identifier the server gives a model for a permitted subject in one prepared decision. The server resolves it using the map for that decision. The model cannot grant itself a new target by naming one.                              | [Actor context](../identity-and-references.md#actor-context)                                                 |
| Response-local alias          | A name that one generated response uses to refer to another operation or proposed output in that response. The application assigns any durable identity when it admits the result.                                                      | [Identity contract](../identity-and-references.md#contract)                                                  |
| Evidence reference            | The identity and revision of the specific source supporting a fact. For example, a private memory’s content digest can identify the version used for a decision. Specify the source family when discussing what can invalidate it.      | [EvidenceRef and source revisions](../identity-and-references.md#selected-observer-specific-evidence-target) |
| Source fragment               | An immutable piece of source material that several personal records can reference. Sharing storage for the source never grants a second observer the first observer’s experience.                                                       | [Shared temporal references](../identity-and-references.md#selected-shared-temporal-references)              |
| Observer receipt (perception) | The record of what a particular observer actually acquired. Two characters can receive different parts of the same event.                                                                                                               | [Shared temporal references](../identity-and-references.md#selected-shared-temporal-references)              |
