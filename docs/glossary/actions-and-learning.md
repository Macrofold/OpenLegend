# Goals, action choices and learning

[Glossary index](README.md) · [Gameplay and physical actions](gameplay-and-space.md) · [Invention and recipes](worlds-and-creation.md#invention-making-and-learning)

## What a character wants and can try

| Canonical term       | Meaning in OpenLegend                                                                                                                                                                                                                                                                                                   | Source                                                                                                                                                               |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Desire               | Something a character wants, even momentarily. A hungry character can want a berry and eat one without deciding on a continuing goal.                                                                                                                                                                                   | [Desire and maintained goals](../agent-agency.md#3-goals-are-useful-structure-not-the-whole-mind)                                                                    |
| Goal                 | An aim a character chooses to keep pursuing across decisions, such as saving food for tomorrow. The agency records also call this a **maintained intention**. Use **goal** in player-facing language.                                                                                                                   | [Goals and intentions](../agent-agency.md#3-goals-are-useful-structure-not-the-whole-mind)                                                                           |
| Plan                 | The character’s chosen next steps toward a purpose. A character can revise the plan when a step fails or circumstances change. The plan itself establishes neither success nor another character’s cooperation.                                                                                                         | [Plans](../agent-agency.md#4-plans-preserve-continuity-without-prescribing-a-life)                                                                                   |
| Action intention     | The action a character means to attempt, or the action someone has asked them to attempt, with any chosen target, means and constraints. “Follow that deer” requests following. Attacking the deer would be a separate choice. The simulation checks whether the actor can carry out the request.                       | [Intent and meaning](../action-capabilities.md#5-intent-envelope-and-semantic-fidelity), [goals](../agent-agency.md#3-goals-are-useful-structure-not-the-whole-mind) |
| Intent grounding     | Matching a requested action to an operation the world supports and identifying the inputs it needs. For “offer her one berry,” the game must resolve “her” to a specific recipient the actor is allowed to select and “one berry” to an item and quantity the actor can offer. The recipient decides whether to accept. | [Translation pipeline](../action-capabilities.md#7-translation-pipeline)                                                                                             |
| Action availability  | Whether a particular actor meets the requirements to start a particular action now, with the specified target, equipment and other inputs.                                                                                                                                                                              | [Availability](../action-capabilities.md#action-availability-and-temporary-execution)                                                                                |
| Action shortlist     | The subset of action choices selected to show a character for the decision at hand. Other supported actions can still be requested.                                                                                                                                                                                     | [Shortlist](../action-capabilities.md#capability-availability-is-not-the-shortlist)                                                                                  |
| Target binding       | How and when an action identifies its target. “Go where the deer was last seen” uses a remembered location. “Follow that deer” uses the same individual’s position only while current observations support tracking it.                                                                                                 | [Binding time](../action-capabilities.md#62-binding-time-is-part-of-meaning)                                                                                         |
| Completion condition | The event or state that marks an activity finished. A fishing cast can finish with no catch. A later step that requires a fish can use one only if the cast produced it. Following can instead continue until a chosen stopping condition.                                                                              | [Completion and dependencies](../action-capabilities.md#completion-and-dependencies)                                                                                 |
| Interruption         | An activity stops before its intended end. Effects that already occurred remain in the world, such as a spent arrow. A later attempt or resumption uses the rules for that activity.                                                                                                                                    | [Recorded outcomes](../action-experience.md#what-is-recorded)                                                                                                        |

## What experience can teach

| Canonical term       | Meaning in OpenLegend                                                                                                                                                                                                                                                                                                               | Source                                                                                                                                                               |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Observed result      | What the actor who made an attempt learned about its outcome from the evidence available to them. A shooter can know they released a projectile yet have no evidence that it hit or injured anyone.                                                                                                                                 | [Recorded effects](../action-experience.md#what-is-recorded), [practice evidence](../action-experience.md#scoped-practice-and-coaching-support)                      |
| Learned method       | A way to try an activity that a character has learned from their own experience. The same sequence of steps can serve several characters. Each needs their own evidence to remember and use it, and must still meet the requirements for the next attempt. The Character screen lists them under **Personally learned activities**. | [Learning and shared definitions](../action-experience.md#learning-and-shared-definitions), [Character screen labels](../../apps/client/src/ui/activity-history.tsx) |
| Practice             | Doing an activity in a way that can improve proficiency under the world’s rules. In the base world, a qualifying sling release counts whether the character was hunting or deliberately shooting at a practice target. Preparing a shot, watching someone else shoot or reading their recipe earns no release credit.               | [Practice and coaching](../action-experience.md#scoped-practice-and-coaching-support)                                                                                |
| Practical competence | The proficiency a world defines for performing a particular activity. For example, the base world records **sling handling** and uses it when resolving an eligible shot. A character can know how to make a sling before they have practiced shooting it.                                                                          | [Base competence](../worlds/base/practical-competence.md#one-narrow-competence)                                                                                      |
| Coaching episode     | An agreed lesson between a willing learner and a coach. Either can withdraw. A completed base-world sling lesson requires the coach to witness a qualifying shot and its visible result, followed by feedback with the learner. The implementation still allows feedback after release, before the result is observed.              | [Base coaching](../worlds/base/practical-competence.md#one-useful-coaching-episode), [delivered scope](../action-experience.md#scoped-practice-and-coaching-support) |
