# Goals, action choices and learning

## What a character wants and can try

| Canonical term       | Meaning in OpenLegend                                                                                                                                                                                                                                                                        | Source                                                                                                                                                                     |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Goal                 | Something a character has chosen to keep pursuing across decisions, such as keeping food for tomorrow. A **desire** is something they want. Eating a berry can satisfy hunger without creating a lasting goal. Use **goal** in player-facing language.                                       | [Goals and intentions](../agent-agency.md#3-goals-are-useful-structure-not-the-whole-mind)                                                                                 |
| Plan                 | The character’s chosen next steps toward a purpose. A character can revise the plan when a step fails or circumstances change. The plan itself establishes neither success nor another character’s cooperation.                                                                              | [Plans](../agent-agency.md#4-plans-preserve-continuity-without-prescribing-a-life)                                                                                         |
| Action intention     | What a character chooses or is asked to attempt, including any specified target, means and constraints. “Follow that deer” authorizes pursuit. Attacking the deer would require another choice. In the agency records, **maintained intention** means a goal that persists across decisions. | [Intent and meaning](../action-capabilities.md#5-intent-envelope-and-semantic-fidelity), [goals](../agent-agency.md#3-goals-are-useful-structure-not-the-whole-mind)       |
| Intent grounding     | Resolving the requested action to a supported operation with specific inputs. “Give her one berry” needs an authorized recipient and a quantity. Binding those inputs still leaves execution to the simulation.                                                                              | [Translation pipeline](../action-capabilities.md#7-translation-pipeline)                                                                                                   |
| Action availability  | Whether this actor could start this exact action under current conditions. The **shortlist** contains choices selected to present in a particular context. A supported action can be absent from the shortlist.                                                                              | [Availability](../action-capabilities.md#action-availability-and-temporary-execution), [shortlist](../action-capabilities.md#capability-availability-is-not-the-shortlist) |
| Target binding       | How and when an action identifies its target. “Go where the deer was last seen” uses a remembered location. “Follow that deer” uses the same individual’s position only while current observations support tracking it.                                                                      | [Binding time](../action-capabilities.md#62-binding-time-is-part-of-meaning)                                                                                               |
| Completion condition | The fact that determines when a particular activity has finished. Starting a gather action cannot satisfy a later step requiring its gathered berries. Some activities, such as following, continue until their stated stopping condition.                                                   | [Completion and dependencies](../action-capabilities.md#completion-and-dependencies)                                                                                       |
| Interruption         | An activity stops before its intended end. Effects that already occurred remain in the world, such as a spent arrow. A later attempt or resumption uses the rules for that activity.                                                                                                         | [Recorded outcomes](../action-experience.md#what-is-recorded)                                                                                                              |

## What experience can teach

| Canonical term       | Meaning in OpenLegend                                                                                                                                                                                                                         | Source                                                                                                                                                               |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Observed result      | What the actor could establish about the effect of an attempt. Releasing a projectile proves it was released. Claiming that it injured someone requires evidence of the impact and injury.                                                    | [Recorded effects](../action-experience.md#what-is-recorded), [practice evidence](../action-experience.md#scoped-practice-and-coaching-support)                      |
| Learned method       | A way of attempting something that one character acquired from eligible experience. A shared structural definition can describe the steps. Each character needs their own acquisition and supporting evidence.                                | [Learning and shared definitions](../action-experience.md#learning-and-shared-definitions)                                                                           |
| Practice             | Attempting the activity under its world’s rules. In the Base sling exercise an eligible, actual release supplies practice evidence. Starting a shot or watching somebody else release supplies different evidence.                            | [Practice and coaching](../action-experience.md#scoped-practice-and-coaching-support)                                                                                |
| Practical competence | For a stated tool or activity, the character’s acquired ability to carry it out. In the Base sling rules, specify **sling handling** when discussing that ability. Knowing the steps and having practiced their execution are separate facts. | [Base competence](../worlds/base/practical-competence.md#one-narrow-competence)                                                                                      |
| Coaching episode     | A voluntary interaction between a learner and a coach involving an actual attempt, observation and feedback. Asking for coaching does not supply either person’s consent to every later step.                                                 | [Base coaching](../worlds/base/practical-competence.md#one-useful-coaching-episode), [delivered scope](../action-experience.md#scoped-practice-and-coaching-support) |
