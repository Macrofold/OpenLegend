# Player interface and presentation

[Glossary index](README.md) · [Assets and releases](assets-and-releases.md) · [Perception and memory](perception-and-memory.md)

## What the player opens

| Canonical term                | Meaning in OpenLegend                                                                                                                                                                                                                                                      | Source                                                                                                                                                 |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Heads-up display (HUD)        | The controls and status information shown around the game scene during play.                                                                                                                                                                                               | [Game HUD](../../apps/client/src/ui/gildmoss-hud.tsx)                                                                                                  |
| In view                       | The list of entities the server reports as visible to the player character. An unfamiliar person can appear here before the character learns their name. Panning the camera changes what is on screen independently of what the character can see.                         | [In view list](../../apps/client/src/ui/nearby-entities.tsx), [selection and inspection](../ui-ux/world-interaction.md#selection-hover-and-inspection) |
| Inspector (player interface)  | The window that displays information the player may read about a selected subject. Opening it reads available information. **Inspect** as a physical action can require the character to approach and examine something.                                                   | [Selection and inspection](../ui-ux/world-interaction.md#selection-hover-and-inspection)                                                               |
| Action browser                | The interface for looking up actions for a particular subject. It can show actions the character can take and explain why others are unavailable. Opening the list does not attempt an action.                                                                             | [World interaction](../ui-ux/world-interaction.md#selection-hover-and-inspection)                                                                      |
| Speak                         | The control a player uses to have their character say words aloud. Choosing an addressee records who the words are meant for. Other characters within hearing can still hear them.                                                                                         | [Player Speak](../narration-and-conversations.md#player-speak-and-descriptive-act), [speech composer](../../apps/client/src/ui/world-composer.tsx)     |
| Act                           | The control for describing an observable gesture or attempt, such as shaking a fist at a gate. To damage the gate, the character must use a separate action that can cause damage.                                                                                         | [Descriptive Act](../narration-and-conversations.md#player-speak-and-descriptive-act)                                                                  |
| Journal                       | The player’s workspace for reading records about their character. Its sections are **Events**, **Memories**, **Notes**, **People**, **Commitments**, **Places** and **Story**. The internal key `promises` opens **Commitments**.                                          | [Journal tabs](../../apps/client/src/ui/journal.tsx)                                                                                                   |
| Events (Journal)              | The Journal section showing recorded occurrences this player is allowed to read. For example, speech their character missed can be absent even though the speaker really spoke.                                                                                            | [Perceived world events](../perceived-world-events.md)                                                                                                 |
| Story (Journal)               | The Journal section that displays selected personal story entries for the player. Reading the narration creates no new world event or experience for the character.                                                                                                        | [Story reader](../../apps/client/src/ui/history.tsx), [narration](../narration-and-conversations.md#2-three-kinds-of-truth)                            |
| Personally learned activities | The list on the Character screen showing [methods this character has learned](actions-and-learning.md#what-experience-can-teach), such as how to put supplies in a cache. Opening the list lets the player read about those methods. Using one requires a separate action. | [Character screen](../../apps/client/src/ui/panels.tsx), [list and labels](../../apps/client/src/ui/activity-history.tsx)                              |
| Map marker                    | A private annotation a player places on their character’s map, with a location, label and optional note. It records what the player entered. A **known place** records something the character learned about a location.                                                   | [Map protocol](../../packages/protocol/src/cartography.ts), [identity](../identity-and-references.md#contract)                                         |
| Invent something              | The command in the **Game** menu that opens the invention workspace. Its **Invent**, **Recipes** and **Requests** controls cover recipe proposals, learned recipes and earlier invention requests.                                                                         | [Entry points](../../apps/client/src/main.tsx), [invention workspace](../../apps/client/src/ui/inventions.tsx)                                         |
| World Agent workspace         | The creator interface opened by **Game → World Agent**, containing the authoring conversation and saved changes for review. The code calls the panel `world-editor`. The menu item **Inspect world** opens a separate inspection tool.                                     | [Entry points](../../apps/client/src/main.tsx), [authoring views](../../apps/client/src/ui/world-agent-session.tsx)                                    |
| World operations              | The separate account-authorized interface for administering or viewing a world. Available tasks depend on the world grant. An operator can use it without controlling a character.                                                                                         | [World operations](../../apps/client/src/ui/operations-console.tsx)                                                                                    |
| Checkpoints                   | The interface for listing, capturing or restoring gameplay checkpoints when authorized. The application also saves the running world during play.                                                                                                                          | [Checkpoint UI](../../apps/client/src/ui/game-saves.tsx), [saving](runtime-and-storage.md)                                                             |

## Controls, selection and camera

| Canonical term               | Meaning in OpenLegend                                                                                                                                                                                                                                | Source                                                                                                                              |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Hover                        | Moving a pointer over a target. Hover can show a hint or outline without selecting the target or issuing a character action.                                                                                                                         | [Selection and hover](../world-presentation.md#selection-and-hover)                                                                 |
| Selection (player interface) | The entity or option the player has chosen in the interface. Selecting a subject to draft an action identifies the intended target. The simulation separately checks what the character currently perceives and whether the action can proceed.      | [Selection and inspection](../ui-ux/world-interaction.md#selection-hover-and-inspection)                                            |
| Keyboard focus               | The control that will receive keyboard input. Use **Focus attribute** or **deliberate attention** when discussing a character inside the simulation.                                                                                                 | [Control interaction](../ui-ux/controls.md), [Base attention](../worlds/base/attention.md#foreground-capacity)                      |
| Center on player             | The camera control that moves the view back to the player character once.                                                                                                                                                                            | [Camera controls](../../apps/client/src/ui/camera-controls.tsx)                                                                     |
| Follow player                | The camera control that keeps the view moving with the player character until follow mode ends.                                                                                                                                                      | [Camera controls](../../apps/client/src/ui/camera-controls.tsx)                                                                     |
| Range guide                  | A visual outline of a character’s sight or hearing range. A subject inside the outline may still be hidden by a wall or may have produced no audible sound. The simulation determines what was actually sensed.                                      | [Camera and settings](../world-presentation.md#camera-and-settings), [range controls](../../apps/client/src/ui/camera-controls.tsx) |
| Speech caption               | On-screen text for a speech event the player character took part in or perceived. It can describe someone seen speaking without displaying any words. Words, speaker identity and direction appear only when the character’s evidence supports them. | [Hearing and speech](../hearing-and-speech.md), [caption renderer](../../apps/client/src/speech-captions.tsx)                       |
| Tooltip                      | Brief, supplementary help for a control, shown without opening a separate interactive surface.                                                                                                                                                       | [Overlay types](../ui-ux/controls.md#which-overlay)                                                                                 |
| Popover                      | A small surface anchored to a control, such as a filter that opens next to the button that invoked it. It can contain interactive choices.                                                                                                           | [Overlay types](../ui-ux/controls.md#which-overlay)                                                                                 |
| Panel                        | A surface for an ongoing task such as inspecting an object.                                                                                                                                                                                          | [Overlay types](../ui-ux/controls.md#which-overlay)                                                                                 |
| Modal dialog                 | A dialog that takes keyboard focus and prevents interaction with the background until it closes.                                                                                                                                                     | [Overlay types](../ui-ux/controls.md#which-overlay)                                                                                 |
| Workspace (player interface) | A dedicated area for carrying out a task with several related controls, such as authoring a world. When discussing editable art files on disk, use **editable asset workspace**.                                                                     | [Overlay types](../ui-ux/controls.md#which-overlay), [asset workflow](../asset-workflow.md#edit-or-generate-art)                    |
