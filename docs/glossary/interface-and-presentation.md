## What the player opens

| Canonical term         | Meaning in OpenLegend                                                                                                                                                                                                          | Source                                                                                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Heads-up display (HUD) | The controls and status information shown around the game scene during play.                                                                                                                                                   | [Game HUD](../../apps/client/src/ui/gildmoss-hud.tsx)                                                                                              |
| In view                | The UI list of subjects the player’s character can currently see. Opening an entry shows information the player is allowed to inspect.                                                                                         | [Selection and inspection](../ui-ux/world-interaction.md#selection-hover-and-inspection)                                                           |
| Inspector              | The window showing permitted information about a selected subject. **Inspect** as a physical action has separate requirements from opening the window.                                                                         | [Selection and inspection](../ui-ux/world-interaction.md#selection-hover-and-inspection)                                                           |
| Action browser         | The interface for finding actions available for a particular subject, with suggestions, categories and reasons an action is unavailable. Opening it does not issue a command.                                                  | [World interaction](../ui-ux/world-interaction.md#selection-hover-and-inspection)                                                                  |
| Speak                  | The control for having a character say words in the world. Choosing an addressee identifies whom the character addresses. Other characters may hear the words.                                                                 | [Player Speak](../narration-and-conversations.md#player-speak-and-descriptive-act), [speech composer](../../apps/client/src/ui/world-composer.tsx) |
| Act                    | The control for describing an observable gesture or attempt, such as shaking a fist at a gate. To damage the gate, the character must use a separate action that can cause damage.                                             | [Descriptive Act](../narration-and-conversations.md#player-speak-and-descriptive-act)                                                              |
| Journal                | The character’s reading workspace. Its sections are **Events**, **Memories**, **Notes**, **People**, **Commitments**, **Places** and **Story**. The internal `promises` key opens **Commitments**.                             | [Journal tabs](../../apps/client/src/ui/journal.tsx)                                                                                               |
| Events                 | The feed of events disclosed to the current player. A world event may occur without appearing in that player’s feed.                                                                                                           | [Perceived world events](../perceived-world-events.md)                                                                                             |
| Story                  | The Journal section that presents the player’s personal story entries. Narration renders permitted material into prose. It cannot create a world event.                                                                        | [Story reader](../../apps/client/src/ui/history.tsx), [narration](../narration-and-conversations.md#2-three-kinds-of-truth)                        |
| Map marker             | A player’s map annotation with a location, label and optional note. Placing a marker records what the player entered. A **Known place** has a separate character-knowledge record.                                             | [Map protocol](../../packages/protocol/src/cartography.ts), [identity](../identity-and-references.md#contract)                                     |
| Invent something       | The command in the **Game** menu that opens the invention workspace. Its **Invent**, **Recipes** and **Requests** controls cover recipe proposals, learned recipes and earlier invention requests.                             | [Entry points](../../apps/client/src/main.tsx), [invention workspace](../../apps/client/src/ui/inventions.tsx)                                     |
| World Agent workspace  | The creator interface opened by **Game → World Agent**. It contains the authoring conversation and saved changes awaiting review. `world-editor` is the internal panel ID. **Inspect world** opens a separate inspection tool. | [Entry points](../../apps/client/src/main.tsx), [authoring views](../../apps/client/src/ui/world-agent-session.tsx)                                |
| World operations       | The separate account-authorized interface for administering or viewing a world. Available tasks depend on the world grant. An operator can use it without controlling a character.                                             | [World operations](../../apps/client/src/ui/operations-console.tsx)                                                                                |
| Checkpoints            | The interface for listing, capturing or restoring gameplay checkpoints when authorized. The application also saves the running world during play.                                                                              | [Checkpoint UI](../../apps/client/src/ui/game-saves.tsx), [saving](runtime-and-storage.md)                                                         |

## Controls, selection and camera

| Canonical term   | Meaning in OpenLegend                                                                                                                                                                                                            | Source                                                                                                                              |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Hover            | Moving a pointer over a target. Hover can show a hint or outline without selecting the target or issuing a character action.                                                                                                     | [Selection and hover](../world-presentation.md#selection-and-hover)                                                                 |
| Selection        | The subject the player has chosen in the interface. Receiving physical detail, sustaining a character’s attention, and admitting a physical action each have their own rules.                                                    | [Selection and inspection](../ui-ux/world-interaction.md#selection-hover-and-inspection)                                            |
| Keyboard focus   | The control that will receive keyboard input. Use **Focus attribute** or **deliberate attention** when discussing a character inside the simulation.                                                                             | [Control interaction](../ui-ux/controls.md), [Base attention](../worlds/base/attention.md#foreground-capacity)                      |
| Center on player | The camera control that moves the view back to the player character once. **Follow player** keeps the camera moving with the character until follow mode ends.                                                                   | [Camera controls](../../apps/client/src/ui/camera-controls.tsx)                                                                     |
| Range guide      | A visual guide to a character’s sight or hearing range. The shape depicts a range. Evidence about whether an individual was actually seen or heard comes from the simulation.                                                    | [Camera and settings](../world-presentation.md#camera-and-settings), [range controls](../../apps/client/src/ui/camera-controls.tsx) |
| Speech caption   | An on-screen account of the character’s own speech or speech they could perceive. Seeing someone speak can produce a caption without words. Heard words, speaker identity and direction each depend on the character’s evidence. | [Hearing and speech](../hearing-and-speech.md), [caption renderer](../../apps/client/src/speech-captions.tsx)                       |
| Tooltip          | Short, supplementary, noninteractive help for a control. A **popover** opens a small contextual choice or filter that can accept input.                                                                                          | [Overlay types](../ui-ux/controls.md#which-overlay)                                                                                 |
| Panel            | A surface for an ongoing task such as inspecting an object. A **modal dialog** takes keyboard focus and makes the background inert until the dialog closes.                                                                      | [Overlay types](../ui-ux/controls.md#which-overlay)                                                                                 |
| Workspace        | In UI prose, a dedicated area for a larger task such as authoring or comparison. Qualify **editable asset workspace** when referring to files on disk.                                                                           | [Overlay types](../ui-ux/controls.md#which-overlay), [asset workflow](../asset-workflow.md#edit-or-generate-art)                    |
