### Reconciliation notes from the implemented review

The current adapter carries response-local operation identity, original request and manifest revision into native admission. Saved pending identity additionally includes explicit target and queue/replace mode; the exact alternative is never silently overwritten. These fields should map to the common invocation/authority contracts rather than become a competing definition registry. Current persistence follows the active in-place upgrade policy. Missing non-authoritative target/mode metadata is defaulted conservatively; existing alternative modes, commands, IDs and text remain unchanged. Executable bindings, stored revisions and queued steps now pin the relevant current encounter for actor targets. Recheck through the existing knowledge owner on admission/acceptance/start; an unpinned old intent remains readable but does not gain re-identification authority. This is a conservative native bridge, not the final INV definition/target contract.
