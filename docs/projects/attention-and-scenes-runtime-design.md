## 1. Outcome, evidence and scope

Characters should notice useful surroundings, remember a recently attended sequence, and act while other minds are thinking. Walking must not manufacture several copies of every observed movement. A long-lived character retains useful knowledge and selected memories, not a permanent map of everything that ever moved.

The [recorded baseline](../verification/attention-and-memory-core.md#final-runtime-comparison--october-29-2026) fails normal-speed acceptance. Its standard opening has seven people, twenty animals, 74 root objects and 163 total entities; the complete server achieved 0.771 normal speed over 30 real seconds with no model calls. Animals also move autonomously; “only the player moves” is not a valid description of that workload. Other historical high-host-load diagnostics identify work, not comparable throughput.

The [recording census](../verification/attention-and-memory-core.md#standard-opening-recording-census--october-29-2026) separately identifies repeated motion, terrain and facet-loss envelopes, along with their actual counts, byte costs and workload limits. Those recent records are not permanent memories, and their costs must not be added to a different complete-server profile.

The redesign removes those amplification mechanisms, rather than only packing them more tightly:

| Replaced cost                                                | Selected replacement                                                                                             |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| Uniform three-game-second broad sight                        | Change-fed broad and detailed sampling with different world-owned rates                                          |
| Full current/detail work for every changed body              | Cheap broad membership/placement; field-specific updates; materialize rich detail only for its consumer          |
| Position + posed body + two-endpoint motion history          | One admitted sample; derive body placement and motion from personal samples                                      |
| Full confirmation/loss envelopes per facet                   | One receiver frame, sparse field changes and grouped availability transitions                                    |
| Ground subdivision and attention-dependent terrain baselines | Shared physical features, bounded personal contextual acquisition, independent feature timeline                  |
| Repeat world/entity scans and list creation for counts       | Maintained membership/count queries and changed/due participant cohorts                                          |
| Repeated freezing/copying of the same evidence               | One private batch writer, immutable chunks and one publication of changed owners                                 |
| Cold ownership discovery before ordinary commands            | Immediate logical retirement; indexed, bounded physical reclamation on the existing maintenance/application path |
| AI requests retaining old worlds                             | Finite actor-permitted request data and independent late-effect admission                                        |

Keep the working clock, physical action/collision rules, language semantics, local identity, knowledge support and selected recent-memory horizon. Change the visual sampling policy explicitly; it is no longer a promise to preserve every old three-game-second sample. Preserve exact values and order **at the newly specified received resolution**. Broader physical vision/acoustics, investigation/combat integration, PP07/SAI-A and social scenes retain their own delivery and acceptance.

### 1.1 Alternatives and selection

| Candidate                                                   | Advantage                                                                      | Rejection or selected use                                                                                                                                                                     |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pack today's receipts more tightly, keep uniform polling    | Smallest conversion; almost identical sampling                                 | Leaves unnecessary sight, loss, terrain and duplicate motion production in place. Insufficient root correction.                                                                               |
| Record all physical motion globally and query it later      | Simple shared route lookup                                                     | Wrong knowledge boundary, unlimited unrelated world history, complex retrospective visibility. Rejected.                                                                                      |
| Shared physical sample streams with personal ordinal ranges | Excellent compression when observers receive identical consecutive samples     | A range can accidentally grant intervening unseen samples; cadence/precision/gaps need a second selection language. Do not require it.                                                        |
| Observer delta frames referencing shared exact values       | Explicit personal acquisition; common headers once; generic field changes      | **Selected.** Add exact adjacent-run encoding only for measured repetition within this representation.                                                                                        |
| Predict every future sight crossing                         | Can avoid periodic candidate work                                              | Requires fragile predictions about motion, occluders, sense changes and world rules. Rejected.                                                                                                |
| Change-fed, periodically serviced sight                     | Actual writes provide invalidation; sampling bounds latency without prediction | **Selected.** A quiet unchanged region does no raycasts or record production. Required occurrences keep their actual event boundary.                                                          |
| Put all sensing/storage on workers                          | Moves foreground delay                                                         | Does not remove work; adds transfers, stale results and queues. Keep minimal acquisition native; defer optional work and physical cleanup. Add CPU offload only after a demonstrated benefit. |

The [research comparison](attention-and-scenes-research.md) remains supporting context. Neither research analogies nor these paper estimates establish game capacity.

## 2. Non-negotiable boundaries

1. One semantic owner admits received information. The same transaction updates current support, attention, admitted recent changes and required effects. No caller can create lasting memory by calling a “final confirmation” shortcut.
2. Share neutral data, never permission. A shared source/sample address grants no access. Resolve the actor/life-owned current or historical selection first; use its precision, modality, local correspondence and source revision.
3. A sample is not a continuous route. Preserve every admitted intermediate sample while retained; never present interpolation or an unchecked interval as received fact. Fallible interpretation may use compatible samples and context, but adds no observations, continuity proof or action authority. Native proximity does not establish an anvil destination.
4. Preserve independent freshness. Seeing a position again does not refresh a hidden face, item, name or activity. Validity/support and actual measurement time are distinct.
5. Required physical effects, actual speech reception and admitted obligations cannot disappear because optional attention, a query budget or a model is busy. Their existing finite admission owns overflow.
6. Optional thought does not hold the world. No model call per movement, sensing phase, forgotten detail or elapsed few seconds; keep existing justified causes, spending, capacity and no automatic paid retries.
7. One current format and one writable authority. Convert producers, readers, validators and saves together; no compatibility branch, old-store fallback or second scene/memory archive.
8. Exact personal logical retention, physical bytes and temporary buffers are separate charges. Sharing is not unlimited memory. Required exact support and optional fading keep their existing meaning.

## 3. Compact evidence from the first write

### 3.1 Representation and ownership

Extend the existing `perception-evidence`, `received-values`, `temporal-evidence` and current-format codec owners. The following are storage meanings inside those owners, not new services or parallel APIs.

| Owner                  | Stored data                                                                                                                                                       | Lifetime                                                                                               |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Shared received values | Immutable typed neutral values, including received precision/clipping variants; no observer identity or nested observations                                       | While a permitted current, recent or required owner needs the value; bounded reclamation lag afterward |
| Current personal track | Local track/body-life binding, current field references, per-field original support and measurement times, availability masks, latest two compatible pose samples | Current encounter plus independently retained minimum knowledge; no list of all prior poses            |
| Personal frame         | One acquisition time/order and observer-frame reference; small dictionaries of track/source/field references; ordered changes and availability transitions        | Admitted recent/required coverage                                                                      |
| Temporal chunk         | Actor/life/epoch header, ordered frames, dictionary and index metadata, exact byte/change totals and coverage bounds                                              | Preferred recent horizon subject to explicit optional limits                                           |
| Feature view           | Actual received feature variant, original support, supported validity intervals and later changes                                                                 | Independent of attention membership; retained only while current/recent/required ownership needs it    |
| Captured cut           | Finite selected personal records and deduplicated immutable values/frames/support                                                                                 | Request/capture owner and its explicit validity; never a pointer to an old whole world                 |

Use bounded per-chunk dictionaries to avoid repeating actor IDs, source IDs, field names and observer frames in every change. The native writer admits the compact operation header and already-received field references directly; proof dictionaries detach those inputs once. Expanded receipts are selected read products. Page indexes and retained-prefix metadata inspect packed headers/references without decoding complete proofs. A frame entry is conceptually `(track, changedFieldMask, valueRefs, unequalSupportOverrides)`; an availability entry is `(track, affectedFieldMask, lastSupported, checkedAt, reason)`. Source identities include revision, body life and original field/occurrence ordinal where relevant. Dictionary compression must be exact and self-contained across cold reads. Numeric values remain exact; do not assume floating-point subtraction is lossless.

Native current capture first compares exact received value and effective pose references. Unchanged checked fields still emit their actual freshness confirmations, through the same minimal proof/time accessor used by rich current reads. They need no expanded lease, body/value projection or serialized-value comparison. New values, selection entry/exit, contact credit and unsupported inline reception keep the complete path. Receiver-frame recording remains independent of this shortcut.

Acquisition time and default measurement/confirmation time may be carried once by the logical frame **only when equal**. Speech occurrence time, delayed receipt, an older inspection, a held appearance and a newly measured position can differ in the same frame. Encode those differences explicitly. Frames have deterministic order within equal game times. A current facet owns compact personal acquisition/support metadata directly, without requiring temporal admission. If history is admitted, its fact handle also addresses the exact frame/operation/field. Broad-only reception creates no recent frame solely to make provenance addressable. A still-current or required fact keeps its small original support/locator after a historical page expires, not the unrelated page or all sibling facts. Full original observations are selected read products.

Only an actual receiver result enters this owner. Preparing a physical value or finding a spatial candidate does not create history. Canonical world IDs stay inside bindings; public/model references remain observer-local. Sharing is keyed by the actual emitted typed value and source meaning, including uncertainty and variant—not merely by entity ID. Producer parameters and field codecs remain exhaustive typed families; do not introduce arbitrary JSON patches.

Keep low-level frame append inside the recording owner, outside the public domain API. Producers submit their typed received contribution through the existing semantic admission operation; that owner derives attended, required and lasting treatment from actual source/consumer ownership and world policy. A caller's `required` boolean, importance score or final-confirmation label cannot authorize retention. Adding a producer requires exhaustive family classification and the shared dependency visitor, not another writable history path or a general capability framework.

### 3.2 Exact headers, frames and freshness

An original identifies the value/source fact actually acquired; a later confirmation records subsequent support without rewriting that original measurement or acquisition date. A receiver frame is the observer's position and heading captured once for the acquisition phase and reused through compact references, not a proof envelope copied into every field.

A source-only move changes its pose fields. The observer's own move changes one receiver frame and affected spatial relations, not every stationary subject's outward appearance. Appearance, carried exposure, public attributes and identity each retain separate dependencies. Source confirmation updates a small current support watermark or exact confirmation run; it does not append a copy of the unchanged value.

An exact run can contain `first, step, count` only after each represented check actually completed under the same support and timing rule. A timestamp outside that encoded cadence, changed precision/dependency, missing check or availability change ends the run. There is no inference that all globally stored source samples between two received samples were seen. Repeated reads of held state produce no acquisition or confirmation. Unchanged physical dependencies can support reuse through the producer's certificate; that reuse keeps the original measurement time and exposes current validity separately.

Support-invalidating changes produce an `unchecked` boundary, not an observed disappearance. Reacquisition restarts actual confirmation coverage even when the received value is unchanged. Coalesced invalidations retain the earliest boundary; if a later invalidation follows an intervening successful check, the unknown interval begins conservatively at that last check. It does not claim the hidden change occurred then. This bounded uncertainty avoids keeping a second physical-change history.

An actual unchanged check records a compact confirmation witness: the subject, exact neutral value/reception variant, original fact, confirming source and actual supported interval. The acquisition frame supplies equal timing once. A witness cannot confirm a different pose merely because both poses share an original source. Independently timed body detail remains separate from pose support. Repeated checks at an already captured support boundary append nothing. A frame carrying another subject's change includes its genuinely confirmed subjects as context; this permits a stationary person's later support to be read without inventing a separate occurrence. Prefix cuts exclude later witnesses, and confirmation cannot bridge an unchecked gap.

Capture and correction use one typed dependency visitor shared by current evidence, temporal chunks, knowledge capsules and storage indexes. Preserve original and later confirming support, source aliases, modality, frames and independently timed fields. Ordinary motion consumers do not expand complete original observations. Exact inspection materializes only the selected permitted closure.

### 3.3 Acquisition to consumption, literally

At an acquisition boundary:

1. Read the existing native change feed and due observer work. Select candidates before source preparation.
2. Prepare each needed neutral source field once per actual revision/received variant. Determine individual reception using the installed sense and authored perception-attribute rule.
3. Update changed current fields and support; emit small entered/changed/unavailable/confirmed results. Preserve needed old samples until recording admission completes.
4. Update attention from affected native scores. Record changes for subjects attended before **or** after the boundary, including a newly admitted baseline. Required occurrences use their independent source/consumer admission.
5. Append **one personal frame containing all admitted changes at this acquisition**, rather than one full receipt per subject/facet. A changed receiver frame is itself an admitted context change while relevant detailed/required history is active, even if stationary subjects changed no fields; record that frame once. Reuse neutral values. Apply [lasting-memory admission before expiry](../memory-architecture.md#6-hourly-consolidation-and-six-hour-raw-recall) independently; a frame is not a permanent memory.
6. Update exact ownership/count/index deltas, release replaced references and publish once at the coherent native boundary. Optional consumers select a finite permitted cut; no later world lookup repairs missing old evidence.

For example, an unknown person's three received placements reference P1, P2 and P3 in three frames. Their unchanged appearance is one A1 reference in the entry baseline. “Approaching” uses compatible P1/P3 plus the receiver's actual frames; the route reader can still return P2. Tool contact or speech enters its actual ordered event slot. There is no “approach episode,” no nearest-landmark label and no second motion payload. An independently received uncertain location remains a separate field if it differs from body placement; share only identical values.

Attention means the native detail allocation, whether chosen automatically or through an admitted focus request. It needs no watch action. Entry keeps the latest received baseline and future admitted changes. It cannot recover an unrecorded pre-entry route from shared storage. This observer’s independently retained earlier detail/required evidence remains retrievable, and an already received two-point current motion baseline may remain; entry grants no additional earlier points.

### 3.4 One compact native current-evidence representation

Keep small current rows and append-only recent chunks under the same received-value owner. Current rows do not retain the entire recent window, and recent rows do not duplicate the whole current map. Materialized `ObservedBody`, full observations and motion are read products, not duplicate writable stores.

Split outward body data from placement. The received pose sample supplies only position, heading and support actually emitted by the sense, preserving unknown/coarse fields; outward data supplies dimensions, appearance, description, effects, quantities and the other existing fields. Audit all variants and readers. Derive motion from compatible adjacent personally received samples, with their original times/precision and continuity, for current views, native cues, player history and NPC context alike. This replaces stored `observed-motion` endpoint envelopes, not the ability to request motion. Ordinary elapsed time or a source moving between samples does not itself break body correspondence: compatible samples support net displacement and separation change, without proving a continuous path. Actual occlusion/correspondence uncertainty is separately marked and forbids unsupported cross-gap joins.

On sight failure, keep the last known values and update one availability transition for affected fields. If six fields lose visual support together, one mask closes them; hearing or a retained name may remain valid. An actual support-invalidating discontinuity can make affected support **unchecked** before the next measurement; it is not proof the target disappeared. Record the uncertainty boundary when needed for attended history. Later successful checks must not silently fill it. Distinguish actual failed sight, attention release, correspondence/body replacement, technical missing coverage and source correction.

Current last-known information and detailed history have different lifetimes. The attended deer’s last placement and gap remain queryable within retained coverage. An unattended deer's earlier route remains absent. Closed unattended current tracks release their fields after the [existing bounded correspondence grace](../worlds/base/perception-recognition.md#exposure-and-weak-evidence) unless a real current/required owner remains. Attended last-known data is read from retained frames; deliberately learned knowledge has its own bounded owner. Do not retain a permanent last-known map of every tree or stranger. The identity owner decides whether reentry supports the same local individual; the history codec never joins tracks merely because raw source IDs match.

Explicit memory, naming and notes can retain selected checkpoint state through the existing sparse support-capsule owner. The capsule is marked `retained-state`, keeps original measurements and availability masks, and receives its own retention source address. It is absent from recent frame history: choosing to remember does not create a sighting, restore a route or refresh a value. Failed admission leaves no capsule, counter allocation or partial knowledge edit.

## 4. Change only the work whose input changed

### 4.1 Sight scheduling without predicting the future

The [broad/detail periods](../worlds/base/attention.md#selected-acquisition-cadence) select the currently supported ordinary sight adapter. Future B retains its [canonical visual law](../worlds/base/vision-and-gaze.md#canonical-temporal-sampling) and full acceptance. Installing B replaces this adapter's sight due-work path through the existing native timing owner; it does not add parallel broad/detail and B polls. Attention selects detail and retention, not a second physical clock or permission to discard required B measurements. Qualify B's resulting cost separately.

Use the existing semantic change feed, sensory index and due-work owner. A physical writer records its source/feature, changed fields and conservative old/new/swept bounds once; it does not loop over observers or rewrite personal field masks. Coalesce repeated changes per source/cell within the native batch before selecting affected receivers. Preserve the earliest producer-declared support-invalidating boundary even if an occluder returns to its old pose. The bounded pending marker records changed scope, not a trajectory or a fact the character perceived. Unknown/global writes or overflow select one conservative rebuild path; they never mean nothing changed. Reuse existing change-feed cursors rather than scan the growing dirty set for every mover.

The first pending change offers one next aligned due marker per applicable rate to the existing native boundary owner, before further native advance; later writes coalesce into that work instead of scheduling each receiver or microstep. The change family conservatively determines applicable rates before affected receivers are known. At the due boundary, settle preceding mechanics and query the shared source/observer indexes once for the accumulated changed scopes. Deduplicate affected receivers, then service their finite continuations in deterministic order against the coherent phase inputs. Native time cannot advance or publish beyond that boundary before its required acquisition cohort completes; a host yield preserves the cursor. Consume only the covered change generation, retaining later dirtiness. No new global dispatcher is needed.

Observer movement/turning or sense/life change selects that observer's affected sensing work; stationary observers are also affected by changed sources or intervening occluders. Grant invalidation follows the producer's declared rules below. Nonlocal authored dependencies declare their wider scope. Intersect coarse bounds and reuse sound cell/blocker/dependency certificates before narrow visibility. Do not rebuild all pairs merely to discover which pairs changed. In a mutually visible moving crowd, actual reception remains observer×source work; there is no linear-cost promise.

Pending invalidation belongs to the existing sensory continuation. Keep it across native publications until its affected work is consumed, and preserve the minimal unconsumed scope/earliest-boundary state through current-format save/restore. A pending observer/region marker distinguishes recomputation from producer-declared grant invalidation. Current eligibility/capture combines that marker with the field’s last actual certificate and declared hold, without mutating every held field on each physical write. Repeated dirtiness in an already unchecked scope does not emit repeated loss records. When a retained cut or next acquisition needs the boundary, the common recording owner emits one grouped availability operation at its actual earliest invalidation time. A completed check replaces only its covered pending scope; unfinished or more recent dirtiness remains. Ordinary continuous source/receiver/occluder motion schedules recomputation without withdrawing the producer’s held contact/field grants or attention eligibility. Compatible sampled endpoints can support displacement while the path between them remains unknown. Actual support-invalidating discontinuities use the producer’s declared invalidation scope; they do not become fictional loss.

Keep recomputation state, fresh authorization and presentation separate. Dirty means the prior proof needs reconsideration; it is not an observed disappearance. The player may continue displaying the last legitimately received sample with its original age through the existing presentation path until a sensed result or genuine revocation replaces it. Dirty marking must not make bodies blink between every pair of samples, issue a contact-loss story or select a different stranger. Held samples retain only the producer’s previously admitted grants through its declared hold. Current-body actions still check present range, clearance and other physical prerequisites; those checks grant no extra visual sample, new field or continuous path. A rendering, panel or context read cannot turn a cache miss into sensing. Actual sensed loss, life/control/privacy revocation and correction update those grants and presentation through their existing rules. Preserve existing renderer smoothing between accepted positions; visual smoothing is never stored as evidence or supplied to cognition as a witnessed intermediate route. No new renderer prediction or last-known-marker UI is required by this design.

The world profile selects broad and detailed periods on one aligned world phase per rate. Only dirty scopes or genuinely unfinished admitted work enter the sensory due index. A clean completed observer has no recurring sight job and no per-period write of an empty next-due record. When new work appears, compute its next aligned opportunity from the saved world epoch and selected policy; initialize first exposure through its normal acquisition boundary. Actual time-dependent sensory laws still register their own next due boundary: illumination changes, signal accumulation/dwell, detector/source/support expiry and capability changes cannot be skipped because no body moved. Priority/clear deadlines and bounded discovery continuation likewise retain their existing owners. They create the work required by their law, not a blanket poll of all observers. Preserve unconsumed due/phase state on restore; rebuilding a disposable index creates no observation, expiry extension or synchronized catch-up burst.

Due broad work discovers sources and updates cheap admitted detection/classification/placement plus actually available recognition cues. Recognition is not restricted to already detailed subjects; reuse unchanged acquired exemplars and rerun only for changed evidence quality/correspondence/personal support. Due detail work visits the selected track set. Do not duplicate detailed pose samples through the broad path; entry/removal and changed membership still update the one current view. Fair discovery may request one eligible source’s supported description without a prior interest match. Broad acquisition includes its declared minimum outward/rendering cues, so unattended bodies remain presentable. The native field mask comes from that minimum, selected detail and actual admitted source/inspection/action work. Rendering, inspector panels and model expansion only materialize already granted exact values; a missing field stays unavailable. Additional evidence requires a supported native acquisition through its existing action/perception continuation, never a new read-triggered queue, off-cadence sample or latest raw-source lookup. An existing received-field read is not a new acquisition. Animals consume the same supported sensed primitives through their controllers without mandatory human history or thought.

Actual speech, contact, effects and source starts/ends keep their source-specific time and causal order. Their source owner admits recipients and supported associations at that boundary; a later batch cannot reconstruct reception from newer poses. Dirty coalescing applies to recomputation metadata, never already admitted occurrences: one publication can carry several ordered acquisition frames. Physical action checks grant no extra visual observation. The [pre-outcome cut remains capture-only](vision-and-gaze-tech-design.md#95-capture-only-turn-observation-and-strike-order): independently due sensing completes first; the cut requests no extra sample and outcome evidence follows it.

Optional formatting and AI do not hold the completed native boundary. Additional fixed phase buckets need measured burst-latency benefit against reduced source sharing. Acceleration advances game-time periods; pause stops them. Host yields do not skip required admitted samples. Brief appearances wholly between broad opportunities may be missed. A door opening and closing between them cannot grant an intervening glimpse or false continuous support. Validate the chosen resolution through ordinary doorway, crowd and animal play rather than treating arithmetic as gameplay acceptance.

### 4.2 Contextual terrain instead of a ground diary

Keep physical geometry in its existing map/support/solid owners and compiled spatial indexes. Replace observer-centred ground subdivision/recertification with selected **physical features**: visible support surfaces, solid outlines, boundaries, volumes and authored landmarks. Merge compatible planar geometry through existing preparation; never merge differing properties, holes or levels. Features need stable source/revision bindings, not new world entities.

Acquire a bounded personal feature view for self/current task, changed attended anchors, world-authored salient landmarks and explicit inspection. Independently due native context completes before relation cues and optional cognition. A capture between opportunities uses existing permitted coverage and unknowns; it schedules no extra geometry acquisition. The selected world admits cue anchors from detail, self and actual work/required-cause targets under its shared relation budget; broad regions supply context without automatically creating a cue for every body. Detailed body slots cannot consume the whole static-context allowance. The world allowance bounds the aggregate selected current feature view, including reused and new variants. Reconcile/prune that union through the existing fair anchor/region selector; release superseded selections unless an independent recent/required or other current consumer owns them. Omission is partial context, not sensed loss, and does not limit broad body visibility or a producer’s required cohort. Do not traverse every ground patch, and do not re-record features when attention membership changes. Ordinary uniform support needs only the current received support/elevation answer; it creates no terrain history unless a retained observation, contextual query, place or required consumer actually needs that geometric fact. Prefer stable feature-local received extents already covering the requested neighborhood. Moving a query box must not automatically create a new polygon/fact: reuse a still-certified extent, derive distance from the new body sample, and acquire a different extent only when the consumer needs newly covered geometry. This prevents query-local clipping from becoming the old patch factory under a new name.

The sense producer still clips visible extents and supplies uncertainty. A full shared polygon may be used only if its emitted extent was actually received. A range/occlusion boundary is a coverage limit, not a cliff. A drop measurement needs received near/far support; unseen terrain is unknown. Native route/physics queries may have their own permitted physical inputs, but cannot expose their hidden map to a personal context reader.

Context selects bounded nearest/support/boundary reads around anchors using existing indexes, early feature-family filters and conservative distance bounds. The spatial index offers best-first node and leaf-entry traversal using actual anchor distance, with receptor-range rejection before expansion. Its existing 64-path retained frontier reports truncation as partial coverage. The selected world orders support surfaces before solid faces; give each physical source one useful extent before additional extents. A fully receptor-contained finite feature needs one certificate rather than artificial tiles. When a solid blocks a feature, project its conservative shadow onto that feature to propose outside pieces first; fully certify each piece against all relevant occluders. Degenerate projections use conservative bounded subdivision. Reuse an unchanged certificate only while its source/view and explicit observer/global invalidation proofs remain valid; a shortcut never refreshes measurement time. Include the existing supported native-cue anchors and coarse broad-region context, not only individually detailed bodies; a relevant received ground boundary must not depend on winning a body slot. Union/deduplicate candidate features and requested local extents across anchors before expensive sensing. A certified extent can serve several anchors without repeated clipping or another personal record. For each candidate, intersect the query-local region of interest with its physical feature, receptor view and range. Reuse the physical owner's finite convex decomposition; certify each emitted interior against all relevant intervening occluders, not just polygon corners. Split only query-local ambiguous pieces within the installed geometry work/error bounds. Uncertified fringe or exhausted work stays unknown. Bound candidate/index/occluder visits, clipping operations and output bytes; do not preserve an unfinished whole-field-of-view rectangle grid. A very large floor with one blocker must neither reveal its hidden extent nor disappear wholesale when a visible local piece can be certified. World policy owns useful terrain/material/landmark distinctions and which native activities request them: concealment, cover, elevation, food or route context are examples, not engine scenario rules. Existing thought can choose an explicit supported focus/query; do not parse an arbitrary personality into an object catalogue each sensing step.

Store a feature's neutral geometry once per exact received variant and its personal acquisition/validity interval once. Historical context joins personally retained sample times with those intervals. It never attaches all terrain to each person or fills old gaps from today's map. Required place knowledge or a chosen lasting recollection retains only its minimum support. An inferred kitchen classification is a supported personal belief, not automatic knowledge of the author's room name.

### 4.3 Lists, cohorts and downstream reuse

Extend existing indexes rather than cache arbitrary arrays keyed by whole-world identity.

| Consumer                   | Required query/invalidation                                                                                                                   |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Root/entity capacity       | O(1) maintained root/entity counts; indexed ID iterator only when actual entities are needed                                                  |
| Sensory participants       | Installed eligible observer membership; change on life/sense/role, not every clock tick                                                       |
| Moving/action participants | Existing active action/motion membership and due boundaries; reuse within the native batch                                                    |
| Status/rates               | Existing participant and definition preparation; touch affected/due actors and actual changed values                                          |
| Animal decisions           | Existing eligible/controller/due-work index; changed food/threat/body inputs invalidate relevant choices                                      |
| Attention                  | Cache description, familiarity, spatial score and priority expiry separately; recompute changed components and final selection only as needed |
| Public/UI views            | Changed personal pose/support/identity/control sections; optional inventory/trade detail only for its actual open reader                      |

Published point indexes coalesce changed IDs across unread publications and prepare them only when consumed. The existing persistent ordered tree copies changed cells once per consumed preparation; native working batches use a changed-only overlay. Current entity records resolve against the exact current collection, while older bindings remain isolated. Existing numeric tree aggregates maintain body/interaction maxima through growth, shrinkage and death. Structural membership/order and installed shape-policy changes rebuild safely; ordinary needs or position writes do not rebuild every unchanged body. Immutable read-only root lists share their exact entity collection and reject container mutation at the type boundary; writable/draft/foreign reads stay fresh.

Counts update atomically with insertion/removal/root membership, including custody changes, death/body-role changes where applicable, raw construction and restoration. A derived index has one rebuild at a real load/foreign-input boundary and exact owner deltas afterward. Its absence is not an empty world. Preserve existing deterministic order where iteration matters; do not create a fresh list merely to get its length.

A sensory deadline must not trigger unrelated status/action/controller preparation for all 163 records. Reuse installed definition preparation and the already existing elapsed-value machinery; do not introduce a universal future-event predictor or a second rate engine. Animal/status scans were secondary in the measured tiny world; their redesign is precise reuse, not a claim they caused most of the slowdown.

## 5. Seal once and account for ownership incrementally

### 5.1 Immutable publication

Retain one private working world per native batch and the last completed world for readers. There is already no world copy per actor. The host's 50 ms wake, native game-time sensing deadlines, coherent publication, durable progress-save cadence and optional network delivery are different clocks. The 905 current-map copies and 3,644 sealed evidence-owner structures in the diagnostic run were in-memory containers; they were not that many database saves.

Apply all actor/source changes to the same writer. Publish only on a coherent boundary, coalescing within the existing yield/return policy. Seal new leaves once, freeze the changed container once and reuse proven immutable children. No full history traversal for a pose update. A nested preview captures only the finite data its reader needs; it must not freeze a parent's working buffers or force an entire interim world publication.

Nested commands retain isolated copy-on-write children and their ordinary fallible admission. Foreign or editable builders retain ordinary completion. This is the existing draft owner’s boundary, not another transaction engine or a caller-supplied permission flag.

Use the existing owned-builder/lineage mechanism. Do not replace the whole engine with an ECS or add a persistent-map library before the compact row/chunk conversion is measured. Large append history belongs in immutable bounded segments with a small current tail; a pending model/save/view job never retains a chain of old worlds. Foreign/raw/restored values retain full current-format validation. A shallow freeze or a boolean “trusted” flag is not proof of safe children.

Pure bookkeeping publication preserves the existing native interval and proven derived sight/continuation bindings through the ordinary completion owner. A cleanup/pressure change must not silently discard those proofs and force the next game step to rebuild unchanged inputs. Pure current-evidence reads resolve latest owned containers without creating writable draft children; they cache no mutable-world authorization.

The selected world owns that retention tradeoff; the engine still supports exact partial retirement for age, correction and forgetting. Stable ordinal coverage includes explicit retired slots where the logical model permits them. Preserve the existing actor/source/life/time fences and metadata/preparation limits. ### 6.1.1 Page checkpoints and exact selection

Here a temporal page is one bounded logical chunk, under the existing 64 KiB allowance, not each physical suffix sealed at a save. One logical acquisition frame may span chunks at complete operation boundaries. Its actor/life/epoch acquisition identity and operation/field ordinals are independent of chunk or segment placement; repeat only the compact context needed to decode each part. Admit/publish the acquisition atomically under the existing complete-batch allowance, keep each indivisible event whole, and count repeated headers/checkpoints in bytes. Neither chunk size nor fragmentation grants a larger acquisition budget.

Cold selection filters actor/life/epoch, local subject, time and retention class before decoding selected chunks. Fetch each selected chunk's checkpoint and the ordered suffixes needed for its requested range, charging all fetched bytes and replayed entries to the existing preparation limits. Replay never walks an unbounded chain of earlier chunks. A checkpoint is historical reconstruction state, not a new measurement or renewed memory. Partial prefix expiry keeps only the minimal baseline needed to interpret the retained suffix, with original times; baseline-only references are not independently searchable earlier history or motion endpoints outside admitted coverage, and support must cover the requested retained time. They cannot reveal earlier removed samples or keep prior chunks alive. Exact event and personal fact addresses remain stable through pruning. Correcting an original fact reaches carried checkpoints and dependent capsules through the shared dependency visitor.

Use one codec/materializer for current capture, recent/history queries, required support, save/load and source correction. A 128-item query may not hide thousands of changes inside 128 frames. ### 6.2 Acceptance and background application

Reuse the existing [durable journal](performance-overhaul/journal-contract.md), world mutation lane, application worker and read fences:

1. Enter the mutation lane and validate the command and authority against the current world.
2. Complete its required native transition, including exact admitted personal frames and earlier unsaved native progress covered by this save. Seal only changed leaves and capture the expected durable predecessor.
3. Prepare compact changed records, receipt/source plans and new suffix segments. Reuse validated column extraction and encoded values; do not immediately decode the encoder's own output and repeat its complete validation.
4. In one short database transaction, check mutable authority, world/generation/predecessor, command receipt and applicable real constraints; durably append the complete exact change description and receipt and advance the committed revision.
5. Only after successful COMMIT, install the accepted candidate and acknowledge it. Release mutation ownership so the world and subsequent commands can continue.
6. The existing worker applies accepted changes in order to ordinary tables and optional indexes. Completion advances applied coverage. **It never reinstalls the older captured world.**
7. Table-backed readers fence to their captured committed revision, then verify generation and applied coverage in their read snapshot. Wait outside the world mutation lane; recheck any authority/action prerequisites before using a delayed read to mutate the world.

Native progress already continues during a background progress save. Preserve that owner and its honest durable coverage. Do not release the current command save's lock around its existing await: that code subsequently installs an old captured candidate and could overwrite newer simulation. The selected fix is a shorter durable barrier, not published speculative command effects or rollback descendants.

### 6.3 Bounded proof-based admission

Keep the existing 512 indexed constraint-probe ceiling, 32 unapplied revisions, 32 MiB encoded debt, one worker and at most eight accepted revisions per online application batch. The selected change is to stop treating every safely owned append row as an independent unknown SQL constraint, not to raise the limits.

Unknown/destructive families keep the existing synchronous atomic writer until their semantics are explicitly covered. The record schema may explicitly identify a collection whose entire canonical membership stays resident across saving, compaction and loading. For such immutable collections, the codec can prove new identities absent from the exact accepted predecessor and derive unique final positions without SQL re-probes. Apply this to current perception collections and capture watermarks; never infer completeness for cold history or shared-value pools. Keep contradictory pending identities, positions and ancestor deletions checked even when SQL is unnecessary. Foreign baselines, mutable collections and unsupported constraints retain full admission.

Separate **physical reclamation of unowned payload** from semantic correction/forgetting. Ordinary command preparation nominates candidates and applies logical owner changes; it does not perform cold ownership proof. Section 5.2 moves that exact proof and physical pruning to bounded existing maintenance/application work. Semantic source withdrawal and privacy obligations retain their own atomic admission/fencing. Preserve delivered append-admission proofs; do not special-case movement or treat an unverified candidate as a proven delete.

Only the semantic owner's prepared object can carry reusable validation proof; no public boolean bypass. Persisted journal recovery and foreign/current-format input receive full validation. ### 6.4 Bound pending memory and recover exactly

After preparing complete application inputs, pending entries retain changed records, exact personal source plans and small revision metadata. ### 10.2 Measurements and pass conditions

A genuine support discontinuity splits the witness run. Attended chronology records one availability operation, not one event per field. Hearing can continue while sight ends. Ordinary source/receiver movement can schedule checking without fabricating loss. No automatic lasting memory or paid thought follows.
5. **Attention entry/exit:** automatic allocation and explicit admitted focus use the same owner. Entry captures a reference baseline of already acquired groups with their old times, then requests only legitimately due/missing detail. Exit captures any just-received change before releasing future detail. Earlier personal retained evidence is accessible; shared payloads never reconstruct an unattended route. Selection, acknowledgment and loss are different transitions.
6. **Correction/forgetting:** revoke the addressed original source/group mask and its actual dependent current, recent, retained, recognition and text support atomically. A correction of one field must not revoke unrelated siblings merely because they share storage. Share immutable bytes across observers while keeping separate permitted references; forgetting for one person cannot erase another's still-owned knowledge. In-flight reads/effects carry existing world/control/life/privacy and selected-source fences; after a wait, an old result is rejected or narrowed only through the common permitted reader. No stale completion can reinstall revoked groups. Use the memory/storage owner’s indexed dependency selection; do not introduce a second ownership mirror or scan all actors on every update.
7. **Save/restore:** persist current contacts, meaningful attention annotations, ordered recent frames/check runs, selected support, pending sensing boundaries and native continuation under the existing save/checkpoint owner. Rebuild score heaps, spatial/query indexes, candidate views and lookup maps from this authority. Rebuilds do not sense, refresh timestamps, acknowledge discovery, redraw RNG or rerun actions. Current-format validation checks referenced masks, complete group membership, monotonic real checks, life/source ownership and permitted payload shape. Reset incompatible disposable development data; provide no old-format reader.
8. **Retention:** preserve existing recent byte/age bounds and optional recording admission. Normalize current groups so old receipt versions leave with their last current/history/support owner. Ordinary detail can disappear; useful accounts require actual existing memory admission, not automatic summarization of every route. Semantic rejection is immediate; physical cleanup remains bounded and later. Shared payload ownership does not imply a bound on independently retained world events, meaningful memories or accounting.

**Literal freshness example:** a coat and face were acquired at time 100; a position is measured at 110 and 120; coat detail was last actually checked at 110. Current contact references the original appearance group with coat-check 110 and pose 120. A broad position check at 130 updates only its covered pose/presence group. A later exact reader derives those separate times from group membership; it does not iterate/update the coat at every pose check. If the producer genuinely checks appearance too, one covered appearance-group stamp advances. A partial coat correction splits that mask while the face remains supported.

### 13.4 Selection, preparation and asynchronous boundaries

Selection must reduce expensive work **before** its construction. The broad producer emits received presence, supported placement and minimum outward/rendering cues; rich inventory/description/attribute detail follows existing detail/inspection policy. Native urgency consumes actual signals directly. Candidate ranking reads compact contacts, authored cue inputs and permitted familiarity; it does not instantiate every possible description and proof. Keep one disposable priority structure per current contact-owner revision, update changed keys and expire actual due causes; use existing attention machinery, not a second scheduler. A cold build visits contacts once. Work/focus or policy changes may legitimately rescore all relevant contacts. Deterministic tie order and discovery progress are persisted inputs; cache layout is not.

Do not silently remove first-seen order, acknowledged versions, displacement anchors or cue expiry as “cache”: they affect selection. Conversely a preformatted description, geometry JSON signature and computed score have no independent gameplay authority. Context/UI expansion reads only received groups; unavailable detail remains unavailable. Model requests retain finite exact selected evidence through the existing cut, byte and lifetime limits, including the reachable payloads of shared references. A cheap root pointer must not pin an entire world or unlimited old contact versions. Broad coverage can use existing scoped region aggregates and bounded expansion; no aggregate asserts a shared motive or hides that detail was omitted.

| Boundary                                                      | Work and sequencing                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Before physical progress crosses a consequential boundary** | Settle ordered physical effects, collisions/contact and installed native reactions; actual sensory classification must establish receiver membership, masks, times/order and minimum required received state. Cheap native cues and attention decisions needed to decide this acquisition's retained detail complete here. Accept the compact evidence needed for consequences and sampled chronology with the native prefix. Yield host I/O between coherent prefixes; a yield does not permit later world geometry to rewrite an earlier receipt. |
| **After accepted progress, through existing lanes**           | Rich evidence materialization, wording, player packet preparation, optional cognition/recall/consolidation, derived search indexing, eligible database saving/application and physical reclamation may finish later under their existing fences. Coalesce replaced presentation requests and dirty scopes; preserve all admitted occurrences and selected changed samples. Durable command acknowledgment still follows acceptance.                                                                                                                 |
| **Possible later sight offload**                              | A bounded worker may calculate exact geometry against captured immutable phase inputs. The current world still waits at a native dependency if that answer can change a reaction. Letting the world pass an unresolved consequential sense requires rollback or an explicitly different delayed-reaction law. Neither is selected. Pure optional formatting is the first async removal; scheduling the same field loops on another thread is not a structural saving.                                                                               |

Cognition latency already need not stop the world. A late interpretation uses its captured sequence plus current action preconditions; it cannot backdate a warning or insert an action before already committed motion. There is no new recurring three-second AI call. Required bodily/native responses still act before optional interpretation, while a parent may miss the personal significance of a novel danger. These are distinct gameplay promises.

Cadence alternatives remain explicit: moving 20/10 game seconds to 40/20 would halve maximum opportunity frequency at the same normal clock, not necessarily total CPU; it doubles nominal broad/detail sampling delay from roughly 333/167 to 667/333 ms and can miss brief events. Source changes, event timing, actual producer laws and native constraints still matter. Keep 20/10 for representation comparison; consider tuning only after the measured remaining cost is actual sensing and play demonstrates acceptable misses. Do not use a slower setting to relabel the original acceptance pass.

### 13.5 Growth, expected benefit and limits

Let `P` be actually admitted observer/contact pairs, `T` tested spatial pairs, `F` held field variants per contact, `G` distinct received/check groups per contact, `K` detailed subjects per observer, `C` actual check opportunities and `D` changed received values. Typical `G` may be much smaller than `F`; that distribution is **unmeasured**. Worst-case independently timed fields have `G = F` and cannot be compressed without losing meaning.

- **First exposure:** geometry still costs the tested pairs `T`; a mutually visible crowd can still require quadratic reception work. B allocates `O(P × G)` small group references and `O(P)` contacts/selection metadata, plus shared distinct payloads and actual recognition/control knowledge. Preparing distinct source payloads still visits their actual fields once; receiver-specific partial sensing can still require field work. Reusing a group mask is only valid when its receiver-dependent support has been established. Required accounts remain separate. It removes independent current-field/original/grant/candidate/exposure persistence where those are administrative views of the same contact. It does not promise to delete every row in those measured families: channel/required-source mappings must be inventoried.
- **Routine play:** source preparation follows distinct changed source variants. Current mutation follows changed contacts/groups; selected history costs `O(C × observers × K × G + D)` rather than walking every selected field for each successful check. Regular unchanged check runs may reduce stored checks further, but pose changes remain actual samples. Group masks are reused; deriving them by scanning all fields each time would defeat the design. Contact path-copy work is logarithmic in owner size; creating a new whole observer map or whole-contact history blob is forbidden.
- **Readers/correction:** field-level expansion is proportional to selected disclosed/corrected fields at consumption, with exact cold selection first. Public movement updates project changed contacts rather than expanding every current field before narrowing. Optional context construction does not make every sensory boundary pay its cost. Large real correction closures can still cost proportionally to affected retained evidence.
- **Long life:** active/grace contacts depend on current surroundings, not total lifetime encounters. Recent history is quota-bounded; lastingly retained identity/knowledge/support keeps its own existing limits and explicit ownership. Transient candidates leave with contacts; completed queries/jobs release references. Ten years of walking does not require ten years of current contacts, confirmation records or model summaries. This is not a total-database bound or a guarantee of six hours of exact history at every activity density.

Logical fields represented may remain numerous even when a group operation handles them once. Distinguish represented-field totals from group operations, actual field materializations, allocations and prepared SQL rows; a smaller counter obtained only by renaming it is not evidence of less work.

Measured support for prioritization: the five current/candidate families account for 83.07% of the crowded save's payload characters; selected recording and record/publication preparation are substantial normal-run CPU owners. Those are removable-work targets, **not** an 83% CPU saving or predicted frame rate. The same source already reuses most descriptions and shared values, and dense temporal packing is small: another codec tweak cannot explain away the dominant first-exposure cost. B also reduces objects traversed by immutable sealing and canonical diff preparation. Exact savings, mask distribution, reader expansion frequency, cold rebuild time and remaining physical cost require later bounded measurements.

### 13.7 Recommendation and uncertainty

Rank structural work by expected impact and confidence, not a claimed speedup: **(1)** remove current-field/original/grant/candidate row fanout with contact-owned state (highest confidence for dense acquisition); **(2)** remove selected per-field confirmation construction/checkpoint expansion (highest confidence for recurring normal history); **(3)** keep only meaningful attention state and materialize selected current evidence at consumption (strong source evidence, magnitude unmeasured); **(4)** carry exact changed contacts/groups through immutable publication, ownership and canonical writes (required to prevent the first three savings from reappearing downstream). These are parts of one conversion. Async preparation may reduce blocking afterward; it is not a fifth elimination of CPU. Actual physical/status work remains, including the measured status-rule/animal-eligibility visits; this design does not claim those scans are necessary in every case or already optimal. Their owning cohorts should be reassessed only if the post-removal trace shows them dominant.

Recommend **B**, implemented through the focused stages in PS04-A. A is a bounded fallback if the contact conversion cannot be completed coherently; C is deferred because always-active native/render consumers weaken its premise. Keep existing semantic mutation owners, spatial indexes and event/correction owners; follow the separately selected shared-value/save layout rather than preserving its superseded internal machinery. No protocol compatibility layer or duplicate old store remains after each delivered conversion.

The recommendation depends on these constraints: genuine observer differences and independently timed fields cannot disappear; native danger/recognition state has meaning beyond a cached candidate; a compact contact is not one unbounded blob; masks and exact check sequences cannot be reconstructed by field scans or fictitious continuous sight; required source capsules must not pin sibling facts; transient caches need cold reconstruction before use. The design therefore uses exact group exceptions, minimal persistent selection annotations, changed-key storage and existing bounded chunks rather than a universal shared-scene authority. These are release checks, not permission to relax the cases above.

No new product choice is required to compare B at current fidelity. Unresolved engineering evidence is `G/F`, the required-source versus redundant-original breakdown, transient-index retained bytes, restored selection equivalence and complete native/SQL cost. Broader cadence reduction or async consequential sensing would be a separate gameplay decision; neither is a hidden prerequisite. Future vision/acoustic producers and full PP07/SAI-A remain in their existing trackers. Designs are complete for this comparison; implementation and performance acceptance are open.

### 13.8 Smallest validation and stop conditions

These checks are a future implementation plan, not runs performed for this design.

1. **One deterministic connected comparison per converted owner:** actual ordinary movement plus dense first exposure, current/captured/retained/cold views and the scenario matrix above. Count fields expanded, group checks, contact writes and encoded rows at the actual caller. Require zero unchanged per-field confirmation allocations in the grouped path, no persisted derived candidates, no new opacity/privacy/loss defects and no missing intermediate attended samples. Use existing tools/disposable scenarios; no new unit suite or paid AI is requested.
2. **One first-exposure census before another long campaign:** preserve the previous substantial fixture's populations/settings; compare complete acquisition and canonical preparation, not just SQL encoding. Report remaining row families/bytes, group sizes and exact/partial-check distribution. If per-field expansion still occurs upstream or the same rows reappear as index/checkpoint entries, stop and repair the owner before measuring throughput. An overloaded warmup is a failure, never a steady-state number.
3. **One normal five-minute OFF run after integrated removal:** same actual movement/animal/speech/recording conditions and current defaults, with existing command/debt measures. Required normal gate remains ≥0.98 with its existing responsiveness/debt conditions. Use a single bounded CPU/write capture only if a remaining failure needs attribution. Do not repeat unchanged runs seeking a favorable result or begin another full ten-case matrix before the standard and one substantial workload can complete.
4. **Cold/age and scaling only after those removals work:** one same-format save/reopen with pending correction and partial support; one current-cap fill/retirement/rebuild case with allocator/heap/reference checks. Reuse valid prior evidence where the changed owners do not invalidate it. Then run remaining SR04/SR07 density, fairness, faster-clock and long-lived-owner qualification under their actual pass/measurement contracts. Hundreds of active characters remain a target; dozens passing do not qualify hundreds.

Stop structural iteration if the required removal counters are achieved but native sensing/status/physics now dominate and standard speed still fails: report that new distribution before another architecture change. Stop immediately on knowledge leakage, stale-read disclosure, lost required support, incorrect native ordering or unbounded deferred debt. Bigger batch limits, more CPUs, longer admission deadlines, smaller memory allowances and slower world time are not substitutes for these checks.
