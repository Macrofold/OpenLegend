## Why this may matter

The third combined compromise observation takes104.0seconds in native advancement and59.9seconds in saving over185seconds. Those spans overlap and are not additive CPU shares. Only46 of380 saves use deferred acknowledgement. Saving currently materializes every retained ordinary meter/episode/work calculation, then installs that materialized world as the next live world. This can undo both shared arithmetic and an unchanged native forecast. The proposed saving change must demonstrate that cost through a finite actual-service sequence, not infer a causal percentage from the complete observation.

There is also a confirmed added database barrier:1,026 queries check whether saved query tables have caught up, totaling9.05seconds of overlapping await time. Some are needed for consistent read snapshots; a writer already holding the primary serialized PostgreSQL lane can use its existing exact committed/applied metadata instead. It must not infer that guarantee outside that lane or apply it to the independent reader connection.

## Growth, sharing and invalidation

Cost grows with saves × actors/meters/episodes and forecast rebuilding, plus retained-window replay. Reuse the single existing window and its current-value/episode/accounting owners. Store its bounded scalar operations and exact identity bindings once. The64segment limit and actual rate/threshold/definition/work invalidators still materialize earned values. Do not let a save create a second stale baseline or silently change subtraction/addition order.

Preparation shared across pure projections is owned by the native engine. Equality must cover entities, current arithmetic, rules, maps, participants, resource/deadline owners and all future unknown roots. Retained history alone does not change a captured mechanical forecast; actual events and their mechanical effects already ran before projection. Replacing an entity or losing the proof rebuilds. The process-local forecast is discarded on reconstruction; canonical arithmetic survives because it is ordinary current data.
