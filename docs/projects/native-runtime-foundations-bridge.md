## Boundary and evidence

Rust owns accepted live state, candidate mutation and rollback, perception, executable choices and final source checks. TypeScript owns sessions and grants, permitted presentation and model requests, spatial and language providers, scheduling, PostgreSQL and transport. A player can keep walking while an NPC considers a reply. The NPC still answers from the evidence it was allowed to use, an observing tab still receives its own permitted update, and the server saves what actually happened. For the proposed stand-alone path, follow the [Rust server ownership and comparison design](rust-game-server-tech-design.md).

Three different lifetimes recur across the interface. An accepted read identifies what a caller may inspect at a particular point in world time. An independent reader, worker, database transaction or transport can retain a product past the original call. A synchronous disclosure lease authorizes handing a particular result to its recipient. Reusing prepared bytes or an immutable lookup never extends a lease, advances a read to a newer point or supplies another recipient's permission. Keep storage admission ahead of allocation, a charge covering each live allocation, and independent custody for every reader. Preserve cancellation, fatal poison handling and exactly-once execution on the admitted lane. The current 2 GiB transient profile has separate resident and pending-save accounting.

The [bounded diagnostics](../maintainers/native-simulation-core.md#bounded-remaining-cost-diagnostics--november-12-2026) recorded 7,563 Rust count/emit pairs, 183,088,457 emitted bytes and 58,776,966 joined bytes. The categories overlap. The Native run advanced 2,999.401 game-seconds before refusal, versus 5,997.860 for Source. The [later repair comparison](../maintainers/native-simulation-core.md#recorded-destinations-and-received-terms-repair--november-13-2026) finished all three repaired runs at a median 6.983 combined CPU ms/completed game-second and no qualified controls. It also left unclassified transient bytes at shutdown. The earlier [outgoing player-encoder experiment](../maintainers/native-simulation-core.md#conditional-player-encoding-comparison--november-11-2026) measured a 19.9% reduction in Native combined CPU in its two completed matched pairs. That result belongs to selecting a patch before encoding it. None of these campaigns prices the five changes below. Priority follows directly demonstrated unused work and number of callers. CPU ranking, RSS improvement and clean shutdown require measurement.
