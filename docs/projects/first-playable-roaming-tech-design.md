## Scope and baseline

Implement the [feature specification](first-playable-roaming-feature-spec.md) and [authored profile](../worlds/base/first-playable-roaming.md). Source baseline is local `main` and `origin/main` at `0543f9ec61301240c5c4ec3cd007063f4f1c25d6` in `https://github.com/Macrofold/OpenLegend.git`. That baseline has wandering/fleeing animals, an independently implemented territorial stag, humanoid rivals, finite resources and physical navigation. Ordinary wolves/bears have no installed predation/pack controller. CTR's new all-danger escape and SPK's speech model are designed dependencies, not delivered facts.

Extend existing owners. No new simulation loop, encounter service, NPC scheduler, shared mind, world-history scan or all-purpose behavior scripting language. The chosen finite forager family is trusted TypeScript under the base world package. Geometry, attributes, evidence, actions, custody, death, work accounting and persistence remain generic shared services. This is a deliberately narrow animal-mechanics extension with a documented family contract, not a claim of general ecological intelligence.

## Animal state and installed definition contracts

Use the existing saved animal component, replacing overlapping legacy flee/patrol fields together when CTR/RW integrate. Do not maintain a compatibility copy. The current representation must express:

- Exact installed behavior profile pin and optional authored pack relation ID; membership is a relation, never access to packmates' private current facts.
- One current mode: routine, resting, feeding, regrouping, stalking, pursuing, searching, escaping or blocked. Mode is a controller phase, not an independent action effect.
- Chosen destination and its provenance: known habitat anchor, currently perceived resource/body/packmate, or last observed position/time. Retain supporting surface and expected body/geometry dependencies. Discriminate the current choice by mode: a regrouping choice binds the personally seen companion/life and its observed point/time, original leg deadline and actual leg distance; a hunting choice binds its quarry and original pursuit limits. These reuse the one route/work record and are mutually exclusive, not competing saved destinations.
- Exact target entity **and physical life** when applicable, current evidence reference/time, chosen attack/action ID and original commitment deadline/travel allowance.
- Saved route/corridor or the existing route-request identity; distance actually traveled since pursuit began; next review/deadline; last failed candidate/dependency key; original cooldown end. A regroup leg uses these same route/deadline fields, with the personally seen packmate/life and observed joining point; it has no shared pack route or second position writer.
- CTR's retained danger evidence and refuge state under its existing owner; do not duplicate it in the new mode record.

The optional `anchorFood` array retains at most one suitable source per familiar anchor: anchor index, source identity, observed food-definition pin and occurrence time. Absence means no retained positive food observation. The existing local visible-food preparation updates it, even when the animal is fed; a newly seen unsuitable or empty source removes its matching observation. Historical sources may move, deplete or disappear unseen without invalidating the saved observation. Routine selection prefers eligible observed-food anchors before its ordinary saved random draw; actual feeding still requires current perception, access, stock and native admission. Current-format validation checks unique in-range anchor indices, exact pin shape and nonfuture observation times, without resolving hidden current source contents.

Authoritative state retains only the selected work and bounded current evidence. Derived nearby-candidate lists, navigation meshes and lookup indexes are rebuilt. An animal target is not required to remain alive for historical evidence to remain valid; an **active attack** requires its exact current live target. A retained pack identity does not require all members to be alive or resident in memory. Public/actor-facing failure wording cannot disclose an unseen death, replacement life, hidden blocker or changed private stock; use a truthful unavailable/current-route explanation when the actor lacks the cause. Authorized diagnostics may retain the exact mechanical cause separately.

The installed status-effect night-rest predicate consumes `nativeForagingActive` as a read-only current fact for admitted feeding/stalking/pursuit/search, including moving preparation and a still-admitted cooldown pursuit; profiles with no forager episode resolve false. The ordinary night branch requires both `nativeResponseActive == false` from CTR and `nativeForagingActive == false`; neither replaces the other. This suppresses ordinary automatic night Sleep while actually engaged, without defeating exhausted rest or CTR alarm waking. Regrouping and routine awake idling supply no exception and no separate energy effect. Actual Sleep retains its perception/action restrictions and full-energy completion.

The forager compiler receives typed profiles and returns a fixed set of bound rule/strike/consumption definitions. Configuration references existing installed species, numeric need attributes, food properties and physical capabilities. Current-format validation rejects a categorical need reference before the controller can become unusable. A world can omit this family entirely. A meaningfully different verification fixture uses a non-hostile charge-powered scavenger that consumes exposed charge cells, never hunts and has no pack; reuse the same optional need/routine/physical-route interfaces without raw-meat, wolf or night branches in shared code. It is a fixture for the contract, not new bundled content.

## Metabolism and diet integration

The current `wilderness:metabolism` status applies −0.003 to every conscious actor with fullness. Merely binding fullness to animals and adding another rate would double-deplete them. RW01 replaces that single applicability with disjoint conditions and generates the three animal rates from ecology.yaml through the existing status-effect operators. Human/default fullness stays −0.003; prey, wolf and bear get exactly their one selected rate. All retain the existing conscious requirement: alive and not incapacitated. No native controller also decrements food.

Add the narrow read-only status field `controllerProfileId`, returning the installed native controller's exact profile ID or the empty string when no native profile is installed. It is derived from the authoritative profile pin, never a writable species flag or private belief. Register/validate the field through existing condition preparation, authoring schemas and current-format validators. World YAML compares this field with its authored profile IDs; shared status code contains no wolf/bear names or rates. The default metabolism's condition excludes the exact installed animal profiles; each new animal metabolism requires its own profile, fullness and the existing conscious condition. On a permitted profile change reconcile old effect applicability before another time interval, so an eligible conscious actor has exactly one active depletion effect. An actor that is dead or incapacitated correctly has none. Existing zero-fullness starvation remains shared and unchanged.

The raw-meat source currently has no numeric nutrition. Add 24 to its single base item definition; diet-specific human refusal remains authoritative even with that property. A prepared menu/model choice cannot call it human food merely because nutrition is positive. Predator feeding reads that same value for exposed items and corpse yields. Pasture's nonportable in-place definition belongs to ecology.yaml and is registered through the existing resource/consumption owner, with nutrition 30, finite source units and no ordinary gather-to-inventory operation. The opening owns its three coordinates; there is no duplicate human recipe/source row.

## Perception, choice and action sequence

1. At an existing native boundary, determine whether a relevant deadline/change makes this animal due. Read its current body, action, attribute values and observer-scoped perception snapshot once.
2. Reconcile unavailability, exact action/life, prior continuation and CTR danger. A fresh attack first uses the existing cancellation owner and CTR escape. Already released effects are not erased.
3. Build eligible candidates from conservative **local** spatial exposure, then apply actual sight, food, body and policy predicates. Known habitat anchors may be offered as remembered static places without asserting current contents. There is no global nearest-prey query.
4. Evaluate the authored ordering against read-only facts. Reuse actor/profile prerequisites across targets. Preserve the existing choice if its relevant conditions still hold. A cheap update of a remembered position does not force pathfinding.
5. Prepare direct movement or bounded corridor work through the existing navigation owner. Pending preparation leaves a truthful waiting state. The controller may maintain a still-valid old route, but cannot invent a safe result or advance along an invalid one.
6. Serialize choice commitment at the existing canonical native order. Revalidate dependencies, spend only the required saved random draw, and install ordinary movement/feed/strike work. Asynchronous preparation callbacks never mutate the world or draw randomness.
7. Advance through the common motion/action owner, including perception/collision crossings. Count actual traveled route length, not straight-line distance or requested movement. Native time slicing and partial interval state remain under simulation-time.
8. On completion/failure/cancellation, record actual occurrence, location, target/life, quantities and cause. Trigger only affected future decisions and projections. No mandatory paid narration accompanies animal movement.

A route ending at a last-seen position gives no live target authorization. Search points must be in exposed terrain; exact unknown topology may refuse a route without teaching the animal hidden map facts. Read the full CTR escape algorithm rather than approximating it with RW's six approach points: escaping and hunting solve different questions under one movement owner.

## Moving contact strike

The current strike owner stops approaching before its stationary work period. The current `approachRange <= range` invariant therefore cannot represent the selected wolf attack: a preparation starting 4m away must move before attempting actual contact at 1.2m. Do not loosen that existing check globally or merely increase the bite's damage reach. Extend the existing installed strike definition with one optional, finite trusted discriminator, `preparationMotion: { kind: 'pursue-observed-target', startRange, standOffRange, locomotionProfileId }`. Its absence retains stationary preparation for every existing strike, including the stag and bear. For this family validate finite `startRange >= range > standOffRange > 0`, an installed compatible locomotion profile and positive existing work/recovery timing. The base wolf definition selects 4m, 0.6m, the installed 0.28m/game-second pursuit profile, contact reach 1.2m, work 120, recovery 240, damage 18 and accuracy 0.85. These values remain in ecology.yaml; shared strike/action code has no wolf predicate.

The action descriptor, parser/model exposure where applicable, admission, motion prediction, execution and current-format validator consume this same installed definition. `approachRange` retains its stationary semantics; this family uses `startRange` as preparation admission distance and `standOffRange` only as its desired supported movement stopping separation. Neither permits an impact farther than `range`. No definition-supplied code, arbitrary steering script, extra action loop or second move action is added.

The exact transition sequence is:

1. **Approach.** The native controller selects its eligible personally seen target and exact life, original pursuit deadline and route allowance. It approaches a supported ring point through ordinary movement. Construct ring positions using body-surface distance and clearance, not a center-distance assumption. At an actual boundary within the authored preparation-start distance, admission checks current visibility, eligibility, participation/protection, strike capability, geometry/definition pins, recovery completion, remaining pursuit allowance and a supported direct or prepared route toward the observed contact position. A pending route is pending preparation, without an admitted bite or started windup. Ring arrival alone is not authority to attack.
2. **Commit visible preparation.** Install exactly one strike action, bind its target/life, immutable strike/profile pins, observed position/time, route identity/cursor and original release time. Commit the actual directed preparation occurrence once. The ordinary exposure owner supplies that occurrence only to observers who actually perceive the behavior; it carries no private hunger, hidden target coordinates or pack plan. The prey's CTR alarm may use this actual perceived directed preparation immediately. An observer who does not perceive it receives no omniscient incoming-attack notice. When seen, the full 120-game-second preparation is rendered through the normal visible activity/pose surface; normal world time continues while the player reads or a provider runs.
3. **Move during preparation.** The strike action owns both its work deadline and physical route. It moves toward the latest personally observed supported point, stopping at the selected surface separation when possible. Each existing perception/motion boundary refreshes only legitimately observed position facts. The physical sample travels at most the gap between the selected stopping separation and contact reach before observing again, including while waiting within reach. The sampled route already includes its stopped branch; do not subdivide indefinitely at a shrinking approach endpoint. Reuse a clear direct route cheaply; the 12-second expensive ring/detour review bound does not permit 12 seconds of hidden tracking or suppress collision/perception boundaries. A pending new corridor may retain a still-valid old route toward its recorded point, otherwise movement stops; preparation time continues. Apply current body scar movement factors once through the same locomotion reader used by prediction and execution. Resolve support, swept body clearance, collision, target movement and temporal subdivision through the current motion owners. Do not freeze either body, turn movement itself into injury, or grant damage because they were briefly close earlier in preparation.
4. **One impact attempt at the original deadline.** At the actual world boundary, ordinary strike authority checks the current exact live target, current eligibility/participation, support, sight, contact reach and permitted definitions. If they hold, consume only the existing impact/accuracy random draw and call the common contact-impact owner. Otherwise record an ordinary miss or scoped refusal without damage and without a hidden extended preparation. The expired preparation cannot wait for the next convenient contact. Another actor's earlier same-boundary hit may already have killed or displaced the target; canonical world order handles that result honestly.
5. **Recovery and further choice.** A hit or ordinary missed attempt establishes the existing `combatReadyAt` deadline once for 240 game seconds. A later native choice may replace stationary recovery with ordinary pursuit movement, but that actor-level deadline survives and prevents another strike. A further bite is a separately admitted action with a fresh full preparation; it keeps the original hunt deadline/distance and requires personally current sight and eligibility. No automatic successful retry, coupled pack strike or new model call is implied.

Loss of sight, fresh CTR alarm, target replacement, unavailable participation, newly invalid authority/definitions, exhausted pursuit time/distance or actor incapacity cancels unreleased preparation through the ordinary action owner. Preserve already committed impact/recovery and actual traveled distance. Loss of sight can select the separately bounded last-seen search; it cannot continue a hidden-target bite. Canceling never refunds a previously established cooldown, and the 600-second hunt-reconsideration rule still applies when a hunt ends. A collision that merely stops movement does not itself delay release: it may produce a real miss unless a separate cancellation condition applies. Exhausted native work allowance parks calculation without inventing elapsed motion or impact.

Persist the existing action's exact motion family/phase, release deadline, target/life, observed point/time, route cursor/dependencies and definition pins, plus the controller's original pursuit limits/consumed distance when it owns this work, and the actor's ordinary recovery deadline. Do not persist a second motion timer or recompute release from the restored current time. Current-format restore validates one action-owned route and matching exact actor/target/definition references for every active moving preparation. Only a strike owned by this world's hunt controller also requires the exact bidirectional hunt linkage; generic moving strikes do not require an animal, forager or hunt record. Past observations may outlive their subjects, active strikes may not. Restore cannot reroll impact, repeat a committed cue or revive canceled work. Definition changes use the existing cancellation/admission boundary; absent new required state is incompatible development data, not a migration case.

Required checks compare prediction with actual motion, elapsed-time partitions and save/load immediately before/after preparation, sight loss, contact and recovery. Include a clear-ground hare beginning 4m away: the paper closure to 1.2m takes 70 game seconds, within the 120 preparation, and at most 33.6m wolf travel during that preparation fits the 144m hunt allowance. Test it as a possible catch, separately from farther prey, turning, obstacles, injury, missed accuracy, already-spent travel, changed participation and another wolf killing the target first. None of these calculations establishes measured hunt success or fairness to a player; RW06/FPV must observe those actual journeys.

A contrasting contract fixture installs an ordinary non-animal actor with a different body, a 2m preparation-start range, 0.8m contact reach, 0.3m stopping separation and 30-game-second work, under its own installed locomotion profile. It has no forager or hunt owner. Exercise ordinary admission, preparation motion, contact failure and current-format restore to establish that the generic contract reads installed values and optional ownership correctly. This is a focused verification fixture, not another bundled creature or new gameplay family.

## Feeding transaction and competition

Offer feeding only for an exact reachable exposed source matching the installed diet and ordinary object/custody access. Exclude carried, worn, attached, held/reserved and protected stock; seeing meat in a person's hand grants no right to consume it. A ground source still requires the installed access policy, and a container's exterior never grants access to its contents. The action binds actor/life, source identity/revision, diet/definition pins, quantity one and original completion deadline. Admission does not reserve all food in a patch or corpse.

At completion, revalidate the current source, body, support/reach, diet, freshness, participation, current access/holds/ownership and actual remaining quantity. In one semantic transaction debit the selected resource/item or **remaining** corpse yield, add the clamped actual fullness outcome, and write the precise occurrence. If another feeder/harvester consumed it first, refuse without food or fabricated success. If a bite killed prey, feeding is a later separately admitted physical action; death does not grant ownership or teleport meat into a wolf.

The remains owner is the sole writer of edible yields. Its current save contract gains exact remaining yields and partial consumption status; normal harvest transfers that remaining set and marks exhausted only when appropriate. A corpse may have zero meat and still yield bones. Preparation before rot cannot override rot at completion. No new actor inventory, unpaid material generation, duplicated corpse container or hidden secondary yield list.

## Human opportunities without scripted interactions

Add a narrow installed opportunity input to the existing actor-scoped decision preparation. `opportunities.yaml` rows have: stable ID/revision, applicable authored roles, the named known-place/need/owned-stock inputs, supported candidate categories and authored explanation text. They **do not** contain action sequences, mandatory target IDs, success branches, player-camp queries, dialogue, relationship writes or elapsed-day triggers. Trusted preparation resolves actor-role references to exact current IDs during creation and later reads the actor's own knowledge/possessions.

For each of Kest and Orin, prepare at most eight optional candidate reasons/places per ordinary decision, after required current work, accepted agreements, personally required needs and fresh threat evidence. Retain a still-relevant chosen opportunity, rotate equally eligible unused alternatives by stable saved selection position, and advance that position only at an actual new choice boundary; this cap must not permanently suppress another valid alternative. Evaluate owned meals/ammunition through the existing inventory/definition reader once; select known place IDs before hydrating their permitted descriptions. A known empty source is not offered as currently stocked; it may remain a place worth revisiting only as an uncertain deliberate choice. Context states the actual gap and alternatives. Existing personal goals can outweigh it. The configured independent decision selects a supported intent, which normal admission may reject or cancel.

The existing director remains the only paid-call owner. Arrival, an actual changed shortage, new perceived camp/person, offer, harm or completed trip can refresh a decision through existing salience/dependency rules. Do not generate a call for every unchanged hunger sample or position update. Food crossing uses a threshold state so an unchanged shortage does not trigger repeatedly. No automatic paid retry or higher budget is introduced. Provider refusal/failure/late stale result remains technical state, not the character deciding to be hostile or hungry.

CP's help/hunt/guide outings and revocable alliance/ceasefire records are consumed through their exact owners. Independent human combat follows CTR's retained explicit threat response. Ordinary speech requires SPK's actual audibility and evidence; a ceasefire offer is not accepted by generating compatible-sounding prose. Shared journey context is a read-only join of independently accessible records, consistent with the attention/scene design; it never merges minds or creates joint authority.

## Permissions and private information

Animals act under the installed trusted native controller and world rules; this never supplies application credentials, human control or protected property rights. Strike admission retains actual human participation and life checks. SH's exact property-exposure grants are required for a humanoid barrier strike. Wildlife in this slice has no barrier-damage capability.

Only perceived present resources/bodies or known static habitat places can enter animal choice. Only personally permitted observations, reported places and owned/inspected stock enter a human decision. A last observed camp remains stale information after an owner changes its walls or supplies. Client map/artwork may expose static geography under existing policy, but cannot expose live hidden bodies, contents or plans. Authorized diagnostics keep private references separate from public events.

## Save/load, replacement and failure

Save selected mode, target/life, actual committed deadlines, consumed units, current route, pursuit distance, evidence times and RNG. Restore definitions/identities first, validate current records, reconstruct derived lookups and resume through ordinary scheduling. No forage draw, chance-to-hit, meal, personal choice, provider request or initial stock is replayed. No offline catch-up is introduced. Revoked operational authority is not restored from the world save.

Current-format work starts and recorded observation/sight-loss times cannot lie in the future. Hunting and pack-joining work require their installed supported rule, retain its original maximum duration, and cannot exceed its travel allowance beyond spatial tolerance. An expired pending record may remain while danger owns movement and is reconciled normally. Ground joining considers supported visible packmates; losing that support retires the same finite joining work rather than inventing a ground location.

A dead/removed predator ends its active work; ordinary released effects may continue under their owner. A changed prey life invalidates its attack, not the historical sighting. A deleted/changed place or food definition blocks affected active work with an exact reason. Approved definition edits must first cancel incompatible work or use the current definition-admission owner; a saved profile pin cannot silently switch to a new policy. Incompatible development saves follow AGENTS, with no legacy converter.

For simultaneous food/strike completion, use the existing serial world order. Budget exhaustion parks preparation with its original limits and no fictitious elapsed travel. Disconnect/body fade respects existing player rules. A distant NPC that continues living is still simulated through admitted normal native work; no abstract arrival or unrecorded travel is claimed.

## Bounded work and measurement

Relevant growth dimensions are active animals, visible local living density, eligible food sources, distinct body/navigation profiles, due decision boundaries and retained personal evidence. Routine deadlines scale with active animals, not total history. Use existing spatial and participant/stock indexes; no scan of all world entities for each animal.

Each due animal prepares one perception view, at most six fresh route destinations and its retained route; lost-contact search has at most three destinations. Share immutable physical definitions and compatible navigation preparation by exact body/geometry dependencies. Do not share observer-private evidence. A local query that cannot establish completeness within the existing work allowance is pending/incomplete, never 'no prey'. Selection can be bounded only after safe candidate filtering; a six-result cap does not justify an unbounded all-world sort.

Measure cold opening construction, warm ordinary simulation, dense local prey/predators, changed wall geometry, simultaneous route failures, corpse competition, save/load and the actual server/publication path. Increase inert world objects independently from local living density. Record visited candidates, navigation requests/reused preparations, actor decision refreshes, native elapsed time and achieved 1×/8× simulation speed. The 8× requirement is simulation speed, not eight times the population. Use current performance gates; no new numerical latency claim is established by this design.

## Implementation order and verification

RW01 locks authored profile compilation and current-format state. RW02 implements animal needs/feeding and single-controller arbitration after CTR03–CTR04's escape foundation is delivered. RW03 adds local hunt/flank/territorial behavior using CTR01's actual contact owner. RW04 adds actor-scoped human opportunity inputs and actual trip discovery, reusing CP/SPK and CTR05–CTR08's human choices/reconsideration. RW05 covers UI/history and continuation. RW06 qualifies actual independent behavior, ordinary pacing and full callers with FPV. Each task has exact exits in the [tracker](../maintainers/first-playable-roaming.md); the [combined sequence](first-playable-world-tech-design.md#implementation-order-and-independent-task-boundaries) supplies these dependencies within one assignment.

Required negative journeys: unseen player moves; packmate sees a target the focal wolf cannot; prey dies or changes life during windup; caller reaches a blocked ring; food disappears/rots; unknown route budget exhausts; a wall changes during travel; owner disconnects; old save has absent new required fields; model says it arrived without traveling; a character refuses a trip; an attack begins while an offer is pending. Verify no hidden movement, manufactured knowledge, duplicate yields or lost previously committed consequences.
