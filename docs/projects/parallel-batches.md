The October 11 allocation follows the consolidated Batch 06 format: **one ambitious assignment per numbered batch**, with its internal stages owned together. These three assignments can run together while Batch 06 remains unfinished. They are not three five-agent groups. The current request supplies no new staffing-hour target; the old Batch 01 400-hour allocation is not reused.

Batch 07 owns initial assembly and empty-host activation; Batch 08 owns its authored incident and ordinary evidence consumers; Batch 09 owns reviewed destructive changes to supported status-effect definitions and their active instances. Batch 06 continues to own new opponent behavior, flight/cover, evasion and combat help. None of these prompts requires another agent to start, send messages, provide intermediate commits or finish before its own acceptance can pass. Later merging still requires ordinary integration review; independent work does not guarantee conflict-free Git merges.

The selection favors two complete new experiences and one already accepted integrity gap. World creation addresses Core creator repertoire entries ACR-122/135/192; the mystery addresses Core AD-076. It is selected as foundational product work, not represented as a newly reproduced deletion bug. Categories are not quotas.
