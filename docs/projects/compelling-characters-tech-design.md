- **Memory:** retain demanded direct-question/follow-up and changed/absent-memory controls, plus a casual cue where private influence or no visible reference is valid. Construction traverses the existing bounded selected evidence and enabled schema once; it must not rescan all history/holdings or hydrate a capability catalogue merely to write a reminder.
