### 1. Establish one visual language

The target is a **lived-in woodland rendered as deliberate, dimensional pixel art**: natural adult proportions, recognizable people, sculpted organic vegetation, quiet ground, readable possessions and light with a visible source. Pixels should describe a face, a fold, a leaf group or an edge; they should not resemble a checkerboard stretched over a smooth object.

Use the [creative brief](../../art-direction/final-board/creative-brief.md) as the authority for preferences. Build a compact reference sheet from the already retained media, identifying the specific quality being borrowed:

## Workload and resource preparation

Cost grows with visible animated subjects, geometry/material diversity, rig/cloth work, target pixel area, shaded lights, vegetation density and transparent overlap. Material changes invalidate affected material preparation; pose changes update the affected character and dependent passes; camera/viewport changes update target mapping and allocations only as needed. A light change invalidates lighting results rather than unchanged source geometry. Revoked visibility removes all related captures/effects promptly.
