## Authority and inspected baseline

This is the implementation contract for [the acoustic feature](acoustic-stealth-feature-spec.md). [Physical sound](../worlds/base/physical-sound.md) owns the bundled movement, source, hearing, feature and response values. [ACS](../maintainers/acoustic-stealth.md) owns implementation work; [the limits inventory](../limits/acoustic-stealth.md) owns restrictiveness and evidence. Read them together with the [SC01–SC14 common contracts](stealth-awareness-tech-design.md#shared-contracts). This document specifies selected behavior, not APIs or sound sources already delivered.

The exact starting point is `codex/design-stealth-00-contracts` at `a3d40b4d71e29d6504e9f3fcc21e76344a0a284e`. The completed `codex/design-stealth-01-perception` was read at `40805523c4a19ab7c6cc455d49d51e4a122ecae0`: [feature][a-feature], [technical contract][a-tech], [world policy][a-policy], [tracker][a-work]. Those pinned links are intentional: the acoustic branch does not merge A. The available vision branch still pointed to the common base when inspected; its shared SC06 pose/clearance boundaries apply, and this design does not wait for or merge a vision branch.

The **single physical hearing owner** generalizes existing speech acoustics. Module C produces actual sound and observer-specific physical opportunities. A acquires/accumulates, classifies, recognizes and associates. E chooses attention and investigation; F decides whether acquired evidence warns; D supplies emotional effects; G presents authorized observations and ordinary controls. Physical source metadata is not an identity proof. A reasoning-capable person does not automatically turn, interrupt or ask an AI about each sound.

**Shared implementation gate:** [SA-D02][sa-d02] proposes preserving exact owner-specific revision types because common SC02's illustrative numeric `EvidenceRef.revision` cannot express existing personal-source string digests. Keep the storage family and exact numeric native revision or exact string personal revision. Do not coerce, hash again, add an acoustic revision counter or silently amend the common contract. Resolve that shared representation before dependent implementation. The acoustic decisions below are otherwise selected. Voice response bands require acquired voice-like classification or understood-speech proof; indistinct utterances follow the same general filter as other indistinct sounds.

## Physical source contract

### One actual occurrence, separate performer and emitter

Reuse `WorldEvent` occurrence ID/order/time, `DefinitionPin`, exact physical-life references, spatial positions and existing action/environment provenance. Introduce an optional physical sound contribution on an existing occurrence; allocate an ordinary occurrence when a foot contact has no other event. A contact is real even if no one hears it. An evaluation/retry is not an occurrence.

| Private field | Required meaning and validation |
| --- | --- |
| Original root | Existing event occurrence for an impulse; actual action/environment/body source start and exact owner revision for an interval. Distinct real contacts have distinct occurrence roots. A relay/recording would also preserve its original learning lineage, but is not installed initially. |
| Cause | Optional existing action/result/performer reference explaining causation. It is not the emitting body's current location or public identity; a projectile may outlive its shooter. |
| Source ownership | Exact physical owner/life, producer family and profile pin, contact ordinal or activity generation. A detached occurrence remains valid after its original actor's departure. Reuse of an entity ID in a new life never continues an old gait/producer. |
| Physical origin | XYZ and contact/source anchor at the occurrence, or admitted piecewise source track over the actual interval. Include accepted support/contact and geometry revision privately where needed. Do not recompute old origins from the actor's current position. |
| Envelope | Discriminated impulse `{at, occurrence}` or interval `{startedAt, from, through, sourceRevision}`. Impulse has no duration. Interval coverage is half-open; an active unended interval must have its current valid physical segment and owner deadline, not infinity as a serialized number. |
| Emission group | Components physically combined at one co-located contact/process. Foot/gear contact at that contact forms one group for energy, features and self-exclusion. Separate simultaneous sources stay separate even if they share a performer. |
| Signal | Finite reference SPL at 1 metre, propagation medium/reference pin, scalar source feature family/value vector and surviving-feature fidelity. Optional voice-identity vector uses its separate pinned family. Values are authored physical properties, not entity-ID hashes. |
| Dependency proof | Exact definition, source/body, accepted path/support, equipment aggregate, geometry, clock conversion and lifecycle revisions used. Current cache tokens do not replace durable original source proof. |

Authored component and source-profile reference levels use the installed finite admission range, currently −120 through 200 dB. Computed group and received levels preserve the complete combined energy and must remain finite; they are not clipped to that authored-profile range. An unrepresentable result follows the explicit numerical/required-work failure contract. Transmission and fidelity are finite `[0,1]`; vectors use their family's finite feature list and range. Required missing profiles are an install/admission error or unsupported producer, never a guessed profile based on English names. Zero transmission returns a blocked exposure with null level/quality rather than `−Infinity`. Absence of an installed emitter is not evidence that its future physical family is inherently silent.

The initial provider is scalar direct-path airborne sound with no travel delay, reverberation, frequency spectrum or fluid/structure propagation. It supports installed bodies and processes, not every physically possible source. The general source schema can be used by a future breaking transition, machinery beat or wing profile once that owner supplies real occurrence/coverage. It does not claim those actions exist now.

### Actual contact production

The locomotion/body owner stores `{profile pin, normalized cycle phase, next contact ordinal}` for the current exact body life. The phase is in `[0,1)`; ordinal is a nonnegative safe integer using the existing integer-allocation/overflow refusal rules. It is independent of `Action.motionSampleRemainingMetres` and animation. A profile has a positive finite cycle distance and one to eight ordered contact offsets in `(0,1]`; equal offsets form a single simultaneous contact group with stable contact labels.

For each accepted traversal piece:

1. Obtain the original path's actual XYZ/support segments, their accepted distance, speed and time interval. Split at turns, support/material changes, actual collisions, pace/posture changes and flight transitions. Do not replace the path with its endpoint chord.
2. Determine the next installed offset beyond the saved phase and its distance. Add that contact to `nativeInterval`/motion boundary composition. A large requested advance cannot jump over it.
3. Advance all affected bodies to that physical boundary. Record the contact origin/time on the accepted segment and combine actual sole/body/support and coupled gear contributions. At a material seam, use the support owner's existing accepted-point tie rule. No rejected distance earns phase.
4. Advance ordinal and phase once with the accepted contact transaction; retain residual phase across stops, route changes, follow updates, yielded work and compatible command replacement. Profile changes preserve normalized phase, while the next cycle uses the newly admitted distance. Do not reset just before a loud contact.
5. A new body starts immediately after its initial contact, producing no free step merely for starting an action. Teleport/editor/recovery position assignment earns no travel; it leaves phase suspended until real ground travel resumes. Ground-to-air motion stops contacts. Landing is its own actual occurrence, not a fictitious travel distance.

The first world uses grouped human/animal contacts, including a hare's bound and the small bird's ground travel. Additional legs do not imply one sound per human foot. Contact profiles can share signatures; the listener cannot identify a species from a private body key. Existing `.4 m` native wandering is processed through the same actual-distance phase, including the case where several short wanders eventually cross one contact.

Quiet pace and crouch follow the selected world law. Ordinary speed remains the underlying current effective rate; speed constraints use the most restrictive cap. Evasion's committed speed/end is pinned: changing pace/posture during that action is refused, and it keeps its admitted contact profile. The quiet preference does not slow a newly admitted evade; its actual evasion rate determines contact noise. The initial human evade requires standing and uses the ordinary 2.20-metre travel contact cycle with its actual pinned evade speed, never the quiet/crouched cadence. A crouched evade is refused by ordinary admission rather than silently standing. Another action that locks stance supplies its own normal refusal/interruption. New posture uses the current person's capability identity, not a new incompatible body ID. Construction stores the standing living profile; accepted variant geometry is derived/validated under the same body owner and must agree on restore. Do not let repeated crouch/stand multiply already-crouched dimensions.

Posture work occupies the ordinary physical action lane. The old body remains authoritative until completion, when support/clearance and existing equipment compatibility are revalidated atomically. Refused admission consumes no action work. If final revalidation fails after admitted transition work, retain the old posture and report refusal without refunding elapsed time or emitting the completion contact. Cancellation follows ordinary work/resource policy. Actual accepted geometry invalidates route, reach, sight/ear anchors and source predictions together. C owns the posture, B the gaze/visibility consequences; preserve or clamp accepted gaze through the joint pose owner, not a camera writer. Current equipment ports have no local coordinates: accurate long-item extension clearance is not claimed by this slice.

### Equipment, impacts and interval producers

Derive one immutable movement/handling aggregate for an actual carrier from installed components, quantities, custody/attachment and admitted enclosure transmission. Reuse the ownership/possession index. Cache by those exact dependencies, never by inventory display text. Rebuild on actual equipment/custody/quantity/fastener/material/definition changes before the next contact; do not scan all world items at each step. A carrier's complete private holdings can participate physically without disclosure. A profile has separate movement and handling reference levels; initial examples set handling equal to their listed movement reference before the posture handling adjustment.

Combine the energies of coupled co-located components and use their energy-weighted physical feature vector. The contact's single group must not mask itself once per component. Self-attribution can use actual proprioceptive ownership under A's self-knowledge contract; it cannot identify another unseen carrier. An explicitly attached or contained component is not duplicated as a free-standing sound producer for the same motion.

For body/tool/projectile impact, use actual accepted contact material and origin. Capture the closing speed relative to the support along the contact normal before fall state is cleared; convert simulation-speed units once. Missing contact, dry-run action availability or canceled windup produces no impact. Existing attack/impact events carry the sound contribution, retaining their original outcome/cause and source root. A future destruction adapter must bind the actual break transition and preserve its outcome; C does not make a living-target strike into general object destruction.

`contact-defense.ts::commitContactImpact` captures actual contact/guard/shield information before guard recovery and injury can change the action/body. Extend that owner's immutable contact result with the sound-relevant source anchor, actual contacted body/shield/material and source pins; the later outer event must not infer them from the mutated defender. Select exactly one canonical existing root per contact: melee **`struck`**; a projectile that contacts a body **`projectile-contact`**; a solid/terrain-only projectile **`projectile-ended`** only when the projectile owner records a real physical contact. A missed/range-exhausted `projectile-ended` has no impact. The accompanying `guarded` record and secondary terminal/outcome records do not emit a second copy of that contact. Released projectile position/contact is the physical origin even after shooter loss. The current melee owner does not solve a mesh hit point: select the contacted body's actual accepted spatial position plus half its current accepted body height on the vertical axis as the first contact anchor, captured before mutation. An actual installed contact/shield anchor may replace this only when its owning geometry supports it; current equipment ports do not. This is a stated body-level source approximation, not an exact limb/shield hit claim. Projectile `flight.position` already supplies its swept actual contact point. This explicit mapping is part of source construction and current-format validation, not a listener-side deduplication guess.

An interval producer is a component of its existing action/body/environment owner: profile pin, active generation, original start, current physical segment, consumed prefix and next owner change/end. Clean fibers binds only to the admitted working stage; fire binds to actual burning state (`completeFireCare` light/fuel/extinguish, endpoint fuel burn/`fire-out`, and the existing `heat.fuelSeconds` temporal boundary); foliage binds to actual moving overlap with an installed contact volume. Grass support under feet and a surrounding brush volume are distinct inputs and can coexist. A standing body in foliage emits no movement-rustle interval.

Starting, stopping, blocking, changing speed, leaving vegetation, losing fuel and cancellation settle the preceding interval under its old profile, then atomically change the source. A new callback is not a new interval start. A work beat has an installed phase/cadence in real accepted work progress; analytic work coarsening must preserve those actual contacts or equivalent interval coverage. Captions, synthesizer output, streamed text and remembered descriptions never create duration or masking. There is one speech occurrence and one physical group per committed utterance, through its present speech owner.

## C to A: physical opportunity, proof and permitted signal

### Three representations

1. **Private physical preparation:** complete source proof, geometry, simultaneous sources, hidden positions and exact body/item causes. Only physical/source owners and trusted validators receive this.
2. **Native A acquisition input:** opaque exact original source binding plus measured coverage, immediate/weak admission and only the received features/location that this listener can support. A's classification/recognition receives the permitted signal payload; the opaque private binding is for deduplication, correction and causal verification only.
3. **Recipient-facing evidence:** A's actual acquired `SensoryEvidence`, facets, permitted location/association and authorized speech content. Personal history, AI input and G projection receive this version. Neither source role nor source coordinates are a convenience field here.

No consumer may unwrap a private event's actor ID to call a sound “Ada,” “the hare,” “a burglar,” “metal armor” or “behind the storeroom wall.” A sound-like hypothesis is an inference from received features. Known words/names, visual body association and believed speaker identity have separate proofs. C never calls the canonical person resolver on behalf of a listener.

A immediately acquires strong impulses and strong interval onsets, then owns the selected weak rule: threshold 1, decay 2 per normal-speed second, admitted continuous full-strength scale 4 per normal-speed second and maximum compatible gap .5 normal-speed second. C supplies physical strength and meaningful boundaries, not another accumulator. Do not multiply by the world's rate twice. A's published contribution/lease/receipt structures preserve the uncovered prefix and one acquisition across event, native, personal and projection paths.

C's generic dimensions cannot count toward A's three usable voice identity dimensions. Human Perception is read through the existing effective-attribute owner; it does not increase hearing range merely because it improves recognition. Unfamiliar speakers, colliding feature vectors, tentative matches and recognized recordings retain A's uncertainty/current-body rules.

For an impulse, acquisition grants no ongoing sound location: its measurement is historical immediately after the occurrence. The .5-second correlation grace is not a live position lease. A real interval can maintain a current permitted bearing/features lease while physical support remains valid. Its latest measurement time differs from how long the channel remained available. Freeze a meaningful final confirmation at actual loss; do not rewrite an onset as if its last sample were valid throughout. Old heard equipment, name or body facts never become fresh because another sound was acquired.

### Speech compatibility and memory independence

Preserve current whisper/normal/shout emission and partial/clear word thresholds through the shared physical receiver. Concurrent sound may reduce word availability without erasing an audible disturbance. A can recognize a familiar received voice without seeing its body and without exact localization; recognition cannot restore masked words. A first unseen stranger remains unknown. One committed instantaneous utterance provides one discrete voice sample; no invented syllable/token duration or familiarity credit.

Both `receiverIndex` and `perceiveSpeech` must stop using autobiography as a physiological gate. Compact acquisition precedes optional memory serialization. Extend event-evidence validation so an actual speech occurrence may produce nonlinguistic hearing-only facets for an animal, not an invalid linguistic placeholder. Retain existing asleep/incapacitated/dead receptor gates; this feature does not add sound-triggered waking. A deaf speaker's self-known action/result remains its existing self-knowledge, not fabricated hearing.

## Continuous reception, mixing and bounded work

### Scene preparation and complete energy accounting

Prepare active source owners, eligible hearing receivers and conservative spatial/dependency indexes once per valid native physical phase. Use the existing native order for equal work keys. A source occurrence's free-field reach is a conservative **individual** candidate bound including weak reception; actual barriers and competition only reduce it. It is not a cutoff for energy that might mask another source or participate in a mixture. Swept source/receiver bounds cover the whole admitted motion segment, not just its endpoints.

For each listener requiring evaluation, compute each contributing group's transfer once and cache it under actual origin/track, receiver ear/body life, medium, geometry and definition pins. Construct ambient energy and the stable group-energy sequence. Derive all leave-one-group-out competition sums with prefix/suffix maximum-offset energy summaries. Never subtract a huge candidate from a nearly equal total to obtain a tiny complement. Components in one group do not mask each other. A separate simultaneous source by the same actor does compete. Add the receptor's floor by the selected `max(floor, ambient plus competitors)` rule, not as another physical sound.

Individual strong opportunities use their own received energy against all other groups. Then evaluate unresolved external residual energy as one mixture against ambient and the resolved groups. Preserve the residual's actual support roots and conservative direction union, unknown producer count, and no individual/voice-identity features. Each original contribution is allocated to the mixture or its individual weak route exactly once for that coverage. Known self components may mask external sounds, but do not become an external mixture. Ambient alone is not a new source or event. This source separation rule is deterministic; it does not progressively remove loud sources and rerun weaker detection until everything becomes separable.

The first implementation uses complete exact accounting for the considered acoustic scene. An energy-bound spatial hierarchy may avoid entire regions only when its aggregate remainder proves **every requested decision** unchanged, including weak/mixture acquisition, words, feature/identity quality, localization, response and earliest deadline. At an acquired sample that promises exact numeric quality, finish its required exact sum. A nearest-N, top-K, individual-weak-reach or fixed-decibel omission is not an allowed fallback. If no useful proof exists, traverse all relevant active sources; cost is charged and may remain incomplete. No spectral rendering, browser audio device or waveform extraction is involved.

Persistent unchanged source/receiver/geometry combinations reuse prepared transfer and intervals. Dirty notices include old and new influence regions and the source's previous bound. Adding a source can invalidate other sounds through masking; removing one can uncover a sound without that sound moving. If a finite affected-region bound cannot be proven, invalidate the complete receptor scene conservatively. A name or familiarity change invalidates A's interpretation, not unchanged geometry. Cache eviction recomputes; it never removes recipients.

### Constant-rate weak intervals and canonical boundaries

The world's **continuous** weak law deliberately uses four duration-sensitivity bands, while its discrete impulse law stays linear. Supply A rates 1, 2, 3 and 4 support units per normal-speed second for `delta` in `[-6,-4.5)`, `[-4.5,-3)`, `[-3,-1.5)` and `[-1.5,0)` respectively. Equivalently pass normalized strengths .25, .50, .75 and 1 to A's scale of four. Below −6 is a zero-rate gap; `delta >= 0` enters immediate strong reception without waiting .25 seconds. A integrates only uncovered constant-rate spans and applies its existing decay in unsupported gaps. This is selected world behavior, not an approximation secretly dependent on host sampling.

The existing temporal/motion owner takes the earliest of:

- Actual contact, source start/end, action working-stage/cadence or material/vegetation overlap transition.
- Actual path/support/track segment end; source/receiver pose, hearing/life, level/fidelity, geometry, ambient or relevant masker change.
- A direct-path transmission/fidelity topology change, the `.25 m` distance-floor boundary, weak/strong threshold, word band, feature-quality bin, bearing/elevation precision boundary or native response baseline crossing.
- A's first weak-detection crossing, eligible continuous learning sample deadline (if that voice producer is installed), actual evidence-cut demand, expiry or meaningful confirmation boundary.

Only the current interval up to the earliest certified boundary is available. A host's smaller requested advance may consume a prefix of an already certified span, but cannot invent a new acoustic sample, reset the span anchor or move a deadline. For a changing live value, retain the latest physical measurement under A's lease; use a required cut or actual semantic change to freeze history. E/G polling reads that lease and never schedules a measurement merely to strengthen recognition.

For recognition-capable continuous producers, A supplies any current finite quality thresholds and required measurement instants implied by its admitted comparison/learning state to this same dependency query. C supplies actual received quality there. It cannot keep a stale optimistic quality until the next renderer call. The initial voice producer is instantaneous, so these duration/learning obligations are exercised by an explicit contrast fixture rather than guessed from text length.

### Selected terminating numerical procedure

The installed first provider accepts piecewise-affine actual source/ear tracks, piecewise-constant source power/background, and the existing finite direct-path shape family. Split at all real track/profile changes. Spatial queries must supply complete crossing intervals of the moving ray with their actual supported shape primitives, including grazing/parallel cases; this extends the existing geometry owner, not a second acoustic map. Source/receiver tracking that cannot supply this supported family is `unsupported` at admission, not silently endpoint-sampled.

Within one fixed-transmission span, normalized linear energy from source `j` is `c_j / q_j(t)`, where `c_j` is its fixed source/transfer power and `q_j` is squared source-ear distance, clamped below by `.25²`. On an affine track the unclamped `q_j` is a quadratic. Its extrema and floor crossings are directly calculable. For a threshold `h` relative to listener detection, compare source energy to `10^((D+h)/10)` times the competing-energy/floor expression. Split the floor-versus-competition switch as another comparison. Multiplying by positive denominators converts each comparison into a finite polynomial sign query; no logarithmic quadrature is required.

Use this ordered solver:

1. Handle constant/identically-equal spans directly. Handle a single varying squared distance with constant competition by its quadratic roots. Use conservative interval bounds from squared-distance extrema to certify whole spans that cannot cross a requested boundary.
2. For unresolved moving multi-source comparisons, construct the polynomial with positive denominators after distance-floor splits. Pin the admitted binary64 primitive powers, threshold powers, affine track coefficients and original segment anchors; interpret those primitives as exact binary rationals. Construct squared-distance and cleared-denominator predicates with exact rational operations. Scheduling and point admission use those same predicates. Calculate outward logarithmic level/quality fields in one pinned operation order; their rounded values never independently re-decide C's physical band.
3. Use square-free factorization (`gcd(p,p')`) and a rational Sturm root count to isolate all distinct real roots in the original physical span. Rational bisection is deterministic, left before right. Repeated roots remain boundary candidates; derivative/sign checks on both sides distinguish a tangent from a real band transition. Constant zero is a plateau, not endless subdivision. This is the required terminating fallback, not a heuristic max-depth midpoint choice.
4. Spatial topology roots use the same certified polynomial predicate approach for the provider's supported moving-segment/plane, polygon-edge and solid-boundary tests. Partition denominator/sign changes before testing containment; include exact-on-plane/grazing cases. Static rays use the existing ordered crossing visitor. An unsupported primitive requires a provider extension, not a guessed visibility blocker.
5. Convert a real root to the earliest representable simulation time at or after it, using the existing numeric-time owner. Retain the isolated root/side and original segment anchor in required preparation so a shorter host call does not select a different rounding. Reevaluate the admitted right-hand band there. Use the existing `TIME_EPSILON` only as a numeric progress guard, not a sensing tick or permission to discard a possible crossing. This canonical representable time is also the boundary supplied to A for constant-rate integration. Check rounding against all actual source ends, physical endpoints, required cuts and other roots: if it erases or reorders an outcome-relevant interval, return an explicit numeric-representability failure through the native work owner rather than merging it away. Retain the consumed root side at a current-time equality. Use the existing absolute-deadline path; `untilThreshold` clamps to `TIME_EPSILON` and must not round away a smaller representable acoustic span. Constant-state and exact endpoint cases must still terminate without failure.
6. Equality belongs to the higher band. An isolated tangent touch has zero duration and does not create a continuous onset unless a nonempty right-hand interval is eligible. A touch from above does not end/restart the exposure. A threshold plateau uses the higher band over its actual duration. Discrete impulses separately use their instantaneous inclusive rule. A source ending at the boundary is absent under `[start,end)`.

Exact-rational polynomial work can be expensive in a dense moving scene. Meter coefficient construction, coefficient bits/bytes, sign operations, roots and pending brackets under the existing required-work budgets; cancellation and reuse are dependency-aware. The algorithm is selected for a complete deterministic fallback, not a capacity claim. Certified simple spans avoid it in ordinary unchanged scenes. ACS07 must measure whole-caller cost, including geometry/root preparation; an implementation that exhausts required work on the target scene has not delivered the performance gate.

### Work units, growth and incomplete results

Use resumable deterministic chunks under [work-budget.ts](../../packages/domain/src/work-budget.ts): at most **128 source/receiver transfer candidates**, **256 source-component contributions**, or **32 root-isolation/sign work steps** before yielding control to that existing owner. These are responsiveness quanta, not valid-world limits, replenished global allowances or permission to truncate recipients. A retains its own 64-contribution/128-exemplar quanta; do not copy those accumulators into C. One polynomial step must itself charge coefficient operation/byte growth so a high-degree expression cannot hide unbounded synchronous work.

Let `S` be active physical sources, `R` eligible receivers, `K` components changed in equipment/source preparation, `P` complete candidate transfers and `B` certified interval/boundary work. One valid phase prepares indexes once, processes changed components in `O(K)`, visits candidates in `O(P)`, and constructs per-listener competition complements in `O(number of received groups)` rather than another per-candidate scan of all groups. Polynomial/shape work is charged separately as `B`, including degree/bit growth. In a genuinely dense all-audible scene `P` can be `S × R`; the design does not promise subquadratic physical work for arbitrary simultaneous sources. It prevents a separate per-frame all-world propagation loop and repeated whole-index rebuild per step.

No nearest-N audience or arbitrary acoustic radius is installed. Existing global/actor/module work and retained-byte bounds remain containment, not a newly qualified acoustic capacity. Their present 2M-candidate, 4M-test and 64 MB input/output group limits must not be advertised as how many moving animals fit. Retained source/receiver preparation and unfinished mixed-root work reserve their real bytes under those owners. Overflow returns incomplete/required-work failure with the coherent prefix and owed work; it is never completed `not-detected`.

Prepared current carrier profiles and source/receiver scene entries are disposable derived state. They use the existing bounded work/cache owner with exact fallback, not a permanently growing per-pair world table. Active producer state is proportional to actual active activities/bodies; retained A/native evidence follows its own actual obligations. Under high density, optional thought/presentation can coalesce but required acquisition cannot. Record queue age, owed simulation time and complete state size as well as local helper duration.

### Scale and play gates

ACS07 measures the **complete** native/server/persistence/projection caller in both cold and warmed states. Increase inert world size separately from living receiver count, moving-source density, inventory component count, simultaneous source count and retained play duration. Include static fires, many crossing movers, concentrated equipment/barrier edits, thin moving occluders, sustained mixing, repeated save/reload and saturated required-work queues. Record index rebuilds, candidate visits, exact transfer work, component/mix operations, polynomial degree/bit growth/root work, retained bytes, source/history writes, queue age, requested versus advanced time, debt and whole-path latency. A bounded output list or cached scalar microbenchmark cannot establish these costs. Correct completion under metered backpressure is necessary but does not certify that the target scene is playable.

ACS08 independently observes the eight required journeys in the feature matrix. Compare the quiet approach's actual time/control burden with a longer soft route, a farther shot, leaving noisy gear behind, ordinary pursuit and abandoning the hunt. Include failed approaches that become interesting through the prey's own noises; a familiar voice behind a wall; believable misclassification; useful overlapping work/noise; ordinary sound as coordination, cargo value or pleasure. The player should infer useful choices through normal feedback, without a numeric sound debug overlay, mandatory note-taking or repeated confirmations. Record what was understood unaided, what choices were enjoyable and where information became spam or effort. Tuning remains provisional until these observations; a mathematically correct detector alone is insufficient.
