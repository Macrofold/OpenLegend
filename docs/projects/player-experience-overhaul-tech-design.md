## Stable presentation and fresh authority

Separate private reader identity (account/world/actor/timeline) from transport availability and short-lived command scope. Quiet blur/pause retains already displayed content and mounted drafts under the same owner while disabling interaction. A fresh successful read replaces the display in place. A real owner/timeline/access loss clears protected information immediately. Permissions removed by a current authoritative result also clear affected detail. Do not make stale actions executable because a page remains visible.

Inventory right-click must not clear the collection through an inspect-write refresh. Keep query/selection/scroll and existing rows while a same-owner refresh is pending; only current-authority command/detail data is actionable. Avoid broad invalidation for unrelated movement/status/clock updates. Grouping derives from canonical disclosed equivalence and retains member references; any multi-unit effect must resolve through the native atomic owner with exact expected stock and grants, not independent client loops.

## Placement interface

Add a plain renderer placement contract: enabled placement mode, pointer-supported point callback, explicit commit/cancel/rotate intentions. Preserve `SurfacePoint` XYZ and support identity from actual picking. Pointer movement updates a local draft; renderer draws only authorized definition-derived shapes. Reuse construction preview geometry and authoritative admission, not duplicated client shelter rules. Throttle/coalesce remote validation with one in-flight request and discard superseded results. Do not send an HTTP request every render frame. A ghost can be provisional; only a checked exact plan may commit, and commit rechecks current physical/resources/grants through the existing command owner.

Primary click in placement mode is consumed by placement; drag release cannot place or walk. UI and text input retain priority. Escape cancels only the active layer. Rotate buttons share the same intention as keyboard rotation. Leaving placement, ownership change, restoration and scene destruction clear graphics/listeners; quiet pause preserves the draft but forbids commit. The material drawer reflects actual world definitions, costs and selected units; it never grants unavailable construction.

A null supported-surface pick is explicit local invalidation, never a request to reuse the previous point. Keep the draft coordinates as the keyboard movement anchor, render its retained geometry as unconfirmed, suspend remote preview checks and prevent pointer, keyboard or button confirmation until a valid pick. This uses only the existing permitted scene picking result, with no hidden geometry or guessed support. Fence confirmation synchronously before React renders; once submission starts, pointer movement cannot invalidate that submitted intention.
