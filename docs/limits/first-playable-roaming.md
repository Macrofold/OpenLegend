# First-playable roaming limits

**Status: selected design, not measured qualification.** [RW](../maintainers/first-playable-roaming.md) owns implementation. The [world profile](../worlds/base/first-playable-roaming.md) owns fictional numbers and exact semantics; this inventory records why they exist, who consumes them and what would justify change.

| ID    | Selected bound / owner                                                                                                                         | Purpose and tradeoff                                                                         | Qualification / change trigger                                                                                                     |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| RWL01 | Existing finite opening population; three wolves, two bears; no replacement or renewal                                                         | Consequences remain real; finite stock/population can eventually exhaust                     | Observe full sessions and later return; renewal needs its separate selected design                                                 |
| RWL02 | Six fresh approach destinations; three lost-sight search points                                                                                | Bound per-choice navigation; constrained animals can fail to find an available approach      | Obstacle cases, body shapes, pending/exhausted handling and navigation work counts                                                 |
| RWL03 | Routine review 2,400 game seconds; pursuit review at most once/12 game seconds except actual collision/urgent change                           | Avoid repeated route work while allowing meaningful movement updates                         | Partition-equivalent motion and actual 1×/8× callers; preserve exposure fidelity                                                   |
| RWL04 | Wolf pursuit 1,800 game seconds/144m; last-seen120/search300; reconsider600                                                                    | A failed hunt ends; actual approach/preparation/recovery/search share one distance limit     | Escape, obstacles, hidden target motion, current-format restoration; 36m nearly exhausted one moving preparation                   |
| RWL05 | Bear territorial pursuit600 game seconds/18m, local4/8m regions                                                                                | Local warning/retreat, without an inevitable long chase                                      | Actual route length, retreat and body-contact scenarios                                                                            |
| RWL06 | Finite pasture240 units each; exact varied initial prey Food42–60 and species rates/diets in world profile                                     | Early and later possible feeding; all-100 delayed first feeding beyond69 normal real minutes | Actual feeding/harvest competition and session stock budget; no measured balance claim                                             |
| RWL07 | Eight prepared human opportunity rows per actor/decision                                                                                       | Useful alternatives through existing independent decision context                            | Fair scoped selection; record omitted/pending preparation, avoid a hidden player-target priority                                   |
| RWL08 | No new paid-call cadence/budget; current director/admission/accounting                                                                         | New circumstances use existing decision authority                                            | Actual configured-provider episodes and costs; fixtures establish only native mechanics                                            |
| RWL09 | Wolf moving preparation starts within4m; speed0.28m/game second, stand-off0.6m, actual reach1.2m, preparation120/recovery240, injury18         | Grounded possible prey contact with visible preparation; no frozen prey or extended reach    | Clear-ground paper catch is possible, not measured success; moving prey/obstacles/miss/cancel/restore and actual human readability |
| RWL10 | Regroup above8m toward6m separation; one12m/120-game-second visible leg, refresh2m/12seconds; one other visible packmate for biped eligibility | Local cohesion can fail; no hidden leader, shared quarry or three-survivor requirement       | Actual pack separation, line-of-sight loss, competing food/alarm, independent target choices and ordinary route overlap            |

World-law values above are not universal engine constants. Work budgets retain existing performance owners; an exhausted search never proves absence/unreachability. Larger populations, broader food ecology, scent, new movement families and global pack coordination require new evidence and explicit design rather than increasing these numbers silently.
