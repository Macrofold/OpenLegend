## MY-L01 — One fixed incident with two independent residents

**Implemented; restrictiveness: Safe.** One finite authored misunderstanding, two adults (`Mara Reed` and `Tavin Vale`), two nearby sites (`Mending Clearing` and `Reed-side Store`) and the exact clue/stock profile supply the first investigation. These are new-start content quantities, not global population, mystery or memory caps. Existing stock can move or disappear; there is no refill, compulsory disclosure or guarantee that every later visitor can complete the original investigation. Fixed past facts reduce generation/cross-world complexity while leaving current choices live. Expand content only after a worthwhile complete activity is demonstrated; dynamic mystery generation requires its own selected scope.

## MY-L02 — Two sources compared at once

**Implemented; restrictiveness: Safe.** The existing `World Events` viewer shows up to two selected permitted source accounts (`slots: [WorldEventSourceReference | null, WorldEventSourceReference | null]`) together, with full text and source navigation, validated on the server at up to `2` references per `POST /api/world-events/sources` request. This limits simultaneous display/read payload, not searchable or retained history; another pair remains selectable through current pages. Selection is scoped local presentation state and clears on actor/world/timeline/access change while surviving memory correction and forgetting epoch bumps. No stored case file, hypothesis scoring, automatic verdict or model call accompanies comparison. Expand only for a demonstrated comparison need, preserving source provenance and readable layout.

## MY-L03 — Historical observations, no live object tracking

**Implemented supported-capability boundary; restrictiveness: Medium.** Detail supports retained deliberate item/place inspections (`encounter`) and heard utterances (`speech`), with optional `ItemDefinition.inscription` bounded to `1..600` non-empty characters. An `observedLocation` (`{ kind: 'world'; point; label; containerId } | { kind: 'possession'; label }`) is the actor-permitted location at that observation; it never refreshes from hidden live custody or lets a historical reference command an unseen object. Comparing a document's words establishes a reading (`Inspected a written account`), not the truth of its claims. Current ordinary inspection is how new facts become available. General claim graphs, evidentiary verdicts and authored executable testimony are unsupported; source privacy/identity itself is a correctness invariant, not a tunable cap.

## MY-L04 — Existing retention and bounded reads, no new stored-history cap

**No limit introduced on total retained evidence; growth remains with existing owners.** Each actual permitted inspection/conversation can add records, and actor notes/accepted interpretations can evolve. Existing [memory/knowledge](memory.md), [perceived-history paging](hearing-and-speech.md#hr06--history-paging-and-growth), [cognition](cognition.md) and [persistence](persistence.md) controls apply. Existing finite search windows (`500` rows per request) expose continuation; exact comparison uses indexed actor/source selection (`history_perspective_type_order` and `history_events_pkey` `Index Scan`) before hydration. Two final rows do not bound SQL join work or all context preparation.

**Restrictiveness: Liberal for the selected scoped reads; total retained growth remains unqualified.** No repeated whole-history scan is selected. Measured in [Batch 08 verification](../verification/parallel-batch-08-the-missing-belonging.md#4-performance-query-plans-and-product-assessment-my05): cold two-source compare read `2.27 ms`, warm two-source compare read at `2,574` retained events `4.74 ms`, and two-window (`500`-row) search continuation `64.02 ms` / `19.40 ms`. Overall retained bytes, long-lived actor growth and concentrated reads have no new independent quota in this assignment and remain unqualified. Do not conceal those gaps by evicting required evidence or changing existing privacy/retention policy.

## MY-L05 — Present actions use current owners

**Implemented scope; restrictiveness: Safe.** Ground-level access, current bag storage and voluntary one-way gift consent (`handover`) supply every physical effect. No lock, enclosure, title enforcement, involuntary return, new social meter, relationship award, combat, new visual asset or generated-world dependency. This protects independent completion and avoids unsupported promises. A chosen later experience may extend an existing owner after its decisions are settled; this restriction grants no authority to change D69 or custody policy.
