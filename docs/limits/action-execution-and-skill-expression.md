## ASE-L01 — Quick tap versus held timing

**Selected initial threshold: 150 real milliseconds**, owned by the [shared client input/settings contract](../projects/action-execution-and-skill-expression-tech-design.md#61-one-owner-visible-state-and-selected-bindings). A shorter tap is ordinary score zero. A longer hold can be scored only after its exact admitted profile has been displayed; start its phase at that later boundary, and keep an earlier release neutral. Native preparation begins with the one admitted attempt and remains independent. Holding never repeats an attack. Early release retains one frozen intention only while its input authorization is live; pause, cancellation, blur, detected disconnection, control loss or expired lease disarms automatic release.

**Restrictiveness: Medium.** This is device input classification, not a world/weapon/recipe property. A smaller threshold risks accidental challenges; a larger one delays a deliberate choice. Qualify actual devices, delayed admission and frame stalls. No additional maximum total hold duration is selected: actual native claims, interruption, vulnerability, control and explicit cancellation remain effective. Indefinite safe camping, if observed, needs a justified world preparation rule rather than an unexplained browser timer.

## ASE-L02 — Ring pace and visible timing bands

The [world input profile](../worlds/base/skilled-action-execution.md#concentric-release-interaction) selects a **one-real-second** expansion/contraction cycle, target radius `0.5`, green half-width `0.06` and ordinary outer half-width `0.15`. Its [generic evaluator](../projects/action-execution-and-skill-expression-tech-design.md#22-deterministic-evaluation-and-presentation) supplies a continuous signed score; exact zero boundaries display ordinary. First center-green occurs 250 ms after ring origin, or 400 ms after an immediately admitted pointer-down. The one-second cycle is an owner-selected pace, not a measured optimum. Those are arithmetic properties, not measured human response.

**Restrictiveness: Medium.** Smaller bands may reward precision while excluding useful play. No new Dexterity, Focus, intoxication or clothworking attribute is installed. Future supported native contributions may visibly alter the pinned challenge; no secret mid-attempt rescoring. Color-independent cues remain required. The ring stays animated; keyboard aiming, frozen phase selection and assisted perfect timing are removed. Ordinary neutral attacks and explicit release/cancel buttons remain available. Actual hardware, reduced-motion and player evidence remains limited.

## ASE-L03 — Scalar execution range and release quality

**Supported score: `[-1,1]`**, with zero ordinary, positive strong and negative weak. One accepted choice contributes to one native attempt; a new request ID cannot reroll an accepted choice. World-installed families select only supported contact/injury consumers. Client score, arbitrary effect/stat keys, nonfinite coordinates/phase and stale exact meanings refuse at admission. Missing optional support is valid absence; an invalid present profile is not silently ordinary.

**Restrictiveness: Safe.** Finite input prevents unbounded supplied modifiers without creating a global stat. The family derives its actual effect, with its native valid-range clamp. Deterministic recalculation does not prove that a human performed the input. Poor timing does not force a physical miss; green does not create collision. Richer future gestures require useful finite semantics rather than overloading this scalar.

## ASE-L04 — Initial bounded weapon contributions

The [weapon consequence table](../worlds/base/skilled-action-execution.md#weapon-specific-consequences-selected-initial-testing-profiles) selects excellent relative maxima: sling contact `+25%`, bow contact `+20%`, spear contact `+15%` plus pre-defense injury `+10%`, and hammer pre-defense injury `+25%`. The [native baseline table](../worlds/base/skilled-action-execution.md#native-weapon-baselines-and-recovery) preserves knife/spear work and recovery, adds sling/bow recovery of 18/24 game seconds, and authors the finite hammer's 24-game-second windup and 48-game-second recovery. Punch remains its ordinary unphased action without an invented timing/recovery profile. The hammer is a new obtainable authored item, not an existing weapon falsely claimed as present.

**Restrictiveness: Medium.** Magnitudes and cadence are installed initial balance values, not universal caps or qualified balance. Qualify combined channels, useful ordinary attacks, high handling/clamping, defense, native windup and total repeat cadence. There is no new critical mechanic. A failed feasible local dodge contest can matter only where real geometry permits a response; low handling never makes unchanged matter transparent.

## ASE-L08 — Input/network work and pending state

There are **zero per-frame gameplay transmissions for ring/pointer tracking**, and at most one accepted scored release for the exact attempt. The [existing server control/presence owner](../projects/action-execution-and-skill-expression-tech-design.md#13-movement-alongside-preparation-and-the-live-input-lease) selects the initial **100-real-ms** routine renewal target and **250-real-ms** lost-input expiry. These operational values are independent of fictional time and installed world/weapon/recipe definitions; a world cannot extend stale-input authority. Unchanged renewal extends an operational lease without full world preparation. Direction/stop changes enter genuine simulation boundaries. Old/equal movement or renewal sequences cannot renew authority; discrete attack sequence is independent. Existing request envelopes and budgets remain controlling.

Retain at most one bounded current attack-gesture slot per live controller and one latest movement intent, with a matching exact early-release identity where needed. The [clock/control contract](../projects/action-execution-and-skill-expression-tech-design.md#13-movement-alongside-preparation-and-the-live-input-lease) permits one unsaved finite steering window and one independent window for the exact armed release, not input history. A fresh window cannot cover old simulation debt; renewal cannot grant future or duplicate game time. Direction changes cannot replace or re-date the pending release. Native offers respect window boundaries and current expiry; unadvanced world time remains owed.

Cancellation can terminally name the original begin request before its action ID is returned. Released/ended work settles the slot; no movement-destination queue, second action registry or persisted gesture database is added. Common pause/load/handoff revokes the input epoch and both fixed lane tokens. An individual expiry rotates only that lane's token before accepting another packet, so an old higher sequence cannot restart it while the independently live lane continues. Each lane has its own renewal watermark; a stale claim cannot suppress the other's valid renewal. Fresh scope requires fresh deliberate input, not automatic rebinding of held controls. Durable receipts keep their separate recovery meaning, and a review's explicit confirmation never becomes a queued action on modal dismissal.

**Restrictiveness: Safe**, with responsiveness versus lost-input travel to measure. Under backlog, input may expire before its authorized window is reached and have no effect. Qualify navigation/CPU debt, delayed host continuation and speed changes, including a pending release; expiry cannot be repaired by deleting an effect while retaining its dependent consequences. The current five-second general presence heartbeat cannot meet this short input deadline. A network partition has no instantaneous remote-cancel guarantee; already committed effects stay real. No new packet-size cap is invented.
