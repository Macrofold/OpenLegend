# Action records and learned activities: limits

**Current limits, reviewed October 3, 2026; initial implementation and measurements date from September 28, with later extensions called out below.** [Current behavior](../action-experience.md), [technical design](../projects/action-experience-tech-design.md), [AE tracker](../maintainers/action-experience.md) and [evidence](../verification/action-experience.md) distinguish contracts, work and measurements. Existing [cognition](cognition.md), [memory](memory.md), [AI execution](ai-execution.md), [native work](native-work.md) and [persistence](persistence.md) limits still apply. These initial finite envelopes replace the design's unselected budgets; they are not measured optimal settings.

## AEL01

**Current — recursive structure and execution · Restrictiveness: Medium.** `ACTIVITY_LIMITS` admits at most 64 nodes, depth 12, 16 iterations per repeat, 86,400 game seconds (one game day) per wait (raised from 36,000 on September 29, 2026 so "until dawn" works from any hour) and 4,096 expanded control/invocation visits per method. Each frontier call unfolds at most 64 nodes; idle wait checks do not consume expansion visits. The existing eight-step active plan and 32-step recent history remain; durable occurrences hold older completed work. Unsupported fields, cycles/recursive references and oversized structures are refused before execution. Exhausted execution becomes an explicit blocker, preserving prior effects. Finite sequence/branch/repeat/wait is supported; unrestricted recursion, arbitrary code and inferred stopping predicates are not. Rationale: nested composition with predictable admission and honest stopping. Native fixtures cover nesting, repeat/wait deadlines and resumed control; expand only for a concrete rejected valid method.

## AEL02

**Current — projection and model input · Restrictiveness: Safe.** A view admits 48 facts, 500 characters per bounded label/value text and the same 64-node/depth-12 structure. Projection defaults to 16,000 UTF-8 bytes; caller-selected collapsed depth changes layout and optional detail, never critical coverage. Own history pages render at most 16 entries/16,384 bytes; learned inspection renders at most four methods/16,384 bytes with independent cursors. Required facts that cannot fit refuse preparation; optional omission is explicit. Existing whole-request admission remains controlling. Compact English and specific permitted target/tool facts are mandatory; JSON is a narrow last resort for critical untemplated relationships. Occurrence descriptions and typed option labels keep IDs, schema/result codes and raw bookkeeping out; the generative action/known-plan list still needs the [AE03 correction](../maintainers/action-experience.md#ae03--compact-english-and-remaining-work-views). Native coverage and single-fixture live wording/fallback checks establish mechanism and narrow comprehension, not general model reliability. No routine duplicate JSON representation is retained.

PG03’s ordinary menu reuses the permitted native facts as display pairs; it does not use the learned-method shortlist or the method projection’s byte/node budget to truncate complete ordinary discovery. Existing command admission remains unchanged. Player-only commitment wording does not alter NPC decision context. [AP01](interface.md#ap01--ordinary-action-discovery) owns this separate browsing envelope.

## AEL03

**Current — scan, provenance and hydration · Restrictiveness: Safe.** Indexed actor reads return 128 base records; dependency reads accept at most 512 source IDs. Each preparation admits at most 512 rows and 4 MiB hydrated payload over at most 12 dependency passes. PostgreSQL applies the payload byte cap before transfer/JSON decoding. Discovery and known-span matching each have 512 work visits; unresolved dependencies remain incomplete. Each occurrence has at most 64 evidence IDs/connections and 16 output/effect entries; contributor chains use the same 64-link bound. Missing/ambiguous state or mixed-item ancestry cannot establish precise reproduction. Cursors retain progression independently of the resident tail. The 500-action branching/long-action fixture is qualification workload, not a semantic time window. Broader population/query latency remains governed by PF qualification.

## AEL04

**Current — candidate repertoire and matching · Restrictiveness: Very safe.** At most four candidates per pass: direct connected material pairs with recorded native support, bounded endpoint slices and explicit-purpose spans. Compatible known spans annotate these without consuming the source trace; overlapping matches cannot duplicate execution. Matching is exact over normalized structure, role/definition pins and installed module manifest; there is no all-subset/permutation/path search or arbitrary semantic equivalence. Excess endpoints remain pending through durable cursors; incomplete slices cannot execute. The exact ten-action fixture and known-four-within-eight fixture pass. This can miss useful intermediate or implicit-purpose groupings. Widen only with demonstrated missed cases, preserving causal and private-evidence boundaries.

## AEL05

**Current — scheduling and paid work · Restrictiveness: Safe.** One existing maintenance worker admits one bounded actor batch at a time; immediate cognition retains priority. Maintenance requires a living, non-incapacitated, memory-capable NPC with inner-world capability and no installed body-policy maintenance blocker. The bundled world currently blocks maintenance below authored health 40 or fullness 30; `bodyThinkingBlocked` reads those world-owned conditions, not a universal `safeCognitiveDowntime` helper or a hard-coded engine percentage. Learning additionally requires no current native action or active plan, including control-only waits. Existing scheduler retry/admission timing applies; no new semantic idle timeout splits sequences. Continuous occupation or insufficient budget can delay learning indefinitely. A dispatched-signature ledger prevents automatic paid reassessment after uncertainty, malformed responses or failure. Known methods can acquire fresh support without a repeated model question. Native capacity preflight precedes dispatch. Strict Jev-only admission reserves the bounded typed path, not generation/embedding work. The final valid-terrain automatic meal run used 86 calls; it is not a fixed calls-per-meal rule. Exact costs are owned by the evidence report.

## AEL06

**Current — sharing, acquisition and generalization · Restrictiveness: Medium.** Definitions are immutable and world-scoped; each learner requires private permitted reproduction/support. Initial evidence stays tentative. No automatic teaching, cross-world library, confidence promotion/decay, approximate matching, guaranteed external cooperation or widening from one wounded target to arbitrary health is supported. The observed maximum target health remains an entry condition. Realized traces can be learned; registered branch/repeat/wait structures execute when explicitly supplied, but predicates are not inferred from a successful trace. Native revision-bound inventory operations are recorded but excluded from reusable invocations until their fresh-revision capability contract supports that use. These conservative boundaries avoid fictional laws or accidental authority. Broaden under AC/knowledge owners when a concrete family requires it.

## AEL07

**Current — retained storage and backlog · Restrictiveness: Medium.** A world admits 100,000 action occurrences in total, including cold rows. Each occurrence/method is at most 32,768 UTF-8 bytes; each world holds at most 256 method definitions. An actor holds at most 64 acquisitions, each at most 65,536 bytes including private support. At most 1,024 assessed signatures and 262,144 bytes are retained per actor. The pending wake list coalesces to 128 source IDs; durable row positions, a maximum 512 examined-endpoint cursor and canonical records preserve history beyond it. Only four provisional candidates are materialized per preparation; no separate durable provisional catalogue exists. Cold residency keeps the last 128 completed records per actor plus running records. Definition/acquisition or assessment exhaustion defers optional learning before dispatch; admission failure during publication aborts the transaction. No support is silently evicted. The 100,000-record limit explicitly refuses new recorded actions while preserving existing work/history. Increasing allowance is an owner/configuration change, not automatic deletion or recovery by reset. Capacity, rollback, cursor, cold paging and current-format reopen fixtures pass; these caps do not establish production capacity at their maximum products. There is no additional feature-specific world byte quota beyond these count/record bounds and shared persistence controls. Assess removal/expansion only with measured pressure and storage policy, not by silently discarding evidence.

## AEL08

**Current — retrieval and staged execution · Restrictiveness: Safe.** Filter the actor's at-most-64 acquired entries for compatible current evidence/definitions before rendering up to four relevant offers. The world catalogue is at most 256 definitions; private inspection can page other acquired methods. Projection follows only supplied structures, with bounded nodes and resource aggregation; it does not enumerate future plans or perform hidden-state simulation. Unknown future products remain requirements, not inventory. Current committed outputs, shared materials, ammunition and fire are rechecked by native execution. One physical lane, supported native families and existing interruption policy remain. Non-executable incomplete ideas may be inspected but cannot be offered as executable methods. Catalogue preparation measured 256 definitions/64 acquisitions/four offers; this is a native CPU fixture, not whole-population acceptance. Larger libraries or new parallel/cooperative families require their own measured contract changes.

## AEL09 — Fresh stock binding and finite reuse

**Current native implementation; broader qualification pending · Restrictiveness: Very safe.** [PW10](../maintainers/parallel-batch-01-playable-week.md#pw10--chosen-camp-activities-and-reusable-finite-methods) implements a plan-eligible semantic stock transfer for portable homogeneous units under one current exact definition pin, from the actor's accessible possessions or the direct contents of one selected accessible container. One stable indexed admission examines at most 200 candidates, including the proof of the actor's available minimum, and moves at most 16 lots atomically. It stops once the required quantity and guard are proved; no nested scan receives another allowance. These are per-operation work bounds, not limits on saved belongings or units per lot. The generic command accepts safe integer quantities; the bundled request form's separate quantity/minimum tuning belongs to [camp routines](../worlds/base/camp-routines.md#authored-choices-and-bounds).

Units reserved or held for another admitted operation, or needed by ongoing work, cannot satisfy available-stock proof. A fuel completion may count only the exact lot pinned by that same action; it never releases another claim. Capacity/access/provenance preflight commits the whole selected move or nothing. Missing coverage returns explicit incomplete selection with inspection/narrowing guidance; it never succeeds on a partial quantity or treats an incomplete read as empty. Exact lot/revision binding and actual output receipts belong to each attempt; only permitted roles, exact pin, demonstrated quantity and guard may become learned support. A ground-cache method role requires current permitted selected-container inspection. Individual keepsakes remain exact-instance transfers. Rearrangement among the actor's accessible bags is not spending their personal stock.

The existing AEL06 restriction remains for other revision-bound commands; this narrow fresh-binding adapter is the implemented exception. Eligible NPCs can choose to retain supported realized finite steps, but retention or later reuse is never forced. Thresholds, branches/repeats, absolute deadlines and unseen outcomes are not inferred. A one-session watch uses existing finite control with an explicitly chosen absolute deadline within one game day and at most 16 fuel attempts/units. Receipt-based counters, completed outputs and interrupted attendance persist across current-format restart. Suspension does not extend the deadline or reset counters; restarted native fuel work is a new attempt. Only an exact installed spending declaration with matching arguments and a conservative per-attempt debit can count as spending. Deadline-safe cancellation alone is insufficient: generic stock movement has no consumption-receipt contract. Attempts whose possible debit exceeds the remaining budget refuse before execution; successful counted actions require a valid actual receipt. A stopped watch does not disqualify a later independent action from finite-method learning. It is not saved as learned conditional knowledge.

**Reason / tradeoff:** Reuse a demonstrated packing method safely as stock changes without replaying old transaction authority. The conservative candidate/lot bound may require narrower scope despite adequate total stock; expand only for a demonstrated valid workload while preserving atomicity and provenance. This does not solve general parameterized templates, standing reservations or cooperation. One replacement frozen 100-watch native specimen completed at simulation time 10 in 947.5319579999998 ms with all watches terminal, zero attempts/spending and valid current-format state; this does not qualify live-server population capacity.
