# Documentation decision history

Current behavior and rationale remain in their [maintained owners](README.md). History records consequential decisions, not task progress or every edit.

Browse [2026](changelog/2026/). New files use the Monday starting each week: `YYYY-MM-DD.md`; create only weeks with meaningful entries. [Earlier collection](changelog/2026/2026-10-24-earlier-collection.md) preserves the previous dated and undated material without inventing dates.

The [documentation system](documentation-system.md#homes-and-filing-units) owns filing and growth.
