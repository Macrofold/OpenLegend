## Selection decisions

This catalogue primarily defines **alternative laws for entire worlds**, not a basic enemy, weapon, destination or recovery action. The full descriptions of 248 entries explicitly require a different world premise outside the four seed proposals. Those entries are Specialist for the current game. This is a scope decision, not a claim that strange worlds are uninteresting, that every D feature is difficult, or that ambitious ideas must always wait in a world actually built around them.

UNR-141 is Depth: a festival whose demonstrations and finite promises temporarily replace ordinary exchange can add an enjoyable event once activities and trading work. Its special exchange constitution is not required for a useful market, a performance or ordinary cooperation. UNR-159 is Depth: an optional unreliable storyteller can add humor and investigation while retaining trustworthy inspection. Honest action results remain mandatory without building this narrative mode.

The predatory labyrinth (UNR-038), currency-sensing predators (UNR-230), adventure-enabling feasts (UNR-244), persistent home beside renewing wilderness (UNR-249), and a world that continues after its final boss (UNR-250) contain valuable future inspiration. Their smaller reusable lessons—readable enemies, worthwhile expedition preparation, persistent rewards and genuine victory—already belong in the current game's foundations. Ranking those lessons highly does not require adopting each entry's full world constitution or building its society-wide consequences first.

Likewise, ordinary travel does not need invitation-dependent distance, normal rest does not need separate dream lives, and basic recovery does not need a municipal resurrection economy. Basic enemies can precede whole ecosystems and supernatural political orders. A later explicit choice to build one of these alternative experiences warrants a new contextual ranking, not an automatic import into the bundled world.

Fictional memory forks, restored districts, world migration or creator succession do not authorize real permission changes or override the [development save policy](../../AGENTS.md#development-save-policy). Preserve identity, actual outcomes, observer boundaries and participant agency whenever the selected fictional capability requires them.
