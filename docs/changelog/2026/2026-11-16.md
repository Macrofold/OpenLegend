- **Scope boundary:** this records accepted target direction only; current client code remains PlayCanvas 2.22.2, and full UE5 client migration design, hardware/VRAM budgets and disposition of the browser renderer comparison ([RCP](../../maintainers/renderer-comparison.md)) remain open.
