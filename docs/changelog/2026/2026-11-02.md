# Documentation decisions — week of November 2, 2026

## November 5 — Character-art production

The [character-production specification](../../projects/character-art-production-feature-spec.md) and [execution guide](../../projects/character-art-production-tech-design.md) define a scoped offline method inside the existing art flows. Generate or edit parts separately when that improves control, but choose final separation from deformation and actual equipment needs. Refine a usable direct mesh; reconstruct topology or bake a detailed source only for a concrete benefit. Prove rough movement and contact before dependent polish, then preserve the same source through a useful revision.

Early gameplay work uses a functional prototype unless greater finish is requested; polished work continues from that source. Rights, identity constraints, promised states, valid exports and native gameplay authority remain required in both cases. Optional facial detail, extra material maps and secondary physics do not become universal stages. Review the actual exported result and intended game view rather than a provider thumbnail or tutorial time estimate.

The [source study](../../research/character-art-production/README.md) and [repertoire review](../../research/character-art-production/repertoire-review.md) separate evidence, project judgments and unrun qualification. The design retains believable proportions, meaningful expression, ordinary pleasure, practical invention and independent lives, without making visual appearance a private-mind readout. It adds no vendor commitment, runtime system, catalogue expansion or numerical production promise.

[CAP00](../../maintainers/art-direction.md#character-production-follow-through) is **Done — designed** for this slice; CAP01 and existing V3D/character/player owners retain production and acceptance. The [work plan](../../projects/character-art-production-design-plan.md#verification-and-remaining-work) records the unrun pinned formatting check separately from completed content/design review. No runtime or artistic qualification is asserted by this decision record.
