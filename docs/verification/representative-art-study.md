## Assets, fixed paint and reproduction

[Editable Blender sources and instructions](../../art-direction/assets/representative-study/README.md), [shared export helper](../../scripts/art_study_common.py) and the three `prepare-study-*` scripts reproduce the study. Each catalog records exact source/script/output hashes, bounds, evaluated triangle/vertex counts, texture sizes, descriptions and selections. Separately editable source pieces are joined only in temporary evaluated export copies, producing one static runtime mesh per asset with shared material parts.

The 30 GLBs total **2,946,504 bytes / 55,366 evaluated triangles**. The ten selections total **18,820 triangles**. People stand at **1.70 / 1.78 / 1.82 metres**; tree studies are about **4.07–4.20 m**, bushes **0.99–1.00 m**, selected chest **0.59 m**, sword **1.00 m**, shield **0.66 m**. These are study geometry dimensions, not native-world body changes. Each person uses one material and one fixed **128×128** atlas; other paint uses **16×16 through 64×64**, plus **32×128** blade artwork. Faces deliberately group multiple atlas cells into larger features rather than implying every source cell is a separate visible face pixel.

Source pixels, UVs and geometry are authored offline. Nearest magnification preserves enlarged cells; trilinear mip minification filters their coverage at distance. The browser uses actual textured meshes, full CSS-pixel framebuffer resolution, four-sample antialiasing and one shared light/shadow treatment. It does not run whole-scene reduction, the mercenary's 96-row capture or a camera-dependent surface generator. Continuous silhouettes are intentional; these are shaped 3D models with fixed pixel artwork rather than cube-built anatomy. Normal screen-edge coverage and mip transitions can still change during motion, so this is not a zero-shimmer guarantee.
