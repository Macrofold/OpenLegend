## Alternatives and reference-based assessment

The [creative brief](../../art-direction/final-board/creative-brief.md), [art decisions](../../art-direction/decisions.md) and [realtime research](../../art-direction/research/3d-pixel-worlds/realtime-pixel-rendering.md) remain the evaluation criteria: Garbage Country's readable organic groups and quiet spaces, t3ssel8r's expressive shaped people, and The Last Night/REPLACED's deliberate materials/light. A free low-poly mesh is a starting point rather than evidence of a completed pixel-art finish.

**Mercenary:** original artwork is preserved alongside **faithful**, **painted** and **graphic** body/cape/face designs. Faithful retains more material detail; painted gives angular open-link mail and cheek planes; graphic uses quieter mail fields, shaped facial features and cape embroidery. Three body maps are 1,024²; cape maps are 1,024×1,536. Designed facial regions are combined into one shared vertex-colored mesh per variant. They follow the existing curved face and head, with the existing modest face proportion retained. No body vertices, UVs, skeleton, source animation or cape contact behavior were replaced. Rig scale remains 1.1, physical height 2.035 metres, with the inherited apparent-height correction beside sprites and fixed 96-row control. The original/source face is more legible than the coarse game capture: the three game material variants are visibly different but subtle at normal scale, and the current capture still loses too much facial detail. This is not a completed face fix or permanent 3D pixel construction.

**Hares:** **field**, **russet** and **winter** have different fixed 64² coats and actual body/ear proportions. Field is slender with longer ears, russet broader with swept ears, winter fuller with shorter ears. The source's solid eye geometry is retained; optional fur/whisker cards are removed. Each prepared asset has 1,532 triangles, two materials and 37 joints. Idle is the creator's Sitting animation and Run is Running, rather than invented native actions. The neutral model fits the existing 0.45-metre appearance envelope; animated ears can reach about 0.48 metres. These choices read more clearly than the mercenary alternatives, especially the coat/ear shapes, but coarse normal gameplay cannot preserve all close-view detail. Unsupported body/action presentation keeps the original sprite.

**Environment:** original procedural and grouped scenery remain; Kenney is a useful cheap geometric control, Quaternius the provisional organic candidate. The selected Quaternius broadleaf/conifer/slender tree/shrub contain respectively 3,182/1,646/3,505/900 triangles before scene instancing. Imported material separation, UVs and alpha-cutout leaves are retained, with quieter painted leaf/bark maps. Slender common-tree geometry with pale bark is an explicit birch approximation. Quaternius better supports organic masses than the blockier Kenney shapes; dense leaf edges remain busy, and some repeated detail still conflicts with Garbage Country's quiet groups. It increases geometry cost. The prior procedural trees were authored by code; the new alternatives use the credited downloaded meshes with local art preparation.

The provisional default is **Quaternius scenery / graphic mercenary / field hare / woodland ground**, replacing grouped scenery / original mercenary / sprite hares. ## Preparation, selection and lifetime evidence

The prepared scenery has eight templates, eleven materials and ten shared textures, at most 128², totaling 655,360 RGBA bytes. Its formatted JSON is 5,924,136 bytes before transfer compression. It keeps source normals/UVs, normalizes appearance into the caller's unchanged envelope and shares meshes/materials/instance buffers. Source and painted alpha bytes are identical. RGB is sRGB while glTF material constants are linear; runtime conversion follows the pinned importer. Fixed source paint does not regenerate when the camera moves. Mip filtering reduces distant texture aliasing, but cannot guarantee stable moving silhouettes.

Preparation caught and corrected two color mistakes: Kenney material constants were being darkened twice, and hare atlas colors were initially written as linear values into sRGB images. Final field/russet/winter coat bytes match the intended palettes. Reimported hare files retain normalized four-weight skinning, actual clips, fitted neutral bounds and distinct proportions. Environment preparation reproduces its recorded geometry, UVs, source/painted alpha and literal license data. All three Python recipes parse successfully.

It shares a byte-rounded alpha mip chain, approximately 349,520 calculated bytes for current Quaternius textures; neighboring framebuffer-pixel rays are prepared once per pointer query. Existing candidate bounds still reject irrelevant scenery before triangle/UV work. Actual CPU checks passed 960 cases across development/production class builds, including repeat/negative UV, filtering, transformations and perspective rays; all 14,737 retained Quaternius vertices fit prepared bounds, and transformed-normal errors stayed below 8e-8 in the diagnostic check.

The actual browser then compared the existing camera ray/obstruction path against GPU readback of a diagnostic quad with the exact 128² Quaternius leaf alpha and 0.2 cutoff, at 1,440×960.
