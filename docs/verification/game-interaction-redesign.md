### World portability correction

**Current correction — October 5, 2026.** The earlier statement that only the bundled base world was installed by the constructor was incorrect. Inventory is a shared interface. Its world identity keeps one world's possessions, private drafts and command recovery separate from another world's; it does not select a hardcoded inventory UI. Reach, access and custody remain native world rules.
