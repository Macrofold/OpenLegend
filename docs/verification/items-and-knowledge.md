Manual isolated runtime execution with the actual WorldService, response admission and public projection changed both entity and conversation labels from “a person” to Ada after an annotated introduction, retained the global name, and preserved the learned name across SQLite close/reopen. Repetition retained the same name revision; an announced alias updated only the observer label. Invalid nonliteral metadata preserved speech and prior knowledge. Distant listeners and a hearing-only observer did not learn the visible entity identity. Ordinary unannotated speech did not fabricate an introduction.
