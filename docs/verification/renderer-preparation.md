### Supported picking precision

Support destinations use the actual admitted surface and return XYZ/support identity. Construction panels use their panel intersection; other construction boxes use box intersection. Sprite picking rejects transparent texels below alpha 24, maps to the same upright virtual body used for rendering and rejects depth outside near/far. Native models use their existing representation hit method; animated character per-mesh conservative picking is still an approximation, while outlines follow the sampled silhouette. Generic procedural objects retain conservative boxes. Decorative canopies can obstruct the camera without becoming physical collision or bodily sight geometry. This inventory does not close [SW11](../maintainers/spatial-world.md#sw11--surface-picking-floor-focus-and-safe-cutaways) or V3D acceptance.
