## Failures found and corrected

- Initial raised/faceted facial additions were rejected; conforming details with consistent normals preserve the original profile, beard, scars and hair.
- RenderComponent attachment replaced mesh-only custom bounds, hiding instanced grass/trees at close views. Factories return patch bounds and the scene applies component bounds afterward. Earlier invisible-geometry captures are rejected; E05 was repeated.
- The first filtering control changed only existing Canvas textures. New/rebuilt textures now initialize with the selected sampling, and the mercenary’s borrowed imported maps retain/restore their original samplers through their material owner.
- Visual landscape rebuilds now reapply the chosen floor cutaway. Ground focus cannot restore an opaque upper deck merely because the art treatment changes.
- Candidate tree forms now supply actual camera-only triangle occlusion for picking; opaque crowns cannot be clicked through when read-through is Off. This does not add native tree collision or knowledge.
- Both ground treatments consume the same preparation randomness, preserving river marks and later glints across matched visual comparisons.
- Generated-asset installation is deferred until the existing object is observed and its root enabled. Late arrival cannot replace a remembered/cut-away image or install while scene updates are suspended. Repeated/failing/disposed loads retain owned fallback behavior.
- The default character target is initialized through the same resolution path as a later 96-row selection, removing a small first-use/return difference.
- Production PlayCanvas uses different whitespace in its normal shader than the debug build. The vegetation normal transformation now accepts both; exact pinned debug/production chunk assertions and the rebuilt production scene pass.
- Preset changes now refresh the staged-motion button’s announced pressed state alongside the other developer controls.
