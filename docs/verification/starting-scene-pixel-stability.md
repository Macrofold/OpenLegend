## Techniques implemented for actual comparison

- **One final reduction:** a `screen` character control captures at twice the actual displayed framebuffer dimensions, with linear color reconstruction and nearest depth. It retains the same body/label/pointer mapping, not a 96-row intermediate. Paired allocations round to 16 pixels, grow before undersampling and shrink after a factor-of-two drop. This control costs approximately four times the displayed area, with retained rounding/hysteresis overhead. It is separate from source texture resolution and all original fixed-row controls.
- **Deliberate surface art:** original connected leaf/bark/stone/ground clusters follow fixed object/metre coordinates, with mipmapped minification and contrast taper when source texels become subpixel. Foliage/bark use a two-metre repeat with 16 source texels per metre; broad ground fields retain quiet regions. Camera changes alter neither source artwork nor geometry. The first eight-metre weak tile failed visual inspection and was revised; ordinary faceted geometry alone is not accepted pixel artwork.
- **Final grids:** current half/third scene targets remain controls. Full-resolution scene rendering with 4×MSAA can instead feed a final two/three-display-pixel grid. A second variant anchors a five/seven-and-a-half-centimetre grid to an orthographic world point and integrates fractional cell-boundary coverage, retaining continuous camera movement. Perspective uses a screen grid because one global phase cannot stabilize all perspective depths. Orbit/zoom/newly visible surfaces remain separate risks.
- **Subject preservation:** an unused opaque HDR alpha channel marks prepared solid scenery while retaining real full-resolution depth. Existing people, animals, grass cutouts, fire and small sprite objects retain their detail in the full-resolution composition; generated crate solids follow scenery. At mixed boundaries, weighted scenery-color numerators are reconstructed continuously before normalization. The first hard threshold could pop a complete cell; interpolating normalized empty cells could create dark fringes; both were corrected before moving acceptance. Mixed foreground/background source pixels remain an approximation, not lossless layer separation. No second geometry/visibility pass or native collision change is added. RGBA16F and additional final samples increase cost.
- **Filtering and soft shadows:** imported character maps can use source/nearest/trilinear minification independently of Canvas sprite filtering. The source samplers restore exactly and late loads use the current selection. A fixed soft-shadow sample-pattern control removes the pinned PCSS shader's screen-position random rotation; the original screen pattern remains available. It is a comparison, not proof that all shadow-map movement is solved.
