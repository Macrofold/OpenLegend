# Foundation review — October 14, 2026

## Assessment and scope

The foundation has several strong, reusable boundaries: deterministic native changes, one owner for authoritative effects, scoped server access, exact definition references, observer-specific evidence, conservative geometry, and separate real spending. Preserve those boundaries. The material problems found are concentrated in the joins between them: permission after waiting for storage, observable facts versus authoritative action facts, removal of optional fields across JSON, current ownership of reserved materials, and browser state after control or evidence changes.

The recommendation is targeted repair, not a broad rewrite. [Thirteen immediate tasks](../maintainers/foundation-review-todos.md) give evidence, reasons, owning paths, implementation steps and acceptance. Twelve describe defects or concrete architecture/documentation debt; FR13 elevates an already tracked, unfinished durability prerequisite without claiming a newly demonstrated runtime failure. [Five later improvements](#later-work-and-activation-conditions) have explicit triggers and live in their subsystem maintainers. Only ten small foundational tests were implemented during this review; no production defect listed here has been fixed by it. The subsequently authorized [implementation follow-up](foundation-hardening.md) records the repairs and documentation audit; this report preserves the original findings.

### What should remain intact

- **One authoritative effect path.** Object custody, placement, quantities, action admission and resource claims have native owners. Build new consumers on those owners rather than adding feature-specific writable copies. A canceled action and a restored action must use the same semantics.
- **Exact dependencies and conservative fallbacks.** Definition pins, scoped references, immutable change information and current checks protect reuse after edits. Unknown or changed inputs should force the owning recheck, not be treated as unchanged to save time. Avoid whole-world hashing or copying where owned change information already suffices.
- **Geometry as a reusable calculation.** Candidate bounds, exact body/support checks and finite surfaces can support many worlds. Preserve the distinction between preparation still pending and a completed search finding no route; waiting must not silently consume game time or become a false impossibility.
- **Knowledge is not world truth.** Listener-specific speech fragments and private versus public history are valuable existing boundaries. Extend them to non-speech facts; do not repair leaked evidence with instructions asking the model to ignore it later.
- **Authority and real spending remain server responsibilities.** Requester/character/world/control/timeline checks, current native admission, durable receipts and non-rewindable spending are essential to multiplayer and invention. A model proposal is not execution permission. Preserve explicit failure/uncertainty and the absence of automatic paid retries.
- **Creation remains reviewable.** World Agent proposals, questions, human review, exact dependencies and Apply have distinct responsibilities. Keep the actual native effects and receipt owner visible; adding a general event bus, second scheduler or plugin framework would not solve the demonstrated defects.

Comments and documentation are strongest when they explain these invariants beside their semantic owner. Do not add comments that restate syntax or a second architecture handbook. Correct the misleading required-read summaries identified by FR09, and update the canonical contract with each later fix rather than rewriting accepted behavior to excuse its defect.

## Foundational testing decisions

The [test plan](../maintainers/foundational-tests.md) selects stable reusable guarantees, not comprehensive coverage. The first delivered slice protects copying game records and sharing a finite computation allowance across nested/yielding work. These utilities serve many actions and should remain correct when recipes, starting content, dialogue or balance change.

The next small slices attach tests to the immediate patch/hold fixes, then consider money arithmetic, serialized operations, streamed JSON, identity/randomness, conservative geometry/observer boundaries, and authority/durable effects when those owners change. Do not implement the entire list as this review's next phase. Database guarantees need disposable real storage; model quality and enjoyable play require their own evidence.

Excluded: full-world snapshots, exact prompt or narration text, NPC choice snapshots, balance constants, every action family, screenshot snapshots, a new testing framework and a coverage-percentage target. Existing broader tests are preserved. A failed stable-contract assertion should prompt investigation, not an automatic update to the expected value.

### Targeted probes and their limits

- **Private read:** a delayed fake repository behind the real tool service returned the old body after the fixture changed subject access or actor evidence revision. This establishes the missing service check, not a real PostgreSQL forgetting transaction or multiplayer exploit. FR01 requires those integration checks.
- **Public update:** actual activity projection, patch production and browser patch application were connected through JSON on synthetic view objects. Removing activity produced `undefined`, serialized to an empty player change, and retained the old active activity. Changes that force a full reset are different; no general revival/corpse claim is made.
- **Resource hold:** a native world with 5 wood units, a real admitted gather owner and a 3-unit hold was copied into deliberately malformed current data. Removing active work failed while the claimant remained; also removing the claimant passed validation and left only 2 units available after reconciliation. This tests validation, not a normal action producing corruption.
- **Old draft:** synthetic local storage containing an earlier private draft was passed through actual access clearing and draft reading; the old text remained recoverable. No real user's text was read or retained.
- **Observed action:** a real native Gather followed by world advancement produced a gathered quantity of 2. The witness could see the actor but not the resource before or after; all positions passed support/clearance. The witness's retained action evidence nevertheless included the hidden target ID, wood definition and quantity. Whether a particular outcome can be independently seen is an authored event-family question; the defect is unconditional fact disclosure without that decision.
- **Numeric rating:** the actual decoder accepted finite 1.01 and the actual selector deferred as invalid. No provider was invoked, and frequency/quality in real model output is unknown.

The native probes used existing operations; injected services and synthetic browser/view fixtures were labeled as such. Scratch scripts were not added as a second maintained test suite. The new regression tests exercise stable contracts, not all the newly reported bugs.

**Not run:** full `pnpm check`/CI, application build, browser/assistive-device checks, multiplayer networking, PostgreSQL integration/recovery, performance/load/soak measurements, live NPC/model behavior, or human playtesting. Prior reports remain historical evidence. Full required CI remains the merge gate; this review does not waive it or certify population capacity or enjoyment.

**Jev/provider cost:** $0 additional; $0 cumulative for this task. No paid or free provider request was made. Provider latency and model quality were not evaluated.

## Delivery boundary

The review, prioritized implementation plans and first stable test slice are the deliverables. Production fixes remain unchecked in the immediate tracker; later improvements remain conditional. The most useful next implementation work is protecting private/observable evidence, then shared view/resource/continuation correctness. This ordering protects the player's ability to trust what characters know, what the UI says happened, and what survives returning to play, while keeping broader invention and new-world development on one coherent foundation.
