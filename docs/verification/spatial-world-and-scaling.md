Many existing tests assume superseded synchronous/domain/provider contracts. The general full-test TypeScript baseline also has 156 existing errors; the production configuration compiles. This branch does not mark those unrelated failures resolved or claim `pnpm run check` passes.

The Playwright scenario in `tests/browser/spatial-world.spec.ts` passed in GitHub Actions run [35803819218](https://github.com/Macrofold/OpenLegend/actions/runs/35803819218) on commit `5b4676c4e612619bd07b36607e225581e5243c90`. Local Chromium navigation remains unavailable under the administrator policy, and no local browser success is claimed. Broader touch/accessibility, context-loss, late generated-model and multi-client cases remain open in SW16. Screenshots are retained in the run's `spatial-browser-evidence` artifact for seven days. The read-only `.github/workflows/spatial-check.yml` preserves this focused gate without replacing the repository's existing full check.

Two source-review passes covered invalidation/ownership and path/collision/event behavior. Geometry now partitions stacked slabs by center variation and short-circuits boolean stance/sweep work without changing ordered acoustic crossings. Navigation conservatively groups potentially connected supports before building a graph, retains directional checks for tolerance-height seams, reduces exact-coincident zero-cost cliques to stars, reuses reversible same-surface checks and uses generation-stamped bounded search storage. Shared-endpoint support changes validate both native legs before avoiding graph construction. Experience ID membership is scoped to the authoritative mutation owner's draft array and invalidated on non-add changes; raw mutable builders retain live lookup. Audience reuse is confined to the synchronous fixed-position encounter phase. Existing per-event ledger, awareness, commitment and RNG behavior remains in its original mutation path. Neither cache is authoritative or persisted.

Production TypeScript (`tsc --noEmit -p tsconfig.build.json`) and the Vite production build passed. Changed-file formatting and diff whitespace checks passed. The existing client bundle-size warning remains; no full-check or current browser success is claimed. No external providers were configured or called.
