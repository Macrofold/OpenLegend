# What does recording every nearby person's routine work cost?

October 16, 2026. **Personal-record-only diagnostic completed: 7.46% less native CPU. It cannot satisfy ordinary saving; the coordinated event-and-record diagnostic also completes, improving running-server mean progress but still failing the goal.** This deliberately removes a large category of personal observations so we can measure its cost before choosing a permanent compromise.

When one person starts gathering, the game can write a separate account for each nearby person who sees it. In the fixed older-world workload, 234 starts produce 2,771 personal start observations: about twelve per start. Personal observations grow by 6,828 overall; starting work, gathering, preparing and eating account for 5,747, or 84.2%, of that net growth. These are record counts, not measured CPU percentages. They come from a full-checkpoint native replay; the running service keeps a smaller recent subset in memory and stores older records in PostgreSQL.

This includes meaningful bystander observations as well as repetitive ones. For example, in a hypothetical witnessed attack on somebody else, the bystander would lose the new personal event record. Immediate appraisal/commitment calculations retain their current code, so this is intentionally an incomplete cognition model. It is not a finished solution or evidence that such memories are expendable. No model request is made; scripted work cannot establish autonomous character quality.
