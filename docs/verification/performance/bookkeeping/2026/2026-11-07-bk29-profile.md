## Concrete repeated work in the retained opening

The clean case's actual cold checkpoint contains 2,830 world event rows. Of these, 1,659 are animal responses, including 1,575 generic escaping announcements. One avian actor accounts for 1,581 responses and 1,545 escaping announcements. Across five observers, these responses produce 5,983 recent occurrence entries and 5,983 pooled event values totaling 4,557,393 bytes: 52.5% of all 8,685,543 pooled-value bytes. Compactly reserializing those occurrence entry bodies produces approximately 7.08 MB, excluding page/index metadata. These are warmup + measurement + final capture totals, not rates from the sampled 90-second interval.

The corresponding flight-choice admission stack occupies 6.13% of weighted CPU samples, almost entirely its event emission chain (dominant emission descendant 5.86%; awareness acquisition 4.89%, overlapping). The code emits the escaping announcement after each accepted finite flight-leg choice. Retained-choice continuity already has a shortcut; these results do not prove that every retained route repeats the announcement. The justified investigation is whether accepting another leg while already escaping should create another witnessed narrative event, rather than a motion continuation. Suppressing only that announcement is an unrun diagnostic; disabling real flight would change the workload and cannot establish a production improvement.
