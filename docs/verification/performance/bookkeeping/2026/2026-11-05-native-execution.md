## Lookup counter semantics

The **1,849,635** count is `currentReadNativeSelections` in `perception-evidence.ts:prepareCurrentBodyReadScope.native`. A synchronous read scope holds temporary per-subject results. A first request for a combination of field kind, modality, exposure and complete channel pin increments the counter, looks up the contact and selects a matching native field/group. Missing or ambiguous results count too. Repeating the identical request within that scope reuses the result; a later scope or differently shaped selector counts again even if it selects the same unchanged field. A native selection builds a small field/grant/original/metadata view, not a new observation or full historical proof. It is not a database call.

This is the completed **final `72eea53fd` diagnostic, with no subsystem cuts**, on the standard AWS m7i.xlarge. It uses wilderness seed 1086, 7 people, 20 animals, 74 objects, one controlled person, installed 60/30-game-second broad/detail sight and 20-game-second relation/context timing, with zero external model calls. Thirty seconds of warmup precede ninety seconds of input; the recorded interval including drain is 92.440 seconds / 5,574.206 game seconds. The measured phase records 193 accepted command replies and 18 additional speech submissions (24 including warmup), with no skipped offers or client errors. One command request began before measurement and completed within it. Player travel is 357.37 m and animal travel 803.71 m. These are not the separate 360-second operating run's counts or a failed startup attempt.
