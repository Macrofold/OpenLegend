# Complete world edits with less repeated traversal

October16,2026. **Fresh and older-world correctness passed; counterless timing and four actual games are complete; not integrated.** The game repeatedly completes temporary edits into a world that saving and drawing can safely read. Current sampling assigns2.99seconds of one30.75second phase to completing those edits. The immutable-edit library's leaves total6.30seconds across several gameplay paths, overlapping that2.99seconds. These times cannot be added or treated as removable savings.

The [official Immer11.0 release](https://github.com/immerjs/immer/releases/tag/v11.0.0) describes replacing recursive finalization with targeted callbacks. It also changes assigned-field tracking to Map and uses loose property iteration by default. [Current performance guidance](https://immerjs.github.io/immer/performance/) describes the iteration tradeoff. These are upstream design facts, not an OpenLegend speed result. The exact11.1.16release is separately verified from its [official release](https://github.com/immerjs/immer/releases/tag/v11.1.16); this comparison does not assume that any newer version is automatically safe or faster.

OpenLegend directly reads the older library's internal draft data to avoid unnecessary copying and to identify changed people and objects. A blind package swap could silently miss changes. Audit and qualify those readers first. No canonical dependency, lockfile, world representation or game rule has changed. The existing full native and saving proofs must still pass before a gain can be retained. More detailed qualification and results will be added here. Additional/cumulative provider cost is $0.
