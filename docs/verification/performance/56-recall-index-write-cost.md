# How much do memory-search indexes cost when experiences are saved?

October 16, 2026. **Private index-removal candidate passes storage checks; the speed sequence stops at a severe first-control failure. Candidate gameplay is unrun.**

A database index is an extra lookup structure: it speeds up searches but must be updated when records are inserted or changed. The searchable-experience table has fourteen secondary indexes plus its primary key. In the current real-game plan, inserting 228 experiences takes 18.261 ms including constraints; preparing their incoming rows takes only 0.543 ms. The full current diagnostic also ranks experience insertion and recall reconciliation among its largest repeated database costs. This makes index maintenance a concrete hypothesis, not an established cause.
