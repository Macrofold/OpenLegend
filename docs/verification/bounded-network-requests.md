### Limits of this evidence

No timeout forces remote rollback or proves zero charge. JavaScript must be able to run to observe expiry; suspended/blocked execution checks eligibility on resume. Unsupported or uncooperative cleanup can reduce available capacity until actual settlement or owned-process termination. This is a deliberate finite-resource refusal, not evidence that every socket can be forcibly reclaimed.

Complete world projections still have no new byte ceiling. The representative workloads above do not close LA165/PD05 broad memory/capacity work or AS07 operational acceptance.
