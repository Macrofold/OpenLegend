## Performance evidence and remaining limits

The matched moving diagnostic reported by the source-owner review used 37 sensing actors, ten moving birds and 30 game seconds. Before the attention/source optimizations it took 58.898 seconds; the corresponding baseline took 20.210 seconds. After change-fed/read-only attention and related native changes it took 13.634 seconds. Attention's sampled self time fell from 3,769 to 399 milliseconds. These are diagnostic complete-caller observations on one workload, not a supported player count, full-server capacity or final release benchmark. Later native confirmation work requires its own matched result.
