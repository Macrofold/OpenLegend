# Screenshot evidence

[Browse every screenshot](gallery.md) · [Game research atlas](../games/README.md) · [Verified index](index.json)

These are original third-party UI image files downloaded for the requested comparative research. Each game's manifest records its source page and original image URL, version/platform knowledge or uncertainty, inspection status, byte size, dimensions and checksum. Every image is embedded and analyzed in the corresponding game dossier.

Count distinct images, not embeds, crops we create, resolution variants, controls within an image or pages containing an image. Publisher-composed comparison images count once. Source-supplied UI crops and explicitly labeled development previews count as their single actual capture. The one screen photograph is retained as useful additional evidence and excluded from the digital-screenshot count. Open Legend's original design wireframes live separately and never contribute to this count.

Game art, interface artwork and source photographs retain their original rights and attribution. These references are not production game assets and are not relicensed under Open Legend's software license. Original bytes, watermarks and aspect ratios are preserved.

The per-game manifests are the provenance owner. The aggregate index and gallery are derived navigation for this research; keep them synchronized when adding or removing an image. A checksum establishes file identity, not the accuracy of a claim about what a control does. Those claims require the visual inspection and documented interactions in the dossiers.
