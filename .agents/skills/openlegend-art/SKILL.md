# Run an art request

Read the [art workflow](../../../docs/production-workflows/art-flows/README.md), the [default roster](../../../docs/production-workflows/art-flows/tools.md#default-roster) and only the tool sections you will use, then only the matching [profile](../../../docs/production-workflows/art-flows/profiles.md) and route: [3D models](../../../docs/production-workflows/art-flows/3d-models.md) for props, characters and creatures, [production packages](../../../docs/production-workflows/art-flows/production.md) for other finished assets. Keep the [study record](../../../docs/production-workflows/art-flows/study-record.md). Read root and applicable art, UI, asset-storage and PlayCanvas guidance; these pages do not replace it.

When drafting or revising generation or edit prompts, use [prompt direction](../../../docs/production-workflows/art-flows/prompting.md#start-with-the-current-brief) and only its matching task examples. Translate the existing brief into the selected tool's inputs; this adds no generation step, candidate, approval gate or style rule. The linked research is optional evidence, not required context for every art request.

Accept natural-language requests without requiring parameters. Infer the settings, including the [simple or full path](../../../docs/production-workflows/art-flows/README.md#quality-the-simple-and-full-paths) and any [step options](../../../docs/production-workflows/art-flows/README.md#step-options), state them in one plan line with the estimate and next decision point, then work. Defaults: the simple path (one candidate, short check) for model and animation generation, and the full path for finished, game-ready or polished work and every other request; a quality word decides the path, a destination such as "for the game" does not, and asking to pick gives that step the full path's candidates; an animated walking character for OpenLegend gets `Idle`, `Walk` and `Run` (the game requires `Idle` and `Run`); on the full path, or when asked to fix a face on either path, `head=auto` diagnoses surface repair versus head replacement; an explicit head option overrides; on the full path, three concept directions, three model candidates and Mike deciding direction, candidate and acceptance; supplied material skips the steps it already answers; the standard tool roster, `faithful` fidelity for a supplied or selected source, and the $10 task ceiling. "Regular", "manual" and "standard" mean the default tools; "Higgs field" means Higgsfield; "both" means a comparison.

Take the look from the selected world's art direction, never from these instructions or memory, and never write a style rule into the workflow pages. Handle prompts, tools, file transfers, inspection, sheets, revision and preservation yourself. Ask only for an unresolved consequential choice or an unavoidable access, account or budget action.

Keep workflow choice separate from scope. A study produces preserved candidates; it does not implement them or change the accepted direction. A request to edit this workflow is documentation work, not authorization to execute it. Existing chat authorization covers only the steps it actually names.
