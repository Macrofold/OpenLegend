## Reading them well

- **Each brief defines its own tags** at the top. The docs in the parent folder translate them into one shared scheme, explained in the [folder README](../README.md#how-to-read-these-docs).
- **Search limits.** The shared web-search budget ran out partway through several briefs, so later checks relied on fetching known pages directly, and some pages could not be read at all. Each brief lists its gaps.
- **Unverified items are marked.** Anything tagged as unverified, from memory or not re-checked should be confirmed against a primary source before it is quoted or used outside this folder.
- **Interpretations are the researcher's.** Design suggestions inside the briefs (often tagged [Interp] or similar) are inputs to the ideation, not recommendations the project has accepted.

The most important sources are gathered by theme in [sources](../sources.md).
