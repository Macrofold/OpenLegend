## 1. An unfinished release has a current game and a future promise

The reproduced developer FAQ identifies **Forbidden Rites / 0.5.5** as the September 4, 2026 event league. Joining creates a new character in a fresh economy; Runes of Aldur continues separately. **Duelist and the full 1.0 release are planned for December 11**, not already delivered on this research date. [Q01](#q01)

**Interpretation:** a new seasonal opportunity does not erase every existing character, and a public database containing an unreleased class or area is not proof players can use it. Research the available activity and label the development promise separately.

## 2. An action is composed in the Skills panel

Support gems sit in sockets on the skill they modify, rather than inheriting the original game's equipment-link arrangement. The current reference distinguishes category restrictions within a skill from the narrower global restrictions on exact Lineage supports and certain persistent-buff supports. An early-access rule that universally forbids repeating any support across the entire character is not the current complete rule. Meta gems can contain skills and supports but cannot contain another Meta gem. [Q02](#q02)

**Interpretation:** acquisition, compatibility and composition are different steps. A larger palette is useful only when the player understands which operation applies to which action. A nesting restriction can preserve legibility without eliminating combinations.

### A concrete support changes the timing problem

**Unleash** accumulates Seals, then repeats a supported spell when it is cast. Repetitions do reduced damage, and skills with cooldowns or an existing Seal mechanism are excluded. [Q03](#q03)

**Worked choice:** allow a useful spell to prepare while moving or performing another action, then spend its accumulated repetitions during a favorable opening. Continuous use and delayed use now have different value. More repetitions are not unconditional free damage, and an ineligible spell does not gain the behavior merely because its name sounds compatible.

## 3. Weapon sets change more than the held model

Two weapon sets can carry different items, dedicated passive allocations and amounts of available **Spirit**. Skills can automatically select a required set or use an explicitly assigned one. Spirit maintains persistent effects such as supported buffs and minions; it is not just another spelling of mana. [Q04](#q04)

**Worked consequence:** a build can change its practical resource budget when a skill switches equipment. A support effect that works in one configuration may not remain eligible in the other. The useful question is not only whether the character owns enough equipment, but which configuration is active now.

A September 2025 player thread makes that interface problem concrete. **Chillyjam** reported that a Spirit skill was not functioning; **nil0tan** described resolving the same apparent issue by correcting its weapon-set assignment, and the original poster thanked them. This is a reported diagnosis, not proof that every Spirit bug has the same cause. [Q05](#q05)

**Interpretation:** an inactive effect can be a configuration error, insufficient resources or a defect. A readable system helps distinguish them instead of making the user reconstruct the entire build to discover which stage failed.

## 4. Automatic protection still requires preparation

**Charms** trigger under specified conditions and consume charges. Their recovery sources include kills and supported checkpoints/wells. A **Thawing Charm** responds to freezing, while other charms address different threats. Limited slots require choosing protection rather than equipping every possible response. [Q06](#q06)

Life and mana flasks are reusable, charge-limited recovery tools; checkpoints and wells replenish them. The present reference also documents checkpoint travel within an area. [Q07](#q07)

**Worked distinction:** the player decides which automatic response to prepare, then may not need another reflex input when that condition occurs. This relocates agency rather than removing it. Protection can still fail if its charges are unavailable or it addresses the wrong threat. A difficult boss and ordinary enemy groups can impose different demands on the same charge economy.

## 5. A familiar currency name can conceal a different operation

The sequel's **Chaos Orb** removes a modifier and adds another to a rare item. It is not the original game's full rare-affix reroll. Its Greater and Perfect variants constrain the replacement's minimum modifier level, while retaining uncertainty about the actual result. [Q08](#q08)

**Worked choice:** risk losing a useful property to improve another part of an item, or preserve the current functional equipment and work on a replacement. Improving one numerical threshold does not guarantee the whole outcome suits the build. The currency is both a crafting operation and something that can serve another acquisition plan.

**Interpretation:** reusable names do not guarantee compatible semantics across games. A player or authoring assistant importing the old operation by analogy could destroy the very property it meant to preserve.
