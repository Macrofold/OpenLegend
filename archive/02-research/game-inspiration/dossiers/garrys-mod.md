## Verified current boundary

The official September 16, 2026 update adds Windows 64-bit build availability and Sandbox interface improvements. This supersedes any assumption that the current product is simply its old 32-bit configuration; it does not demonstrate unlimited performance or repair every add-on. [P1]

The official tool inventory explicitly distinguishes shipped tools from community content. Prop Hunt's wiki identifies hunter penalties for attacking ordinary props and settings-dependent taunts; DarkRP's page describes a separate role-play ecosystem. None of these rules is a universal Sandbox economy or progression contract. [P2] [P3] [P4]
