## Mixed spatial review

The current renderer keeps 2D images facing the camera under yaw and pitch, using shared upright virtual depth for lighting/picking while bodies and shadow proxies remain world-space. Shadow-only casters do not occupy color layers; proxy geometry, reveal uniforms and plank detail are reused. Native visual acquisition is observer-private; the designated introduction selector admits only the observer's own acquisition, not private thoughts or third-party evidence. Indexed route-support projection, crossed-cell terrain checks and worker failure/shutdown handling are implemented. [Evidence](../../docs/verification/mixed-spatial-review.md) and SW/EPR/PF/SR trackers separate these facts from unqualified GPU, crowd, exposure and lifecycle limits.

## Spatial-world foundation

The current model uses continuous XYZ/support state, shared capsule/cylinder body profiles, server-worker Recast/Detour ground corridors and Rapier shape-level clearance. Exact support reconstruction, checked string-pulling and bounded replans replace the former lattice planner. Required pending work holds simulation time without retaining the writer. Ordinary native movement/flight, analytic sight/hearing and ledger/effect owners remain authoritative.

The client has camera-facing lit sprites with separate upright virtual depth beside meshes, sun/local-fire lighting, multi-receiver shadow maps with simple body proxies, continuous right-drag orbit/pitch and profile-configurable local authorized read-through. Ramp display interpolation preserves common seams; cutaway geometry retains shadows. The target-only reveal pass does not open holes onto unknown background content. This is not full per-pixel occluder-opacity editing or inferred 3D art.

Current facts: [Architecture](../../docs/architecture.md#spatial-world-foundation). Current observations: [Recast integration](../../docs/verification/recast-integration.md). ## Immediate gameplay limits

Shared reachable containers, durable explicit restrictions, giving, recursive own-item use and dependency-aware inventory handling are implemented through domain, server and UI. Server/database work lanes now bound queued depth/age, with coordinated 100-player admission defaults and fair/coalesced private projection. Native execution reuses unchanged exposure results and yields private progress while retaining one atomic transition. SQL retains cold awareness outside the row/byte-targeted resident tail; retrieval guards bodies before hydration, caches revision-scoped metadata and uses native lexical indexes. [Current architecture](../../docs/architecture.md), [evidence](../../docs/verification.md#immediate-gameplay-limits), and [remaining PF work](../../docs/maintainers/performance.md#immediate-gameplay-limits-follow-through) distinguish implementation from unmet dense/sustained release performance.

Elapsed-time integration now separates clock conversion, host wake, native boundaries and rendering. Linear finite-family rates and work consume elapsed game time with start-state predicates and endpoint effects, shortening intervals for mechanical deadlines and explicit sensory fidelity. A 60-game-second base ceiling and unsupported coupled-law fallbacks remain revisitable policy. The host accepts actual progressed time, not requested calls, retains debt and existing routine/command durability, and introduces no save reset or feature version. [PF13](../../docs/maintainers/simulation-time.md) and the [boundary catalogue](../../docs/maintainers/simulation-boundaries.md) distinguish implemented scope from regional/exact-exposure and general coupling work. [Evidence](../../docs/verification/simulation-cadence.md) records short actual 8x server observations and their limitations; this is not combined sound-branch or physical-GPU acceptance.

The spatial/cadence performance follow-through adds receiver candidates, scalar visibility reuse, affected-region object invalidation, changed-history sealing and perception-only inter-slice snapshots. Private motion deadlines reuse mechanical predictions, constrain small senses to potentially interacting movers and let the host request publication at coherent boundaries. Flight evidence reads synchronized poses; continuous state retains the existing phase order. [Matched evidence](../../docs/verification/spatial-cadence-main-integration.md#performance-follow-through) distinguishes these reductions from remaining dense 8x, regional rates and growing-history qualification in PF12/PF13.
