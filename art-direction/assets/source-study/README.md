# Source-based starting-world study

Work in progress under the [approved replacement strategy](../../../docs/projects/3d-pixel-art-first-scene-plan.md#proposed-replacement-study--october-16-2026). These are review candidates, not accepted artwork or completed game integration.

The original concept-derived mercenary and three Quaternius tree structures are being compared in the existing `/art-study.html` inspector. The earlier rejected study remains preserved. Each new catalog beside the runtime GLBs records sources, exact hashes, measurements and the editable Blender file here.

- Mercenary: owner-supplied Meshy body and rig with original OpenLegend cape; imported source production rights remain unqualified. The restored control recovers the earlier viewer's 29-color preparation. Tailored and embroidered alternatives retain the original face while changing clothing/material organization.
- Broadleaf sources: Quaternius Stylized Nature MegaKit Standard, exact acquired CC0 archive and licenses recorded in [environment provenance](../../../apps/client/src/props/library-environment/provenance.json). Actual library topology and leaf cards, normalized for the study. Source texture finish remains a comparison input.

`scripts/prepare-source-study.py` reads those retained sources without changing them and reuses the existing static export helper. Static GLBs demonstrate source/material choices; they do not establish animation, cape coverage or in-game qualification. The original animated files and cloth owner remain available for that work.

The inspector compares fixed metre-scale sampling with a smooth 3D control. Its enlarged images and source textures do not by themselves prove rotation stability. Actual motion, scene composition, remaining families and runtime integration are still being implemented.
