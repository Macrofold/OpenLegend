# Source-based starting-world study

**Current art target:** beautiful dimensional pixel art with believable proportions; visibly low-poly, blocky, cutesy and big-head/small-body designs are excluded by the [current visual requirements](../../decisions.md#current-visual-requirements--october-16-2026). Retained source assets, alternatives and their credits document the study; their presence is not style approval. This preference update does not replace assets or alter their licenses.

Implemented October 16, 2026 under the [authorized replacement strategy](../../../docs/projects/3d-pixel-art-first-scene-plan.md#proposed-replacement-study--october-16-2026). The collection and runtime comparisons are delivered; working selections are provisional art, not Mike's acceptance or production qualification. [Actual evidence and review access](../../../docs/verification/source-based-starting-study.md) own captures, measurements, defects and remaining limits.

There are 24 editable Blender files for 45 families, 135 static alternatives, 42 normalized source controls, 39 additional animated exports and three depleted berry exports. The catalogs beside `apps/client/src/props/art-study/source-*` record source URLs/digests, generation recipe/helper hashes, evaluated dimensions, geometry, textures and output hashes. Source/recipe hashes describe the recorded export run. The 219 runtime GLBs total 273,063,156 bytes for the complete preserved study; the game loads selected appearances, not every option.

## Reproduce or edit

Blender 5.2.2 LTS successfully exported these sources on the local Mac. Invoke recipes through Blender with `--background --factory-startup --disable-autoexec --offline-mode --python-exit-code 1 --python scripts/<recipe>.py -- <arguments>`. Downloaded Blend files are treated as data; startup scripts stay disabled. Human preparation uses an isolated temporary `BLENDER_USER_CONFIG` directory and imports the acquired official MPFB source in that process only. Reacquire missing originals using their exact recorded URLs and verify digests; do not silently substitute the current upstream master/archive.

| Recipe | Inputs / output role |
| --- | --- |
| `prepare-source-study.py` | `--mercenary <original-study> --libraries <environment-extracts>`; optional `--families mercenary broadleaf`. |
| `prepare-human-study.py` | `--sources <mpfb/core/garment-directory> --person <ada|mike|mara|tavin|kest|orin|armor>`. Uses `study_human_motion.py` for fitted rig export. |
| `prepare-animal-study.py` | `--sources <animal-directory> --species <wolf|deer|stag|bird|bear>`; retained sources and explicitly authored bird/bear motion. |
| `prepare-hare-study.py` | Uses the retained repository rabbit source; source-proportioned hare variants and motion. |
| `prepare-equipment-study.py` | `--sources <weapons-directory>`; source weapon constructions. |
| `prepare-nature-study.py`, `prepare-chest-study.py`, `prepare-small-equipment-study.py` | `--libraries <environment-extracts>`; source forms and authored material/detail alternatives. |
| `prepare-resource-study.py` | `--libraries <environment-extracts> --pack <backpack-glb>`; includes depleted berry variants. |
| `prepare-study-controls.py` | `--sources <source-study-downloads> --libraries <environment-extracts> --mercenary <original-study>`; optional `--families ...`. Normalized original-source comparisons. |
| `prepare-study-scenery.py` | Extracts selected catalog exports into the existing instanced-scenery data format. Run after changing those selected source assets. |

The shared `art_study_common.py` measures evaluated geometry, exports static joined-by-material copies and retains separately editable originals. Eye features fit to the actual source surface and follow its head. Texture minification keeps mip filtering to suppress subpixel noise; source artwork is not regenerated by camera changes. GLB exports are checksummed after sampler adjustments. Export scripts do not write a game save, call a provider or grant native equipment.

Run the existing Vite client on any free port and open `/art-study.html` for source/options or `/scene-study.html` for actual scene comparisons. Current choices use 40 samples/metre and closer game framing, with 20/30/64 and the earlier overview retained. The ordinary adult is 1.85 m and mercenary 2.035 m in calibration; these are presentation measurements, not changed world body rules. Inspect actual moving exports and all affected scene consumers after an edit; a successful Blender export alone is not visual qualification.


## Poly Haven detail study — October 17, 2026 UTC

Four additional CC0 families retain the original normalized source and clear, quiet and weathered finishes. The chest (Rico Cilliers), boulder (Rico Cilliers), fern (Rob Tuytel / Rico Cilliers) and dead tree trunk (Rob Tuytel) come from [Poly Haven](https://polyhaven.com/license). Exact URLs, sizes and SHA-256 values are in [the acquisition manifest](polyhaven-sources.json) and each family catalog. These are actual imported source forms and adapted albedo maps, not newly hand-painted pixel textures. The existing renderer supplies the final pixel treatment.

The clear chest is the new ordinary crate appearance; the former banded/carved/cache alternatives remain available. The quiet boulder and clear fern/fallen log are inspection selections, not new world placements or replacements for every tree/stone. The source fern contains four arranged plants; the study uses one complete specimen. The trunk is a fallen log. The remaining angular bear has not been replaced; current source/access findings are recorded in [the new review](../../../docs/verification/small-subject-art-and-atmosphere.md).

To reproduce, download each manifest URL under `<sources>/<asset>/<file>`, verify its digest, and copy the manifest to `<sources>/download-manifest.json`. Run the existing Blender executable with `--background --factory-startup --disable-autoexec --offline-mode --python-exit-code 1 --python scripts/prepare-grounded-study.py -- --sources <sources>`. Blender runs locally; no provider generation or uploads are required. Selected derivatives use 512-square albedo (clear) or 256-square albedo (quiet/weathered), remove fine normal/specular noise, and preserve UV construction/cutouts. Coincident organic-surface vertices are welded before triangle-budgeted reduction; actual exported geometry is inspected and counted. Original controls remain intact in the editable sources and separate GLBs.
