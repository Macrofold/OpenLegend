# Natural-source replacement set

Prepared October 16–17, 2026 EDT for the [authorized replacement](../../../docs/projects/3d-pixel-art-first-scene-plan.md#replace-the-remaining-quaternius-selections--october-16-2026-edt). The [review evidence](../../../docs/verification/natural-source-replacements.md) owns visual checks, measured costs and limitations; the [capture archive](../../studies/2026-10-17-natural-replacements/README.md) preserves accepted and rejected trials. Believable proportions and dimensional pixel art remain controlling; visible low-poly facets, blocky/cutesy forms and oversized heads remain rejected.

## Retention and reproduction

Nineteen `source-natural-*` catalogs contain 57 finishes and original controls; 16 families supply current replacements. The simpler Shrub 02 trial, its berry adaptation and the rejected box-shaped Wildfire pack remain inspectable. All prior Quaternius exports and captures remain available as **Retained source** choices. Existing Poly Haven conifer/chest and the Meshy mercenary remain unchanged.

Catalogs record source URLs/download hashes, editable Blend hashes, recipe/helper hashes, actual bounds, triangles, textures and final GLB hashes. The original large tree control is shared by broadleaf and pale-barked families; it is not duplicated. Source-control geometry is intentionally expensive and is never selected for ordinary scenery.

- `prepare-natural-replacements.py`: Poly Haven glTF inputs and yd's packed Blend; select whole tree leaves before simplifying bark/foliage separately; consolidate branch UVs; compose rooted shrub stems; prepare grouped materials and fruit-free exports.
- `prepare-natural-deer.py`: source Blends opened with scripts disabled; actual skin UVs and fresh Principled materials; four-weight skinning shared by static evaluation and animated export.
- `prepare-natural-wildfire.py`: Collada conversion with temporary official Blender 4.2.23, followed by current Blender preparation. Original DAE, textures, actor records, license and exact repository commit are retained in [wildfire-originals](wildfire-originals/manifest.json).
- `prepare-natural-pack.py`: visible Sintel meshes only; explicit UV bindings, two shared leather/quilt materials and bounded fine cord/cloth geometry. Original archive and license are retained in [sintel-pack-originals](sintel-pack-originals/download.json). Its old embedded UI script is never executed.
- `prepare-study-scenery.py --natural`: compile the five selected scenery shapes into the existing instanced format, respecting each material's UV set and texture transform. No runtime model conversion or new placement authority.

Run authoring recipes with `Blender --background --factory-startup --disable-autoexec --offline-mode --python-exit-code 1 --python <recipe> -- --sources <download-directory>`. The Wildfire Collada step uses Blender 4.2 and `--convert-collada` (omit `--offline-mode`, unsupported there); the current Blender step exports GLBs. No dependency or application installation is required by the game. Raw CDmir and yd Blends are retained beside the edited sources. Poly Haven download manifests in each catalog identify every original glTF, buffer and texture.

The finite [selection data](../../../apps/client/src/props/art-study/selections.json) changes presentation only. Shape, pose and material preparation remain offline; the scene reuses its existing loading, instancing, shadows, camera obstruction and disposal owners.
