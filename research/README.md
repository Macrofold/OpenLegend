## Game engines and platforms

The [game-engine research collection](game-engines/README.md) compares browser and native engines, performance/hardware limits, controllers, networking, effects, live generated content, console/mobile deployment, licensing and production cost.

Start with the [Open Legend recommendation](game-engines/open-legend-assessment.md), then use the [comparison matrices](game-engines/comparison-matrices.md) and individual dossiers. A [proposed benchmark plan](game-engines/benchmark-plan.md) identifies the unmeasured evidence needed before committing to a migration.

Research is not implementation approval. Current executable behavior and accepted policy remain in the repository's [architecture](../docs/architecture.md), [performance](../docs/performance.md), [gameplay priorities](../docs/repertoires/gameplay-priorities.md) and [licensing](../LICENSING.md) owners. This collection changes none of those contracts.
