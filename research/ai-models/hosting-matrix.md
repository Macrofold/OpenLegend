[Overview](README.md) · [Runpod workflow](runpod-hosting.md) · [Capacity planning](capacity-planning.md) · [Structured records](data/README.md#runpod-hosting-records)

Use a specific profile rather than combining a family’s strongest features and smallest memory figures. **Publisher GPU evidence** can be a card-budget claim, an example setup or a measured peak under that publisher’s workload; its wording preserves the distinction. **Planning GPU** is an untested candidate, not a minimum. Weight/artifact size excludes runtime state. Full host-RAM and disk minima remain unknown unless explicitly published. All configured deployment limits, game-request fit and measurements are still unknown.

Context cells preserve native claims, configuration positions, runtime defaults and their source scope separately. Hosted limits belong to the listed external route. The complete JSON profile retains input/audio limits, memory basis, dependencies, blockers and source IDs; the linked domain record provides human-readable evidence and sources. Values marked unknown must be resolved before claiming that a configuration supports an intended workload.
